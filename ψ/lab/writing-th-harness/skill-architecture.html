The Writing‑TH Harness

A closed loop. writing-th draws rules from one style pack and produces a merged Thai deliverable; style-capture reads the edits you make by hand and promotes them back into that same pack. This page shows the pipeline as it runs today, and what is still proposed.

Shipped

Tranche 1 is built and verified. The gates are binding rather than advisory, five defects found by running the code are fixed, and the two style packs are now one typed pack of 48 rules. Six verification checks pass. Everything marked proposed below is not built.

The loop

Five nodes and two arcs. Every rule the harness enforces lives in one file, and exactly one skill writes to it.

  • Forward arc — writing-th
  • Return arc — human edit and promotion
  • Binding gate — exit code, not persuasion
  • Proposed — not built

Forward arc · writing-th, as it runs today

Seven stages, the v4.0.0 order. The content-first reorder is real but unbuilt — it is listed under tranche 2 below rather than drawn here as if it shipped.

0

Calibration

การเตรียมความพร้อม
Stop

Loads the style pack, builds the jargon ban list, and halts to confirm the writing persona — before any source document is read.

Still open

The pack’s own activation map puts voice at stage D (“only after structure and payload already work”) and lexicon at stage E (“a late-pass sweep, not a first-pass drafting engine”). Stage 0 does both first. Learning 2026‑06‑10 names this as the hollow-draft cause.

1

Strategy

การกำหนดวาทศิลป์
No gate

Defines the victory condition and the evidence→analysis→solution shape: stance, risk to manage, and the ask.

Still open

Scaffolding is a generative anchor. Learning 2026‑04‑05: metaphor here produces metaphor in the final prose, and nothing written at this stage passes through the gates.

2

Density & Scope Validation

ด่านวัดขนาดข้อมูล
Stop

Lists every table, equation, and framework in the source that must survive the rewrite, then halts for sign-off on that list.

3

Payload Gate

ด่านสกัดความกลวง
No gate

4‑Pillar Extraction — Claim, Concrete Example, Consequence, Mechanism — required before drafting is permitted.

Still open

Applied to every paragraph with no exception. The style pack says each substantive paragraph; a foundation paragraph forced to carry a claim invites the model to invent one.

4

Governed Execution

การร่างที่ถูกควบคุม
No gate

One subagent per subsection. Output goes only to ψ/incubate/drafts/; the target file is unreachable from here by construction.

Still open

Subagents get a topic, not a contract. Learning 2026‑07‑03: delegated scope, examples, and qualifiers must be declared non‑removable.

5

Script Gates

ด่านสคริปต์บังคับ
Binding

Lexicon lint plus density. Exit code 1 is a silent rejection. Rules marked structural print as [REVIEW] and do not block — the stage now states its own coverage instead of implying total enforcement.

Fixed

Three of the five rules from the 2026‑08‑05 round never fired — prose descriptions sitting in a field compiled as regex, where [ผลงาน/deliverable] became a character class. All three are now kind: regex with real patterns. One caught "storefront" in a live report on its first run.

Fixed

A rule whose prescribed replacement contained its own banned string made the rerun-until-exit-0 loop non-terminating. It is an expand-the-claim instruction, not a term swap, and is now kind: structural.

Fixed

Word and sentence boundaries now come from PyThaiNLP. DCCE no longer fires inside a path, the contrast rule scopes to one sentence, and code spans, link targets, and file paths are excluded from prose linting entirely.

Still open

Density remains a floor with no ceiling. A draft at 3× source length passes silently, so padding is still the cheapest way to clear the gate.

6

Merge

การอนุมัติและรวมไฟล์
BindingStop

You approve, and merge_draft.py copies the draft over the real file.

Fixed

The merge used to check only that the draft existed, then copy — it never called the gates. It now runs them itself and exits 1 without touching the destination, so calling merge directly is safe. --skip-gates exists for deliberate override and prints a loud warning.

Return arc · style-capture

The learning half. It reads what you changed by hand and turns repeated corrections into permanent rules.

A

Read the delta

Human-initiated

Runs git diff on the file you edited in place. Deleted lines are the draft, added lines the correction.

Open loop

Nothing in writing-th invokes this. Stage 6 merges and the workflow ends; promotion happens only when you remember to run it.

B

Materialize evidence

Artifact

Writes a dated diff-evidence file recording the word-for-word changes and candidate rules before anything is promoted. The case that produced each rule is kept, not just the rule.

C

Validate before promoting

Binding

Every rule declares a kind — literal, regex, or structural — and a scope. validate_lexicon.py rejects a literal containing regex metacharacters or an ellipsis, a rule whose fix contains its own banned string, and duplicates.

Fixed

The producing side was ungated while the consuming side was gated. Run against the old lexicon the validator flags 7 malformed entries — every defect that reached production, caught at the moment of writing.

D

Check the miss register

Proposed

An append-only SQLite log of every run, every rule that fired, and every correction made by hand. Promotion fires once a pattern has failed twice.

Proposed

Learning 2026‑06‑27 already fixed the threshold at two. Nothing counts to two — markdown files cannot aggregate. The same log would make regression runs possible: replay today’s ruleset over drafts written before those rules existed.

E

Merge into the pack

No gate

Appends examples and counter-examples to the pack, adds term pairs to the lexicon, and re-ranks rules appearing across multiple samples.

Still open

When a new pattern contradicts an old rule the instruction is to prefer the new one and “keep a note.” Across nine append-only rounds nothing is ever marked retired, so the pack only grows.

F

Index to Oracle

Persisted

Calls oracle_learn with the delta so the round becomes searchable memory, and synthesizes a prompt that can activate the style in a fresh session.
