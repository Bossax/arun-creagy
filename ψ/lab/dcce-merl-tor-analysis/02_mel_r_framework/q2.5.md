# Does evaluation require an explicit target value

## Question
Does the evaluation process need target values, or can something else serve as the basis for judgment?

## Evidence
This session's own reasoning, refined directly in response to Boss's pushback. A target is one form of a stated basis for judgment — but not the only one. The alternative is a recorded theory-of-change assumption ("we expect X to produce Y because we believe Z"), which is falsifiable without a number attached. Targets are structurally awkward for adaptation outcomes specifically: there's no agreed definition of "successful adaptation" (see [[q2.1]]); climate baselines shift underneath a fixed target; the attribution gap means hitting a target doesn't establish you caused it; and maladaptation can hide behind a hit target (e.g. irrigation expansion meeting a coverage goal while depleting an aquifer). Ditto's own Dimension 4 design (see [[q3.2]]) runs *all* indicators — including outcome-level ones — through the same percent-of-target scoring mechanism, which fits output/monitoring indicators well but distorts outcome/evaluation indicators.

## Judgement
Closed. The workable arrangement is two evaluative bases running in parallel: targets for the output/monitoring side (honest, verifiable, within an agency's control), recorded assumptions and contribution reasoning for the outcome/evaluation side (where the useful question is whether the causal logic held, not whether a number landed). What DCCE currently has is neither running properly — see [[q4.5]] for how this should reshape the TOR's evaluation-metrics clause.
