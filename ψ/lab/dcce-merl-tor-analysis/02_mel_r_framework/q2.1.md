# What separates Monitoring from Evaluation

## Question
What actually separates Monitoring from Evaluation — is it just "does a target exist"?

## Evidence
OECD review of 106 adaptation project documents across six bilateral development agencies, *ENV/WKP(2011)8* (`ψ/inbox/notebooklm_runs/2026-08-21_1539.../q1_monitoring_vs_evaluation.json`). Six real dimensions, not one: **attribution** (evaluation confronts the "attribution gap" — rigorous causal attribution in adaptation is "negligible," so contribution analysis substitutes for proof); **value judgment** (no field-wide consensus on what "successful adaptation" means, so evaluators inject subjective judgment); **timing** (monitoring is continuous through the project; evaluation needs a much longer horizon — see [[q1.5]]); **methodology** (monitoring runs on RBM/logframes; evaluation needs surveys, focus groups, consultation); **who conducts it** (internal staff vs. external evaluators — a real objectivity trade-off).

## Judgement
Closed. None of these six dimensions require a target value to exist — what they require is a stated basis for judgment set in advance, which a target is only one form of (developed further in [[q2.5]]). This directly corrects an earlier, cruder framing in this session ("evaluation = comparing numbers to a benchmark") that Boss pushed back on directly.
