# บทสรุปผู้บริหาร

ข้อเสนอในการปรับปรุงโครงสร้างพระราชบัญญัติป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 มีเป้าหมายสำคัญเพื่อยกระดับกฎหมายจากระบบที่มุ่งเน้นการบัญชาการเหตุฉุกเฉินและการให้ความช่วยเหลือหลังเกิดภัย ไปสู่ระบบกฎหมายที่สามารถลดความเสี่ยงล่วงหน้า เตรียมพร้อมก่อนเกิดเหตุ ปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ และใช้กลไกการเงินเพื่อป้องกันความเสียหายได้อย่างทันท่วงที การปรับปรุงนี้มีความจำเป็นเนื่องจากสถานการณ์สาธารณภัยในปัจจุบันมีความแปรปรวน รุนแรง และซับซ้อนมากขึ้น ทั้งจากสภาพภูมิอากาศสุดขั้ว น้ำท่วมฉับพลัน ภัยแล้ง ดินถล่ม คลื่นความร้อน การขยายตัวของเมือง และความเปราะบางของประชาชนในแต่ละพื้นที่

ประเด็นการปรับเปลี่ยนหลัก คือ การเปลี่ยนบทบาทของกฎหมายจาก “กฎหมายจัดการภัยเมื่อเกิดเหตุ” ไปเป็น “กฎหมายกำกับระบบลดความเสี่ยงภัยพิบัติทั้งวงจร” โดยยังคงกลไกอำนาจในการบัญชาการเหตุฉุกเฉินไว้ แต่เพิ่มกลไกใหม่ที่ทำงานก่อนเกิดภัย ได้แก่ กลไก DRR no-regret กลไกการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ กลไกกองทุนภัยพิบัติและการเงินเพื่อการลดความเสี่ยง กลไกข้อมูลความเสี่ยงและผังภูมินิเวศ กลไก anticipatory action และกลไกฟื้นฟูแบบ Build Back Better ทั้งหมดนี้มีเป้าหมายเพื่อให้รัฐสามารถดำเนินมาตรการล่วงหน้าก่อนเกิดความเสียหาย ลดการพึ่งพาการเยียวยาหลังภัย และเพิ่มขีดความสามารถของพื้นที่ในการรับมือกับภัยที่เปลี่ยนแปลงรวดเร็ว

การปรับเปลี่ยนหลักอีกประการหนึ่ง คือ การทำให้การป้องกันและบรรเทาสาธารณภัยไม่ใช่ภารกิจของกรมป้องกันและบรรเทาสาธารณภัยเพียงหน่วยงานเดียว แต่เป็นภารกิจร่วมของหลายกระทรวงและหลายระดับการปกครอง โดยกำหนดให้กรมป้องกันและบรรเทาสาธารณภัยเป็นหน่วยประสานหลักด้าน DRR no-regret และการบัญชาการเหตุฉุกเฉิน กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม โดยกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม เป็นเจ้าภาพด้าน climate adaptation กระทรวงการคลัง กรมบัญชีกลาง และสำนักงบประมาณ เป็นเจ้าภาพด้านกองทุนและกลไกการเงิน ขณะที่กรมส่งเสริมการปกครองท้องถิ่น จังหวัด อำเภอ และองค์กรปกครองส่วนท้องถิ่น ก็ต้องยกระดับขีดความสามารถในเตรียมพร้อม-เผชิญเหตุอย่างชัดเจนสอดคล้องกัน

ด้านการเงิน ข้อเสนอสำคัญคือ มาตรการ DRR no-regret ไม่ควรถูกออกแบบให้ต้องพึ่งพางบกลางหรือกองทุนภัยพิบัติเป็นหลัก แต่ต้องถูกบรรจุไว้ในงบประมาณปกติ งบฟังก์ชันของกระทรวง/กรม งบจังหวัด และงบท้องถิ่น เพื่อให้การลดความเสี่ยงกลายเป็นภารกิจประจำของหน่วยงานเจ้าของภารกิจ ส่วนกองทุนภัยพิบัติควรเป็นกลไกเสริมสำหรับกรณีจำเป็น เร่งด่วน ข้ามหน่วยงาน หรือกรณีที่ต้องดำเนินมาตรการป้องกันล่วงหน้าแต่ไม่สามารถใช้งบปกติหรือเงินทดรองราชการได้ทันการณ์ โครงสร้างกองทุนจึงควรรองรับอย่างน้อย 3 บัญชีย่อย ได้แก่ 1\) DRR no-regret, 2\) climate adaptation, 3\) anticipatory action และ Build Back Better

การปรับปรุง พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ต้องมุ่งสร้างกฎหมายที่มีขีดความสามารถสูงขึ้นในการรับมือกับสาธารณภัยที่แปรปรวนและซับซ้อนมากขึ้น กล่าวคือ ต้องไม่จำกัดอยู่ที่การบัญชาการเหตุฉุกเฉินและการช่วยเหลือหลังภัย แต่ต้องรองรับการลดความเสี่ยงล่วงหน้า การใช้ข้อมูลพื้นที่เป็นฐาน การใช้มาตรการเชิงโครงสร้างและไม่ใช่เชิงโครงสร้าง การปรับตัวต่อสภาพภูมิอากาศ การใช้กองทุนอย่างมีเป้าหมาย และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ ทั้งหมดนี้ควรอยู่ภายใต้หลักร่วม 3 ประการ คือ ลดความเสี่ยงล่วงหน้า ใช้ข้อมูลผังภูมินิเวศและความเปราะบางเป็นฐาน และไม่สร้างความเสี่ยงใหม่ในอนาคต

# ข้อเสนอในการปรับปรุงโครงสร้าง พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570

การปรับปรุง พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ควรมุ่งเปลี่ยนกฎหมายจากระบบที่เน้นการบริหารจัดการเหตุฉุกเฉินและการช่วยเหลือหลังเกิดภัย ไปสู่ระบบกฎหมายที่ครอบคลุมการลดความเสี่ยงภัยพิบัติล่วงหน้า การเตรียมพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การใช้ข้อมูลพื้นที่เป็นฐาน และการจัดระบบกองทุนเพื่อป้องกันความเสียหายก่อนเกิดภัย โดยยังคงกลไกการบัญชาการเหตุฉุกเฉินไว้ แต่เพิ่มบทบาทของกระทรวง กรม จังหวัด และองค์กรปกครองส่วนท้องถิ่นให้มีหน้าที่ตามกฎหมายอย่างชัดเจน

หลักการสำคัญของกฎหมายใหม่ควรกำหนดว่า ทุกโครงการและมาตรการภายใต้กฎหมายนี้ต้องผ่านหลักร่วม 3 ประการ ได้แก่ หนึ่ง ต้องลดความเสี่ยงล่วงหน้า สอง ต้องใช้ข้อมูลผังภูมินิเวศ ข้อมูลความเปราะบาง และข้อมูลความเสี่ยงของพื้นที่เป็นฐาน และสาม ต้องไม่สร้างความเสี่ยงใหม่ในอนาคต ไม่ว่าจะเป็นการเพิ่มการตั้งถิ่นฐานในพื้นที่เสี่ยง การกีดขวางทางน้ำ การทำลายระบบนิเวศ หรือการฟื้นฟูโครงสร้างพื้นฐานกลับไปสู่ความเปราะบางเดิม

## 1\. กลไกใหม่หรือโครงสร้างใหม่ที่ควรเพิ่มเข้ามา

พ.ร.บ. ฉบับแก้ไขควรเพิ่มกลไกใหม่ที่ทำให้การลดความเสี่ยงภัยพิบัติเป็นภารกิจปกติของหลายหน่วยงาน ไม่ใช่ภารกิจของกรมป้องกันและบรรเทาสาธารณภัยเพียงหน่วยงานเดียว โดยยังให้กรมป้องกันและบรรเทาสาธารณภัยเป็นหน่วยประสานหลักของระบบ แต่กำหนดเจ้าภาพเฉพาะด้านให้ชัดเจน

ตารางที่ 1 กลไกใหม่และขีดความสามารถที่เพิ่มขึ้น

| กลไกใหม่ | เจ้าภาพหลัก | ขีดความสามารถที่เพิ่มขึ้น |
| :---- | :---- | :---- |
| DRR no-regret | ปภ. / มหาดไทย | ทำงานป้องกันและเตรียมพร้อมได้ก่อนเกิดภัย โดยใช้งบปกติ งบฟังก์ชัน งบจังหวัด และงบท้องถิ่นเป็นฐาน |
| Climate adaptation | ทส. / DCCE | มองความเสี่ยงระยะยาวจากภูมิอากาศและลดความเปราะบางของพื้นที่ |
| กองทุนภัยพิบัติ | กระทรวงการคลัง / กรมบัญชีกลาง / สำนักงบประมาณ | อุดช่องว่างเมื่อจำเป็นต้องป้องกันเร่งด่วน แต่งบปกติหรือเงินทดรองราชการใช้ไม่ได้หรือไม่ทัน |
| ปฏิบัติการระดับพื้นที่ | สถ. / จังหวัด / อำเภอ / อปท. | แปลงข้อมูลความเสี่ยงเป็นแผน ข้อบัญญัติ งบประมาณ และมาตรการจริงในพื้นที่ |
| ข้อมูลความเสี่ยงและผังภูมินิเวศ | ปภ. ร่วมกับหน่วยงานข้อมูลรายสาขา | ตัดสินใจจากข้อมูลพื้นที่จริง เช่น ผังน้ำ ผังเมือง ผังภูมินิเวศ กลุ่มเปราะบาง และทรัพยากร |
| Anticipatory action | ปภ. / จังหวัด / หน่วยเทคนิค | สั่งการและใช้มาตรการล่วงหน้าเมื่อ trigger ถึงเกณฑ์ |
| Build Back Better | สำนักงบประมาณ / มหาดไทย / เจ้าภาพด้านโครงสร้างพื้นฐาน | ฟื้นฟูโดยไม่กลับไปสู่ความเสี่ยงเดิม |

กลไกใหม่ที่ควรเพิ่มเข้ามา มีดังนี้

- **กลไก DRR no-regret** โดยให้กรมป้องกันและบรรเทาสาธารณภัยเป็นเจ้าภาพหลักในการขับเคลื่อนมาตรการลดความเสี่ยงที่ทำแล้วคุ้มค่า แม้ภัยจะไม่เกิดขึ้นตามคาด เช่น ระบบเตือนภัยชุมชน แผนอพยพ เส้นทางอพยพ จุดปลอดภัย ศูนย์พักพิง การซ้อมแผน การเปิดทางน้ำหลาก การเตรียมทรัพยากรฉุกเฉิน และการดูแลกลุ่มเปราะบางล่วงหน้า ทั้งนี้ มาตรการ DRR no-regret ไม่ควรพึ่งพางบกลางหรือกองทุนภัยพิบัติเป็นหลัก แต่ควรถูกบรรจุไว้ในงบประมาณปกติ งบฟังก์ชันของกระทรวง/กรม งบจังหวัด และงบท้องถิ่น ส่วนกองทุนภัยพิบัติควรใช้เฉพาะกรณีจำเป็น เร่งด่วน หรือกรณีที่ต้องป้องกันล่วงหน้าแต่ไม่สามารถใช้งบปกติหรือเงินทดรองราชการได้  
    
- **กลไกการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ** โดยให้กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม โดยเฉพาะกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม เป็นเจ้าภาพด้านข้อมูลความเสี่ยงจากสภาพภูมิอากาศ การประเมินความเปราะบาง แผนปรับตัวระดับพื้นที่ และเกณฑ์โครงการ climate adaptation เพื่อรองรับความเสี่ยงระยะยาว เช่น น้ำท่วม ภัยแล้ง คลื่นความร้อน การกัดเซาะชายฝั่ง ดินถล่ม และผลกระทบต่อสุขภาพ เกษตรกรรม และการตั้งถิ่นฐาน  
    
- **กลไกกองทุนภัยพิบัติและการเงินเพื่อการลดความเสี่ยง** โดยให้กระทรวงการคลัง กรมบัญชีกลาง และสำนักงบประมาณเป็นเจ้าภาพด้านกติกาการเงิน การเบิกจ่าย การตรวจสอบ และการจัดสรรงบประมาณ กองทุนควรรองรับการใช้เงินทั้งก่อนเกิดภัย ระหว่างเกิดภัย และหลังเกิดภัย โดยแยกบัญชีย่อยอย่างน้อย 4 ประเภท ได้แก่ บัญชี DRR no-regret บัญชี climate adaptation บัญชี anticipatory action และบัญชี recovery and Build Back Better  
    
- **กลไกปฏิบัติการระดับพื้นที่** โดยให้กรมส่งเสริมการปกครองท้องถิ่น จังหวัด อำเภอ และองค์กรปกครองส่วนท้องถิ่นเป็นหน่วยปฏิบัติจริงในการนำข้อมูลความเสี่ยงไปใช้จัดทำแผนพัฒนาท้องถิ่น ข้อบัญญัติท้องถิ่น แผนป้องกันและบรรเทาสาธารณภัยระดับพื้นที่ แผนอพยพ แผนดูแลกลุ่มเปราะบาง ระบบเตือนภัยชุมชน และโครงการลดความเสี่ยงที่สอดคล้องกับบริบทของพื้นที่  
    
- **กลไกข้อมูลความเสี่ยง ผังภูมินิเวศ และความเปราะบางของพื้นที่** โดยกำหนดให้มีระบบข้อมูลกลางที่เชื่อมโยงข้อมูลภัย ข้อมูลภูมิอากาศ ผังภูมินิเวศ ผังน้ำ ผังเมือง ข้อมูลประชากรเปราะบาง โครงสร้างพื้นฐานสำคัญ และทรัพยากรในพื้นที่ เพื่อใช้เป็นฐานในการจัดทำแผน อนุมัติโครงการ ใช้กองทุน และตัดสินใจดำเนินมาตรการล่วงหน้าก่อนเกิดภัย  
    
- **กลไก anticipatory action หรือการดำเนินการล่วงหน้าก่อนเกิดภัย** โดยกำหนดให้หน่วยงานที่เกี่ยวข้องสามารถดำเนินมาตรการและใช้เงินได้ก่อนเกิดความเสียหาย เมื่อข้อมูลเตือนภัยหรือเกณฑ์ trigger ถึงระดับที่กำหนด เช่น ฝนสะสมสูง ระดับน้ำเพิ่มขึ้น พายุเข้า คลื่นความร้อน หรือภัยแล้งรุนแรง  
    
- **กลไกมาตรการเชิงโครงสร้างและไม่ใช่เชิงโครงสร้าง** โดยให้การป้องกันและบรรเทาสาธารณภัยครอบคลุมทั้งมาตรการเชิงโครงสร้าง เช่น ระบบระบายน้ำ พื้นที่หน่วงน้ำ ศูนย์พักพิง อาคารปลอดภัย ถนนและสะพานที่ไม่กีดขวางทางน้ำ และมาตรการไม่ใช่เชิงโครงสร้าง เช่น ผังเมือง ข้อบัญญัติท้องถิ่น ระบบเตือนภัย การซ้อมแผน แผนอพยพ การสื่อสารความเสี่ยง และการคุ้มครองกลุ่มเปราะบาง  
    
- **กลไกฟื้นฟูแบบ Build Back Better** โดยกำหนดให้การฟื้นฟูหลังภัยพิบัติต้องไม่ใช่เพียงการซ่อมแซมให้กลับไปสู่สภาพเดิม แต่ต้องลดความเสี่ยงในอนาคต เช่น การซ่อมถนนไม่ให้กีดขวางทางน้ำ การยกระดับอาคารสาธารณะในพื้นที่น้ำท่วม การปรับปรุงศูนย์พักพิงให้รองรับผู้สูงอายุและผู้พิการ และการฟื้นฟูระบบนิเวศที่ช่วยลดผลกระทบจากภัยพิบัติ

## 2\. การคงไว้ซึ่งกลไกอำนาจในการบัญชาการเหตุฉุกเฉิน

แม้กฎหมายฉบับใหม่ควรเพิ่มกลไกด้านการลดความเสี่ยง การปรับตัว และกองทุนภัยพิบัติ แต่กลไกอำนาจในการบัญชาการเหตุฉุกเฉินยังจำเป็นต้องคงไว้ เนื่องจากในสถานการณ์ภัยพิบัติจริงจำเป็นต้องมีผู้มีอำนาจสั่งการที่ชัดเจน สามารถตัดสินใจได้รวดเร็ว ระดมทรัพยากร ขอสรรพกำลัง อพยพประชาชน ควบคุมพื้นที่อันตราย และประสานงานหน่วยงานต่าง ๆ ได้อย่างเป็นเอกภาพ

อย่างไรก็ตาม กฎหมายใหม่ควรทำให้ระบบบัญชาการเหตุฉุกเฉินไม่ใช่ระบบที่เริ่มทำงานเมื่อเกิดความเสียหายแล้วเท่านั้น แต่ต้องเชื่อมกับระบบลดความเสี่ยงล่วงหน้า ระบบข้อมูลความเสี่ยง และกลไก anticipatory action โดยกำหนดให้ผู้บัญชาการเหตุการณ์ในแต่ละระดับสามารถสั่งการล่วงหน้าได้เมื่อข้อมูลเตือนภัยหรือเกณฑ์ trigger ถึงระดับที่กำหนด เช่น การเตรียมศูนย์พักพิง การอพยพเชิงป้องกัน การเคลื่อนย้ายกลุ่มเปราะบาง การเตรียมเครื่องสูบน้ำ การจัดเตรียมทรัพยากรฉุกเฉิน หรือการเปิดศูนย์บัญชาการล่วงหน้า

กฎหมายควรกำหนดให้การบัญชาการเหตุฉุกเฉินใช้ข้อมูลจากระบบกลาง เช่น ผังน้ำ ข้อมูลพื้นที่เสี่ยง ข้อมูลกลุ่มเปราะบาง เส้นทางอพยพ จุดปลอดภัย บัญชีทรัพยากร และข้อมูลพยากรณ์หรือเตือนภัยจากหน่วยงานเทคนิค เพื่อให้การตัดสินใจของผู้บัญชาการเหตุการณ์อิงกับข้อมูลที่ทันเวลาและสะท้อนความเสี่ยงจริงของพื้นที่

นอกจากนี้ ควรกำหนดให้มี “หน่วยเทคนิคสนับสนุนผู้บัญชาการเหตุการณ์” ในระดับชาติและระดับพื้นที่ โดยให้หน่วยงาน เช่น กรมอุตุนิยมวิทยา สำนักงานทรัพยากรน้ำแห่งชาติ กรมชลประทาน กรมทรัพยากรน้ำ กรมทรัพยากรธรณี กรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม และสำนักงานนโยบายและแผนทรัพยากรธรรมชาติและสิ่งแวดล้อม ส่งข้อมูล วิเคราะห์สถานการณ์ และให้คำแนะนำตามกรอบเวลาและมาตรฐานที่กฎหมายกำหนด

ดังนั้น การแก้ไขกฎหมายไม่ควรเป็นการลดทอนอำนาจบัญชาการเดิม แต่ควรทำให้กลไกบัญชาการเหตุฉุกเฉินมีข้อมูล มีเครื่องมือ มีงบประมาณ และมีอำนาจดำเนินการล่วงหน้าได้มากขึ้น โดยระบบ DRR no-regret และ climate adaptation ทำหน้าที่ลดความเสี่ยงก่อนเกิดภัย ส่วนระบบบัญชาการเหตุฉุกเฉินทำหน้าที่บริหารสถานการณ์เมื่อภัยใกล้เกิดหรือเกิดขึ้นแล้ว

## 3\. บทบาทที่ชัดเจนของกระทรวงและกรมที่ต้องทำงานสนับสนุน

พ.ร.บ. ฉบับแก้ไขควรกำหนดบทบาทของกระทรวงและกรมที่เกี่ยวข้องให้ชัดเจนในฐานะ “หน้าที่ตามกฎหมาย” ไม่ใช่เพียงการให้ความร่วมมือทั่วไป เพื่อให้หน่วยงานรายสาขาต้องจัดทำข้อมูล แผน มาตรการ งบประมาณ และรายงานผลที่เกี่ยวข้องกับการลดความเสี่ยงภัยพิบัติตามภารกิจของตนเอง

ตารางที่ 2 หน่วยงานหลักและหน้าที่ตามกฎหมายที่ควรกำหนด

| หน่วยงาน/กลุ่มหน่วยงาน | บทบาทหลัก | หน้าที่ที่ควรกำหนดในกฎหมาย |
| :---- | :---- | :---- |
| ปภ. / กระทรวงมหาดไทย | ประสานระบบ DRR และบัญชาการเหตุฉุกเฉิน | มาตรฐานแผน DRR no-regret การซ้อมแผน ระบบเตือนภัยระดับพื้นที่ การประสานบัญชาการเหตุฉุกเฉิน |
| สถ. / จังหวัด / อำเภอ / อปท. | หน่วยปฏิบัติพื้นที่ | แปลงข้อมูลความเสี่ยงเป็นแผนพัฒนาท้องถิ่น ข้อบัญญัติ งบประมาณ แผนอพยพ ระบบเตือนภัยชุมชน และโครงการลดความเสี่ยง |
| ทส. / DCCE | เจ้าภาพ climate adaptation | ข้อมูล climate risk แผนปรับตัว ความเปราะบางของพื้นที่ และเกณฑ์โครงการ climate adaptation |
| สผ. | ผังภูมินิเวศและระบบนิเวศ | เชื่อมผังภูมินิเวศ พื้นที่เปราะบาง มาตรการคุ้มครองสิ่งแวดล้อม และ ecosystem-based DRR |
| สทนช. / กรมชลประทาน / กรมทรัพยากรน้ำ / กรมทรัพยากรน้ำบาดาล | น้ำท่วม ภัยแล้ง และผังน้ำ | ผังน้ำ ลุ่มน้ำ ทางน้ำหลาก พื้นที่รับน้ำ พื้นที่หน่วงน้ำ สถานการณ์น้ำ และ trigger น้ำท่วม-ภัยแล้ง |
| กรมอุตุนิยมวิทยา | ข้อมูลพยากรณ์และเตือนภัย | พยากรณ์อากาศ คำเตือนภัย พายุ ฝนสะสม คลื่นความร้อน และข้อมูลประกอบ anticipatory action |
| กรมทรัพยากรธรณี | ธรณีพิบัติภัย | ข้อมูลพื้นที่เสี่ยงดินถล่ม แผ่นดินไหว หลุมยุบ พื้นที่ลาดชัน และเกณฑ์เฝ้าระวัง |
| กรมโยธาธิการและผังเมือง / กรมที่ดิน / อปท. | ผังเมือง ที่ดิน อาคาร และศูนย์พักพิง | risk zoning มาตรฐานอาคาร ข้อกำหนดการใช้ที่ดิน พื้นที่กันชน เส้นทางอพยพ และศูนย์พักพิง |
| กระทรวงการคลัง / กรมบัญชีกลาง / สำนักงบประมาณ | กองทุนและกลไกการเงิน | กติกาเงิน งบปกติ งบฟังก์ชัน กองทุนภัยพิบัติ การเบิกจ่าย การตรวจสอบ และการติดตามผลลัพธ์ |
| เกษตรฯ / อุตสาหกรรม / สาธารณสุข / พม. / ศึกษาธิการ / แรงงาน / คมนาคม | หน่วยงานรายสาขา | จัดทำข้อมูล แผน มาตรการ และงบประมาณตามภารกิจ เช่น เกษตรปลอดภัย โรงงานและสารเคมี สุขภาพ กลุ่มเปราะบาง โรงเรียนปลอดภัย แรงงาน และโลจิสติกส์ฉุกเฉิน |

สาระสำคัญของหมวดนี้คือ การกำหนดให้หน่วยงานรายสาขาเป็น “เจ้าของภารกิจลดความเสี่ยงตามหน้าที่ของตน” ไม่ใช่เพียงผู้ช่วยกรมป้องกันและบรรเทาสาธารณภัย กล่าวคือ หน่วยงานด้านน้ำต้องรับผิดชอบข้อมูลและมาตรการน้ำ หน่วยงานด้านภูมิอากาศต้องรับผิดชอบข้อมูลความเสี่ยงและแผนปรับตัว หน่วยงานด้านผังเมืองต้องรับผิดชอบการใช้ข้อมูลความเสี่ยงในผังและมาตรฐานอาคาร และหน่วยงานด้านการคลังต้องรับผิดชอบกติกาการเงินที่ทำให้การลดความเสี่ยงเกิดขึ้นได้จริง

ด้านงบประมาณ กฎหมายควรวางหลักว่า DRR no-regret และ climate adaptation ต้องใช้เงินงบประมาณปกติ งบฟังก์ชัน งบจังหวัด และงบท้องถิ่นเป็นฐานก่อน ส่วนกองทุนภัยพิบัติเป็นกลไกเสริมสำหรับกรณีจำเป็น เร่งด่วน ข้ามหน่วยงาน หรือไม่สามารถใช้งบปกติและเงินทดรองราชการได้ทันการณ์

## 4\. หมวดใน พ.ร.บ. ปภ. ที่ควรปรับ เพิ่ม หรือแก้

การปรับปรุง พ.ร.บ. ป้องกันและบรรเทาสาธารณภัยควรปรับโครงสร้างหมวดกฎหมายให้รองรับภารกิจใหม่อย่างเป็นระบบ โดยลำดับหมวดควรสะท้อนตรรกะของกฎหมายใหม่ คือ เริ่มจากนิยามและกลไกนโยบาย ตามด้วยหน้าที่ของหน่วยงาน ข้อมูลความเสี่ยง แผน มาตรการล่วงหน้า กองทุน การฟื้นฟู และการติดตามผล

| :---- | :---- | :---- |

| ข้อมูลความเสี่ยง ผังภูมินิเวศ และความเปราะบาง | จัดทำฐานข้อมูลกลางด้านภัยพิบัติ ภูมิอากาศ ผังน้ำ ผังเมือง กลุ่มเปราะบาง และทรัพยากร | ให้ทุกแผนและทุกโครงการใช้ข้อมูลพื้นที่จริงเป็นฐาน |
| แผนลดความเสี่ยง การเตรียมพร้อม และการปรับตัว | บังคับให้แผนทุกระดับมี DRR no-regret, climate adaptation, anticipatory action และการดูแลกลุ่มเปราะบาง | ยกระดับแผนจากแผนเผชิญเหตุเป็นแผนลดความเสี่ยงทั้งวงจร |
| การเตือนภัย การสื่อสารความเสี่ยง และ anticipatory action | กำหนด trigger และอำนาจดำเนินมาตรการล่วงหน้า เช่น อพยพเชิงป้องกัน เปิดศูนย์พักพิง เตรียมเครื่องสูบน้ำ | ทำให้รัฐสามารถป้องกันก่อนเกิดความเสียหาย |
| กองทุนลดความเสี่ยงและฟื้นฟูภัยพิบัติ | กำหนดบัญชีย่อย DRR no-regret, climate adaptation, anticipatory/emergency และ recovery and Build Back Better | อุดช่องว่างด้านการเงิน แต่ไม่แทนงบปกติของหน่วยงาน |
| มาตรการเชิงโครงสร้างและไม่ใช่เชิงโครงสร้าง | ครอบคลุมโครงสร้างพื้นฐาน ผังเมือง อาคารปลอดภัย ระบบน้ำ เตือนภัย ซ้อมแผน แผนอพยพ และข้อบัญญัติท้องถิ่น | ทำให้มาตรการลดความเสี่ยงครบทั้ง hard และ soft measures |
| การฟื้นฟูแบบ Build Back Better | กำหนดว่าการฟื้นฟูต้องไม่ซ่อมกลับไปสู่ความเสี่ยงเดิม | ลดความเสี่ยงซ้ำหลังเกิดภัย |
| ติดตาม ประเมินผล และความรับผิดชอบ | วัดผลจากการลดความเสี่ยง เช่น พื้นที่เสี่ยงที่ได้รับการจัดการ ชุมชนที่ซ้อมแผน กลุ่มเปราะบางที่มีแผนอพยพ และโครงการที่ไม่สร้างความเสี่ยงใหม่ | ทำให้กฎหมายมุ่งผลลัพธ์ ไม่ใช่รายงานเพียงงบประมาณหรือการช่วยเหลือ |

จุดสำคัญของหมวดกองทุนคือ ต้องไม่เขียนให้กองทุนกลายเป็นช่องทางหลักของทุกโครงการ DRR no-regret เพราะจะทำให้หน่วยงานรอเงินกองทุนแทนที่จะใช้งบปกติของตนเอง กฎหมายควรบัญญัติให้ชัดว่า มาตรการลดความเสี่ยงล่วงหน้าและ DRR no-regret ให้ใช้เงินงบประมาณปกติ งบฟังก์ชัน งบจังหวัด และงบท้องถิ่นเป็นหลัก ส่วนกองทุนภัยพิบัติให้ใช้เพื่ออุดช่องว่างในกรณีจำเป็น เร่งด่วน ข้ามหน่วยงาน หรือไม่สามารถใช้เงินทดรองราชการและงบปกติได้ทันการณ์

การติดตามประเมินผลควรวัดจาก “ขีดความสามารถที่เพิ่มขึ้น” เช่น จังหวัดและ อปท. มีแผนและซ้อมแผนครบหรือไม่ ระบบเตือนภัยเข้าถึงกลุ่มเปราะบางหรือไม่ มี trigger ที่เปิดใช้มาตรการล่วงหน้าได้จริงหรือไม่ งบปกติของกระทรวง/กรมมี DRR no-regret หรือไม่ โครงการฟื้นฟูลดความเสี่ยงเดิมได้จริงหรือไม่ และพื้นที่เสี่ยงได้รับการจัดการลดความเปราะบางหรือไม่

พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ควรวางให้กรมป้องกันและบรรเทาสาธารณภัยเป็นแกนประสานระบบ DRR และการบัญชาการเหตุฉุกเฉิน แต่ต้องกำหนดหน้าที่ของกระทรวงและกรมรายสาขาให้ชัดเจน เพื่อให้การลดความเสี่ยงภัยพิบัติ การปรับตัวต่อสภาพภูมิอากาศ การใช้กองทุน และการปฏิบัติระดับพื้นที่เป็นภารกิจร่วมของทั้งระบบราชการ ท้องถิ่น ชุมชน และภาคส่วนที่เกี่ยวข้อง ไม่ใช่ภารกิจของหน่วยงานใดหน่วยงานหนึ่งเพียงลำพัง

## 5\. เพิ่มหมวดใหม่ต่อท้ายจากหมวดและมาตราเดิม

หากการปรับปรุง พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ใช้วิธี “แก้ไขเพิ่มเติม” โดยไม่รื้อโครงสร้างกฎหมายเดิมทั้งฉบับ ควรคงหมวดและมาตราเดิมไว้เป็นฐาน โดยเฉพาะกลไกคณะกรรมการ แผนป้องกันและบรรเทาสาธารณภัย อำนาจของผู้อำนวยการแต่ละระดับ เจ้าพนักงาน อาสาสมัคร และบทกำหนดโทษ แล้วเพิ่มหมวดใหม่ต่อท้ายเพื่อรองรับภารกิจที่กฎหมายเดิมยังไม่ครอบคลุม ได้แก่ การลดความเสี่ยงล่วงหน้า การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การใช้ข้อมูลผังภูมินิเวศและความเปราะบาง การดำเนินการล่วงหน้าก่อนเกิดภัย กองทุนภัยพิบัติ และการฟื้นฟูแบบไม่สร้างความเสี่ยงซ้ำ

แนวทางนี้มีข้อดีคือไม่กระทบโครงสร้างการบัญชาการเหตุฉุกเฉินเดิม แต่เพิ่มกลไกใหม่ที่ทำงาน “ก่อนเกิดภัย” และ “หลังเกิดภัยอย่างยืดหยุ่น” เข้าไปในกฎหมาย ทำให้ พ.ร.บ. ปภ. ฉบับใหม่สามารถขยายขอบเขตจากกฎหมายจัดการเหตุฉุกเฉิน ไปสู่กฎหมายกำกับระบบลดความเสี่ยงภัยพิบัติทั้งวงจรได้อย่างเป็นรูปธรรม โดยควรเพิ่มหมวดใหม่ต่อท้ายจากหมวดและมาตราเดิม ดังนี้

| หมวดใหม่ที่ควรเพิ่ม | ชื่อหมวด | สาระสำคัญ |
| :---- | :---- | :---- |
| หมวด 7 | หน้าที่ของหน่วยงาน แผนลดความเสี่ยง การเตรียมพร้อม และการปรับตัว | กำหนดให้หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น และหน่วยงานที่เกี่ยวข้องมีหน้าที่ตามกฎหมายในการจัดทำหรือสนับสนุนข้อมูล แผน มาตรการ งบประมาณ และการดำเนินงานด้านการลดความเสี่ยงภัยพิบัติตามอำนาจหน้าที่ของตน โดยให้แผนป้องกันและบรรเทาสาธารณภัยทุกระดับครอบคลุม DRR no-regret, climate adaptation, การเตรียมพร้อม, การดูแลกลุ่มเปราะบาง และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ |
| หมวด 8 | ระบบข้อมูลความเสี่ยง การเตือนภัย และการดำเนินการล่วงหน้าก่อนเกิดภัย | กำหนดให้มีระบบข้อมูลกลางด้านความเสี่ยงภัยพิบัติ ผังภูมินิเวศ ผังน้ำ ผังเมือง ความเปราะบาง กลุ่มเปราะบาง และทรัพยากรในพื้นที่ เพื่อใช้ประกอบการจัดทำแผน การเตือนภัย การสื่อสารความเสี่ยง และการดำเนินมาตรการล่วงหน้าก่อนเกิดภัยเมื่อข้อมูลเตือนภัยหรือเกณฑ์ trigger ถึงระดับที่กำหนด |
| หมวด 9 | งบประมาณและกองทุนลดความเสี่ยงและฟื้นฟูภัยพิบัติ | กำหนดหลักการใช้งบประมาณ โดยให้มาตรการ DRR no-regret และ climate adaptation ใช้งบประมาณปกติ งบฟังก์ชัน งบจังหวัด และงบท้องถิ่นเป็นฐานก่อน ส่วนกองทุนภัยพิบัติให้เป็นกลไกเสริมสำหรับกรณีจำเป็น เร่งด่วน ข้ามหน่วยงาน ข้ามพื้นที่ หรือกรณีที่ไม่สามารถใช้งบปกติหรือเงินทดรองราชการได้ทันการณ์ |
| หมวด 10 | มาตรการลดความเสี่ยงและการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ | กำหนดให้การป้องกันและบรรเทาสาธารณภัยครอบคลุมทั้งมาตรการเชิงโครงสร้างและมาตรการไม่ใช่เชิงโครงสร้าง รวมถึงกำหนดหลักการฟื้นฟูภายหลังภัยพิบัติให้ไม่ซ่อมกลับไปสู่ความเปราะบางเดิม แต่ต้องใช้ข้อมูลความเสี่ยงประกอบการฟื้นฟู เพื่อเพิ่มความปลอดภัย ความยืดหยุ่น และขีดความสามารถของพื้นที่ |
| หมวด 11 | การติดตาม ประเมินผล และความรับผิดชอบ | กำหนดให้มีการติดตามและประเมินผลจากผลลัพธ์ด้านการลดความเสี่ยงและขีดความสามารถที่เพิ่มขึ้น ไม่ใช่เพียงจำนวนงบประมาณที่ใช้หรือจำนวนผู้ได้รับความช่วยเหลือ โดยให้ครอบคลุมความพร้อมของแผน การซ้อมแผน ระบบเตือนภัย การเข้าถึงกลุ่มเปราะบาง การใช้ข้อมูลความเสี่ยง การดำเนินมาตรการล่วงหน้า และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ |

การเพิ่มหมวด 7–11 ต่อท้ายกฎหมายเดิมควรจัดลำดับตามตรรกะของการทำงานทั้งระบบ ตั้งแต่การกำหนดว่า “ใครต้องทำ” การใช้ข้อมูลความเสี่ยงและผังภูมินิเวศเป็นฐาน การจัดทำแผน การเตือนภัยและดำเนินมาตรการล่วงหน้า การใช้กลไกงบประมาณและกองทุน การดำเนินมาตรการเชิงโครงสร้างและไม่ใช่เชิงโครงสร้าง การฟื้นฟู และการติดตามประเมินผล แม้ในเชิงเทคนิคทางกฎหมาย การเพิ่มหมวดใหม่ต่อท้ายอาจทำให้บทกำหนดโทษของกฎหมายเดิมไม่ได้อยู่ท้ายสุด แต่เป็นแนวทางที่เหมาะสมหากต้องการแก้ไขเพิ่มเติมโดยไม่รื้อโครงสร้าง พ.ร.บ. เดิมทั้งหมด ทั้งนี้ สาระสำคัญของหมวดใหม่ไม่ใช่การซ้ำซ้อนกับกลไกบัญชาการเหตุฉุกเฉินเดิม แต่เป็นการเติมเต็มช่องว่างของระบบเดิมในด้านการลดความเสี่ยงก่อนเกิดภัย ข้อมูลพื้นที่ การปรับตัวต่อสภาพภูมิอากาศ การใช้เงินเพื่อป้องกันล่วงหน้า และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ โดยยังคงรักษากลไกบัญชาการเหตุฉุกเฉินไว้ พร้อมเพิ่มโครงสร้างกฎหมายที่รองรับการลดความเสี่ยงภัยพิบัติทั้งวงจร ภายใต้หลักร่วมว่า ทุกโครงการต้องลดความเสี่ยงล่วงหน้า ใช้ข้อมูลผังภูมินิเวศและความเปราะบางเป็นฐาน และไม่สร้างความเสี่ยงใหม่ในอนาคต

## 6\. แนวทางการแก้ไขเพิ่มเติมบทบัญญัติรายมาตรา

จากข้อเสนอเชิงโครงสร้างข้างต้น การแก้ไขเพิ่มเติม พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ควรดำเนินการในลักษณะ “แก้ไขมาตราเดิมที่เป็นฐานของระบบ” ควบคู่กับ “เพิ่มบทบัญญัติใหม่” เพื่อให้กฎหมายรองรับการลดความเสี่ยงภัยพิบัติทั้งวงจร โดยไม่จำเป็นต้องรื้อกลไกบัญชาการเหตุฉุกเฉินเดิมทั้งหมด แนวทางรายมาตราจึงควรมุ่งปรับถ้อยคำให้กว้างพอสำหรับการดำเนินงานของหลายหน่วยงาน แต่ชัดเจนพอที่จะกำหนดหน้าที่ตามกฎหมายในเรื่องการลดความเสี่ยงล่วงหน้า การใช้ข้อมูลความเสี่ยงและผังภูมินิเวศ การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การใช้กลไกงบประมาณและกองทุน และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ ทั้งนี้ รายละเอียดเชิงปฏิบัติสามารถกำหนดต่อในแผนป้องกันและบรรเทาสาธารณภัยแห่งชาติ ระเบียบ ประกาศ หรือหลักเกณฑ์ที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

จากข้อเสนอเชิงโครงสร้างข้างต้น การแก้ไขเพิ่มเติม พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย ฉบับแก้ไข พ.ศ. 2570 ควรดำเนินการในลักษณะ “แก้ไขมาตราเดิมที่เป็นฐานของระบบ” ควบคู่กับ “เพิ่มหมวดใหม่ต่อท้ายกฎหมายเดิม” โดยไม่รื้อกลไกบัญชาการเหตุฉุกเฉินเดิมทั้งหมด แต่เพิ่มบทบัญญัติที่ทำให้กฎหมายรองรับการลดความเสี่ยงภัยพิบัติล่วงหน้า การเตรียมพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การใช้ข้อมูลความเสี่ยงและผังภูมินิเวศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การใช้กลไกงบประมาณและกองทุน และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ แนวทางรายมาตราจึงควรเขียนเป็นบทบัญญัติกว้างในลักษณะกฎหมายแม่บท โดยกำหนดหลักการ อำนาจ หน้าที่ กลไก และกรอบความรับผิดชอบ ส่วนรายละเอียดเชิงปฏิบัติ เช่น รายชื่อหน่วยงานเฉพาะ รายการข้อมูล เกณฑ์เตือนภัย รูปแบบรายงาน ประเภทโครงการ หรือวิธีการเบิกจ่าย ให้กำหนดต่อในแผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ ระเบียบ ประกาศ หรือหลักเกณฑ์ที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

### 6.1 บทบัญญัติเดิมที่ควรแก้ไขเพิ่มเติม

#### มาตรา 4 บทนิยาม

ควรแก้ไขเพิ่มเติมบทนิยามให้ครอบคลุมถ้อยคำสำคัญที่จำเป็นต่อการลดความเสี่ยงภัยพิบัติทั้งวงจร ได้แก่ “การลดความเสี่ยงภัยพิบัติ” “การเตรียมความพร้อม” “การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ” “การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย” “ความเปราะบาง” “กลุ่มเปราะบาง” “ผังภูมินิเวศ” “ข้อมูลความเสี่ยง” และ “การฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ”

การเพิ่มนิยามดังกล่าวมีวัตถุประสงค์เพื่อขยายขอบเขตของกฎหมายจากการจัดการเมื่อเกิดสาธารณภัย ไปสู่การป้องกัน ลดความเสี่ยง เตรียมพร้อม และฟื้นฟูอย่างยั่งยืน

#### มาตรา 7 อำนาจหน้าที่ของคณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติ

ควรแก้ไขเพิ่มเติมอำนาจหน้าที่ของคณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติ ให้ครอบคลุมการกำหนดนโยบาย หลักเกณฑ์ มาตรฐาน และแนวทางเกี่ยวกับการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ ระบบข้อมูลความเสี่ยง การเตือนภัย การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การใช้กองทุน และการติดตามผลลัพธ์ด้านการลดความเสี่ยง

การแก้ไขมาตรานี้ควรมุ่งให้ กปภ.ช. เป็นกลไกกำกับเชิงนโยบายของระบบลดความเสี่ยงภัยพิบัติทั้งวงจร ไม่ใช่กำกับเฉพาะแผนและการบูรณาการเมื่อเกิดภัยเท่านั้น

#### มาตรา 11 อำนาจหน้าที่ของกรมป้องกันและบรรเทาสาธารณภัย

ควรแก้ไขเพิ่มเติมให้กรมป้องกันและบรรเทาสาธารณภัยเป็นหน่วยงานกลางในการประสาน สนับสนุน และติดตามการดำเนินงานด้านการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การเตือนภัย การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย และการสนับสนุนการบัญชาการเหตุฉุกเฉิน ร่วมกับหน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น และหน่วยงานอื่นที่เกี่ยวข้อง

การแก้ไขมาตรานี้ไม่ควรกำหนดให้กรมป้องกันและบรรเทาสาธารณภัยเป็นผู้ดำเนินงานทุกภารกิจโดยลำพัง แต่ควรวางบทบาทให้เป็นหน่วยประสานกลางของระบบ และให้หน่วยงานรายสาขาดำเนินการตามอำนาจหน้าที่ของตน

#### มาตรา 12 สาระสำคัญของแผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ

ควรแก้ไขเพิ่มเติมให้แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติต้องครอบคลุมการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ ระบบข้อมูลความเสี่ยง การเตือนภัย การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การคุ้มครองกลุ่มเปราะบาง การใช้กลไกงบประมาณและกองทุน และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ

แผนดังกล่าวควรเป็นกรอบกลางที่กำหนดบทบาทของหน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น ภาคเอกชน ชุมชน และหน่วยงานอื่นที่เกี่ยวข้อง ให้ดำเนินการสอดคล้องกับระดับความเสี่ยง ประเภทภัย และขีดความสามารถของพื้นที่

#### มาตรา 15 และมาตรา 16 อำนาจหน้าที่ของผู้อำนวยการจังหวัดและแผนจังหวัด

ควรแก้ไขเพิ่มเติมให้ผู้อำนวยการจังหวัดและแผนการป้องกันและบรรเทาสาธารณภัยจังหวัดมีอำนาจและหน้าที่ครอบคลุมการลดความเสี่ยงล่วงหน้า การใช้ข้อมูลความเสี่ยงและความเปราะบางของพื้นที่ การกำหนดมาตรการเตรียมพร้อม การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การคุ้มครองกลุ่มเปราะบาง และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ

การแก้ไขควรกำหนดให้จังหวัดสามารถประสานและสั่งการหน่วยงานในพื้นที่เพื่อดำเนินมาตรการล่วงหน้าก่อนเกิดภัยได้ เมื่อมีข้อมูลเตือนภัยหรือเกณฑ์ที่กำหนดบ่งชี้ถึงความเสี่ยงที่อาจก่อให้เกิดอันตรายแก่ประชาชนหรือระบบสาธารณูปโภคสำคัญ

#### มาตรา 20 และมาตรา 21 อำนาจหน้าที่ของผู้อำนวยการท้องถิ่น

ควรแก้ไขเพิ่มเติมให้ผู้อำนวยการท้องถิ่นมีหน้าที่นำข้อมูลความเสี่ยง ความเปราะบางของพื้นที่ และข้อมูลกลุ่มเปราะบาง ไปใช้ประกอบการจัดทำแผนป้องกันและบรรเทาสาธารณภัยระดับท้องถิ่น แผนอพยพ ระบบเตือนภัย จุดปลอดภัย ศูนย์พักพิง และมาตรการลดความเสี่ยงที่เหมาะสมกับพื้นที่

ควรกำหนดให้ท้องถิ่นสามารถดำเนินมาตรการเตรียมพร้อมและมาตรการล่วงหน้าก่อนเกิดภัยตามแผนและตามหลักเกณฑ์ที่กำหนด โดยคำนึงถึงความปลอดภัยของประชาชน สิทธิของประชาชน และการไม่ก่อให้เกิดความเสี่ยงใหม่

#### มาตรา 32 และมาตรา 33 การป้องกันและบรรเทาสาธารณภัยในเขตกรุงเทพมหานคร

ควรแก้ไขเพิ่มเติมให้การจัดทำแผนและการดำเนินงานในเขตกรุงเทพมหานครครอบคลุมการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การใช้ข้อมูลความเสี่ยงของเมือง การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดูแลกลุ่มเปราะบาง การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ เช่นเดียวกับแผนระดับจังหวัดและระดับท้องถิ่นอื่น

### 6.2 บทบัญญัติใหม่ที่ควรเพิ่มต่อท้ายกฎหมายเดิม

#### หมวด 7 หน้าที่ของหน่วยงาน แผนลดความเสี่ยง การเตรียมพร้อม และการปรับตัว

##### มาตรา 59

ให้หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น รัฐวิสาหกิจ และหน่วยงานอื่นของรัฐที่มีภารกิจเกี่ยวข้องกับการป้องกันและบรรเทาสาธารณภัย มีหน้าที่ดำเนินการหรือสนับสนุนการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การเผชิญเหตุ และการฟื้นฟูภายหลังภัยพิบัติ ตามอำนาจหน้าที่ของตน

การดำเนินการตามวรรคหนึ่ง ให้คำนึงถึงการลดความเสี่ยงล่วงหน้า การใช้ข้อมูลความเสี่ยงของพื้นที่ ผังภูมินิเวศ ความเปราะบางของประชาชนและระบบสาธารณูปโภค และการไม่ก่อให้เกิดความเสี่ยงใหม่ในอนาคต

##### มาตรา 60

ให้แผนการป้องกันและบรรเทาสาธารณภัยทุกระดับครอบคลุมการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การเตือนภัย การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การคุ้มครองกลุ่มเปราะบาง และการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ

แผนตามวรรคหนึ่งต้องใช้ข้อมูลความเสี่ยงภัยพิบัติ ผังภูมินิเวศ ความเปราะบางของพื้นที่ ข้อมูลกลุ่มเปราะบาง ข้อมูลทรัพยากร และข้อมูลอื่นที่เกี่ยวข้องเป็นฐาน ทั้งนี้ ตามหลักเกณฑ์ที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

##### มาตรา 61

ให้หน่วยงานของรัฐและองค์กรปกครองส่วนท้องถิ่นบรรจุมาตรการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม และการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศไว้ในแผนงาน โครงการ และงบประมาณตามอำนาจหน้าที่ของตน

มาตรการลดความเสี่ยงภัยพิบัติที่ดำเนินการได้ล่วงหน้าและเป็นประโยชน์ต่อความปลอดภัยของประชาชน หรือการลดความเสียหายของพื้นที่ แม้ภัยพิบัติจะไม่เกิดขึ้นตามที่คาดการณ์ ให้ใช้เงินงบประมาณปกติ งบประมาณตามภารกิจ งบจังหวัด หรืองบประมาณขององค์กรปกครองส่วนท้องถิ่นเป็นหลัก

##### มาตรา 62

เพื่อประโยชน์ในการดำเนินการตามหมวดนี้ คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติอาจกำหนดหลักเกณฑ์ วิธีการ มาตรฐาน หรือแนวทางปฏิบัติเกี่ยวกับการประสานงานระหว่างหน่วยงาน การจัดทำแผน การใช้ข้อมูลความเสี่ยง การจัดทำงบประมาณ การฝึกซ้อม การติดตามผล และการรายงานผลได้

หลักเกณฑ์ วิธีการ มาตรฐาน หรือแนวทางปฏิบัติตามวรรคหนึ่ง อาจกำหนดให้แตกต่างกันตามประเภทภัย ระดับความเสี่ยง ลักษณะพื้นที่ ขีดความสามารถของหน่วยงาน และความจำเป็นในการคุ้มครองประชาชนหรือกลุ่มเปราะบางก็ได้

#### หมวด 8 ระบบข้อมูลความเสี่ยง การเตือนภัย และการดำเนินการล่วงหน้าก่อนเกิดภัย

##### มาตรา 63

เพื่อประโยชน์ในการป้องกันและบรรเทาสาธารณภัย การลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย และการฟื้นฟูภายหลังภัยพิบัติ ให้มีระบบข้อมูลกลางด้านความเสี่ยงภัยพิบัติ ผังภูมินิเวศ และความเปราะบางของพื้นที่

ระบบข้อมูลตามวรรคหนึ่ง ให้เชื่อมโยงข้อมูลจากหน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น และหน่วยงานอื่นที่เกี่ยวข้อง ตามหลักเกณฑ์ วิธีการ มาตรฐาน และระยะเวลาที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

##### มาตรา 64

ให้หน่วยงานของรัฐที่มีภารกิจเกี่ยวข้องกับข้อมูลด้านภัยพิบัติ สภาพภูมิอากาศ ทรัพยากรน้ำ ผังเมือง ที่ดิน ทรัพยากรธรรมชาติ สิ่งแวดล้อม สาธารณสุข โครงสร้างพื้นฐาน เศรษฐกิจ สังคม และประชากร จัดทำ ปรับปรุง สนับสนุน หรือเชื่อมโยงข้อมูลที่จำเป็นต่อระบบข้อมูลกลางตามมาตรา 63 ตามอำนาจหน้าที่ของตน

ในกรณีที่ข้อมูลใดมีความจำเป็นเร่งด่วนต่อการเตือนภัย การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย หรือการบัญชาการเหตุฉุกเฉิน ให้หน่วยงานเจ้าของข้อมูลจัดส่งหรือเปิดให้เข้าถึงข้อมูลดังกล่าวโดยไม่ชักช้า ตามหลักเกณฑ์ที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

##### มาตรา 65

ให้มีระบบการเตือนภัยและการสื่อสารความเสี่ยงที่สามารถแจ้งข้อมูลภัยพิบัติ ความเสี่ยง ผลกระทบที่อาจเกิดขึ้น และแนวทางปฏิบัติที่เหมาะสมแก่หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น ภาคเอกชน ชุมชน และประชาชนได้อย่างทั่วถึง ทันเวลา และเข้าใจได้

การดำเนินการตามวรรคหนึ่ง ให้คำนึงถึงประเภทภัย ระดับความเสี่ยง ลักษณะพื้นที่ ช่องทางการสื่อสารที่เหมาะสม ความสามารถในการเข้าถึงข้อมูลของประชาชน และความจำเป็นในการคุ้มครองกลุ่มเปราะบาง

##### มาตรา 66

เมื่อมีข้อมูลเตือนภัยหรือเกณฑ์ที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด แสดงว่ามีความเสี่ยงที่อาจก่อให้เกิดสาธารณภัย หรืออาจกระทบต่อชีวิต ทรัพย์สิน ระบบสาธารณูปโภค หรือความปลอดภัยของประชาชน ให้ผู้มีอำนาจตามพระราชบัญญัตินี้มีอำนาจสั่งการให้หน่วยงานที่เกี่ยวข้องดำเนินมาตรการล่วงหน้าก่อนเกิดภัยได้เท่าที่จำเป็นและเหมาะสมแก่สถานการณ์

การสั่งการตามวรรคหนึ่งต้องคำนึงถึงความได้สัดส่วน ความจำเป็น ความปลอดภัยของประชาชน สิทธิของประชาชน และข้อมูลความเสี่ยงของพื้นที่เป็นสำคัญ

#### หมวด 9 งบประมาณและกองทุนลดความเสี่ยงและฟื้นฟูภัยพิบัติ

##### มาตรา 67

ให้หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น รัฐวิสาหกิจ และหน่วยงานอื่นของรัฐที่มีภารกิจเกี่ยวข้องกับการป้องกันและบรรเทาสาธารณภัย จัดให้มีแผนงาน โครงการ และงบประมาณเพื่อสนับสนุนการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การเผชิญเหตุ และการฟื้นฟูภายหลังภัยพิบัติ ตามอำนาจหน้าที่ของตน

การจัดทำงบประมาณตามวรรคหนึ่ง ให้คำนึงถึงข้อมูลความเสี่ยงของพื้นที่ ความเปราะบางของประชาชนและระบบสาธารณูปโภค ความจำเป็นในการคุ้มครองกลุ่มเปราะบาง และหลักการไม่ก่อให้เกิดความเสี่ยงใหม่ในอนาคต

##### มาตรา 68

ให้มีกองทุนลดความเสี่ยงและฟื้นฟูภัยพิบัติ เพื่อเป็นกลไกเสริมในการสนับสนุนการดำเนินงานตามพระราชบัญญัตินี้ ในกรณีจำเป็น เร่งด่วน ข้ามหน่วยงาน ข้ามเขตพื้นที่ หรือกรณีที่ไม่สามารถใช้งบประมาณปกติ งบประมาณตามภารกิจ งบจังหวัด งบประมาณขององค์กรปกครองส่วนท้องถิ่น หรือเงินทดรองราชการได้ทันการณ์

กองทุนตามวรรคหนึ่ง มีวัตถุประสงค์เพื่อสนับสนุนการลดความเสี่ยงภัยพิบัติล่วงหน้า การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การเผชิญเหตุในกรณีจำเป็น และการฟื้นฟูภายหลังภัยพิบัติโดยไม่สร้างความเสี่ยงซ้ำ

##### มาตรา 69

หลักเกณฑ์ วิธีการ เงื่อนไข การบริหาร การรับเงิน การจ่ายเงิน การเก็บรักษาเงิน การตรวจสอบ และการรายงานผลของกองทุนตามมาตรา 68 ให้เป็นไปตามระเบียบที่คณะรัฐมนตรีกำหนด โดยข้อเสนอของคณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติ และโดยความเห็นชอบของกระทรวงการคลัง สำนักงบประมาณ และหน่วยงานที่เกี่ยวข้อง

การใช้เงินจากกองทุนต้องมีข้อมูลความเสี่ยงหรือเหตุจำเป็นประกอบ และต้องสอดคล้องกับแผน มาตรการ หรือหลักเกณฑ์ที่กำหนดตามพระราชบัญญัตินี้

#### หมวด 10 มาตรการลดความเสี่ยงและการฟื้นฟูที่ไม่สร้างความเสี่ยงซ้ำ

##### มาตรา 70

เพื่อประโยชน์ในการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การป้องกันความเสียหาย และการเพิ่มขีดความสามารถในการรับมือของพื้นที่ ให้หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น รัฐวิสาหกิจ และหน่วยงานอื่นที่เกี่ยวข้อง ดำเนินมาตรการเชิงโครงสร้างและมาตรการไม่ใช่เชิงโครงสร้างตามอำนาจหน้าที่ของตน

การดำเนินมาตรการตามวรรคหนึ่ง ต้องคำนึงถึงข้อมูลความเสี่ยงภัยพิบัติ ผังภูมินิเวศ ผังน้ำ ผังเมือง ความเปราะบางของพื้นที่ ความปลอดภัยของประชาชน และหลักการไม่ก่อให้เกิดความเสี่ยงใหม่ในอนาคต

##### มาตรา 71

ในกรณีที่การดำเนินโครงการ มาตรการ หรือกิจกรรมใดอาจมีผลให้เกิดความเสี่ยงภัยพิบัติเพิ่มขึ้น หรืออาจกระทบต่อความปลอดภัยของประชาชน ระบบนิเวศ ทางน้ำ พื้นที่รับน้ำ พื้นที่ลาดชัน พื้นที่ชายฝั่ง หรือโครงสร้างพื้นฐานสำคัญ ให้หน่วยงานเจ้าของโครงการหรือหน่วยงานผู้มีอำนาจอนุญาตพิจารณาข้อมูลความเสี่ยงและกำหนดมาตรการป้องกันหรือลดผลกระทบตามความเหมาะสม

หลักเกณฑ์การพิจารณาตามวรรคหนึ่ง ให้เป็นไปตามที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด โดยอาจกำหนดให้สอดคล้องกับกฎหมายว่าด้วยผังเมือง อาคาร สิ่งแวดล้อม ทรัพยากรน้ำ ที่ดิน โรงงาน เหมืองแร่ หรือกฎหมายอื่นที่เกี่ยวข้อง

##### มาตรา 72

การฟื้นฟูภายหลังสาธารณภัยตามพระราชบัญญัตินี้ ให้ดำเนินการโดยคำนึงถึงการลดความเสี่ยงภัยพิบัติในอนาคต การเพิ่มขีดความสามารถในการรับมือของพื้นที่ และการไม่ก่อให้เกิดความเสี่ยงใหม่หรือความเปราะบางซ้ำเดิม

การซ่อมแซม ก่อสร้าง ปรับปรุง หรือฟื้นฟูโครงสร้างพื้นฐาน อาคารสาธารณะ ระบบสาธารณูปโภค เส้นทางคมนาคม แหล่งน้ำ ศูนย์พักพิง หรือทรัพย์สินของรัฐที่ได้รับผลกระทบจากสาธารณภัย ต้องใช้ข้อมูลความเสี่ยงประกอบการวางแผน การออกแบบ การจัดสรรงบประมาณ และการดำเนินโครงการฟื้นฟู

#### หมวด 11 การติดตาม ประเมินผล และความรับผิดชอบ

##### มาตรา 73

ให้มีการติดตามและประเมินผลการดำเนินงานตามพระราชบัญญัตินี้ เพื่อประเมินผลสัมฤทธิ์ด้านการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย การเผชิญเหตุ และการฟื้นฟูภายหลังภัยพิบัติ

หลักเกณฑ์ วิธีการ ตัวชี้วัด และระยะเวลาในการติดตามและประเมินผล ให้เป็นไปตามที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

##### มาตรา 74

ให้หน่วยงานของรัฐ องค์กรปกครองส่วนท้องถิ่น รัฐวิสาหกิจ และหน่วยงานอื่นของรัฐที่มีหน้าที่ตามพระราชบัญญัตินี้ จัดทำรายงานผลการดำเนินงานด้านการลดความเสี่ยงภัยพิบัติ การเตรียมความพร้อม การใช้จ่ายงบประมาณ การใช้เงินกองทุน การดำเนินมาตรการล่วงหน้าก่อนเกิดภัย และการฟื้นฟูภายหลังภัยพิบัติ ตามหลักเกณฑ์และระยะเวลาที่คณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติกำหนด

##### มาตรา 75

ให้กรมป้องกันและบรรเทาสาธารณภัยรวบรวม วิเคราะห์ และจัดทำรายงานภาพรวมการดำเนินงานตามพระราชบัญญัตินี้ เสนอต่อคณะกรรมการป้องกันและบรรเทาสาธารณภัยแห่งชาติ อย่างน้อยปีละหนึ่งครั้ง หรือตามระยะเวลาที่คณะกรรมการกำหนด

รายงานตามวรรคหนึ่งให้เปิดเผยต่อสาธารณะเท่าที่ไม่กระทบต่อความมั่นคง ความปลอดภัยของประชาชน การคุ้มครองข้อมูลส่วนบุคคล หรือประโยชน์สาธารณะอื่นตามที่กฎหมายกำหนด
