# Roll-up 4 — Thai layout text (v02)

**Stage:** 4 — controlled layout copy for the text-free composition prototype
**Use:** จัดวางในโปรแกรมออกแบบเท่านั้น ห้ามใส่ข้อความนี้ลงในภาพที่สร้างด้วย AI

## Header

- `04`
- `ห่วงโซ่ผลกระทบช่วยอ่านความเสี่ยงข้ามระบบอย่างไร?`
- `ผลกระทบแรกจากภูมิอากาศส่งต่อไปยังบริการ อาชีพ และระบบนิเวศที่เชื่อมโยงกัน`

## What impact-chain analysis does

### Core explanation

`การวิเคราะห์ห่วงโซ่ผลกระทบเป็นเครื่องมือที่ทำให้ความสัมพันธ์เหตุและผลของความเสี่ยงจากภูมิอากาศมองเห็นได้เป็นลำดับ โดยเชื่อมอันตรายภูมิอากาศเข้ากับการเผชิญ ความเปราะบาง และขีดความสามารถในการรับมือ เพื่อระบุความเสี่ยงและจุดที่การปรับตัวควรเข้าไปลดแรงกระเพื่อมของผลกระทบ`

### Four analytical moves

| ลำดับ | คำถามวิเคราะห์                                                       | สิ่งที่แสดงในแผนภาพ                                    |
| ----- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| `01`  | `อันตรายใดเกิดขึ้น และวัดจากอะไร?`                                   | `ภัยภูมิอากาศ`                                         |
| `02`  | `ผลกระทบโดยตรงใดเกิดขึ้น และส่งต่ออย่างน้อยสองช่วงอย่างไร?`          | `ผลกระทบตรง → ผลกระทบต่อเนื่อง`                        |
| `03`  | `ใครหรือระบบใดอยู่ในทางผ่านของผลกระทบ และข้อจำกัดใดทำให้ฟื้นตัวยาก?` | `การเผชิญ + ความไวต่อผลกระทบ + ขีดความสามารถที่ขาดหาย` |
| `04`  | `ความเสี่ยงสุดท้ายคืออะไร และจุดใดควรใช้เพื่อลดหรือตัดวงจร?`         | `ความเสี่ยง + จุดเข้าสู่การปรับตัว`                    |

`แผนภาพนี้แสดงตัวอย่างเชิงวิธีวิทยา ไม่ใช่การคาดการณ์ผลลัพธ์ของพื้นที่หนึ่งพื้นที่ใด`

## Main impact-chain diagram

### 01 เมือง ระบบน้ำ และบริการ

| อันตรายภูมิอากาศ          | ผลกระทบโดยตรง                                          | ผลกระทบต่อเนื่อง                              |
| ------------------------- | ------------------------------------------------------ | --------------------------------------------- |
| `ฝนสะสมสูงและพายุเขตร้อน` | `ถนนและผิวจราจรท่วมฉับพลัน; เสาไฟล้มทำให้ไฟฟ้าขัดข้อง` | `การคมนาคมในเมืองและกิจกรรมเศรษฐกิจหยุดชะงัก` |

**การเผชิญ:** `พื้นที่ก่อสร้างหนาแน่น เส้นทางคมนาคมในเขตน้ำท่วม และโครงข่ายไฟฟ้าที่อยู่ในแนวลมพายุ`
**ความเปราะบาง / ขีดความสามารถ:** `การจัดการน้ำและโครงข่ายไฟฟ้าสำรองไม่เพียงพอ; แรงงานรายวันและแรงงานนอกระบบสูญเสียรายได้เมื่อเดินทางไปทำงานไม่ได้`
**ความเสี่ยงที่ห่วงโซ่ชี้ให้เห็น:** `ความต่อเนื่องของบริการเมืองและรายได้ครัวเรือนที่พึ่งพาการเดินทาง`

`[S04] ตัวอย่างโครงสร้างพื้นฐานเมือง: น้ำท่วมถนนและไฟฟ้าขัดข้อง → คมนาคมและกิจกรรมเศรษฐกิจหยุดชะงัก`
`[S02] บริบทประเทศไทย: ฝนหนักและพายุสร้างความเสียหายต่อโครงสร้างพื้นฐาน ระบบชลประทาน และแหล่งน้ำประปา`

### 02 เกษตร น้ำ และความมั่นคงทางอาหาร

| อันตรายภูมิอากาศ | ผลกระทบโดยตรง                        | ผลกระทบต่อเนื่อง                                         |
| ---------------- | ------------------------------------ | -------------------------------------------------------- |
| `ภัยแล้ง`        | `น้ำในระบบชลประทานลดลงและพืชเสียหาย` | `รายได้เกษตรกรลดลง → ความมั่นคงของอาชีพและอาหารถูกกดดัน` |

**การเผชิญ:** `ที่ดินเกษตรและครัวเรือนเกษตรที่ต้องพึ่งพาน้ำสำหรับการผลิต`
**ความเปราะบาง / ขีดความสามารถ:** `เข้าถึงน้ำถาวรและระบบชลประทานไม่เท่ากัน; พืชไวต่อสภาพอากาศ; รายได้ทางเลือกและเงินออมมีจำกัด`
**ความเสี่ยงที่ห่วงโซ่ชี้ให้เห็น:** `ความมั่นคงของรายได้เกษตรกร อุปทาน และอาหาร`

`[S04] ตัวอย่างเกษตร: ภัยแล้ง → น้ำชลประทานลดลงและพืชเสียหาย → รายได้เกษตรกรลดลง`
`[S02] บริบทประเทศไทย: ภัยแล้ง พ.ศ. 2558 กระทบการผลิตเกษตร ระบบกักเก็บน้ำ และน้ำใช้ในครัวเรือน; ครัวเรือนเกษตรคิดเป็น 45.49% ของประชากรยากจนของประเทศ`

### 03 ชายฝั่ง ระบบนิเวศ และการท่องเที่ยว

| อันตรายภูมิอากาศ                                         | ผลกระทบโดยตรง                                                                       | ผลกระทบต่อเนื่อง                                                                      |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `พายุ ฝนหนัก ความแปรปรวนของระดับน้ำทะเล และทะเลอุ่นขึ้น` | `ทรัพย์สินและโครงสร้างพื้นฐานท่องเที่ยวเสียหาย; ปะการังฟอกขาวกดดันระบบนิเวศชายฝั่ง` | `การดำเนินงานและจำนวนผู้เยือนลดลง → รายได้ท้องถิ่นและต้นทุนการดำเนินงานได้รับผลกระทบ` |

**การเผชิญ:** `ทรัพย์สิน บริการ และแรงงานท่องเที่ยวริมชายฝั่ง รวมถึงระบบนิเวศที่สร้างความน่าดึงดูดของแหล่งท่องเที่ยว`
**ความเปราะบาง / ขีดความสามารถ:** `ระบบนิเวศที่เสื่อมโทรมฟื้นตัวช้า; เศรษฐกิจท้องถิ่นพึ่งพารายได้จากการท่องเที่ยวสูง`
**ความเสี่ยงที่ห่วงโซ่ชี้ให้เห็น:** `ความต่อเนื่องของรายได้และบริการท่องเที่ยวจากทุนธรรมชาติชายฝั่ง`

`[S02] บริบทประเทศไทย: ฝนหนัก พายุ ระดับน้ำทะเล และทะเลอุ่นขึ้นทำลายทรัพย์สินและโครงสร้างพื้นฐานท่องเที่ยว ลดจำนวนผู้เยือน และกระทบรายได้ท้องถิ่น; พฤษภาคม พ.ศ. 2567 ปะการังทั่วประเทศได้รับผลกระทบ 86.6%`

## How to read the arrows

- `ลูกศรเส้นเข้ม = ลำดับผลกระทบที่เลือกจากตัวอย่างในแหล่งอ้างอิง`
- `ป้ายการเผชิญและความเปราะบาง = เงื่อนไขที่ทำให้ผลกระทบลุกลามหรือฟื้นตัวยาก`
- `ปลายห่วงโซ่ = ความเสี่ยงต่อระบบและความเป็นอยู่ ไม่ใช่จุดจบที่ตายตัว`

## Cross-cutting insight

### Heading

`เหตุใดผลกระทบเดียวจึงลุกลามไม่เท่ากัน?`

### Three determinants

- `การเผชิญ: คน สินทรัพย์ และบริการอยู่ตรงทางผ่านของผลกระทบมากเพียงใด`
- `ความไวต่อผลกระทบ: ระบบต้องพึ่งพาน้ำ พลังงาน การคมนาคม หรือระบบนิเวศมากเพียงใด`
- `ขีดความสามารถในการรับมือ: มีข้อมูล เงินออม บริการสาธารณะ ระบบสำรอง และทางเลือกในการฟื้นตัวเพียงใด`

`การวิเคราะห์ห่วงโซ่จึงไม่หยุดที่การระบุภัย แต่ใช้หาจุดที่ลดการเผชิญ ลดความเปราะบาง หรือเพิ่มขีดความสามารถได้`

## Response bridge

`ความเสี่ยงที่ส่งต่อข้ามระบบ ต้องใช้การปรับตัวที่เชื่อมระบบเข้าด้วยกัน`

## Footer

- `ห่วงโซ่ผลกระทบแสดงความสัมพันธ์เชิงเหตุและผลในบริบทที่เลือกศึกษา ไม่ใช่แบบจำลองคาดการณ์หรือการจัดอันดับความเสี่ยงของพื้นที่`
- `แหล่งข้อมูลหลัก: [S04] คู่มือการจัดทำห่วงโซ่ผลกระทบจากการเปลี่ยนแปลงสภาพภูมิอากาศ; [S02] ร่างรายงานการปรับตัวของประเทศไทยสำหรับ 5NC/2BTR; [S03] IPCC AR6`
- `ต่อไป: การปรับตัวที่ใช้ข้อมูลความเสี่ยงช่วยลดและตัดวงจรผลกระทบได้อย่างไร?`

## Layout rules

- ให้โมดูล `การวิเคราะห์ห่วงโซ่ผลกระทบทำอะไร` อยู่เหนือแผนภาพหลักและอ่านได้ก่อนตัวอย่างทั้งสาม เพื่ออธิบายว่าแผนภาพเป็นเครื่องมือวิเคราะห์ ไม่ใช่ภาพเหตุการณ์
- ข้อความในวงกลมใช้เพียงสามชั้น: หมวดวิเคราะห์ → กลไกผลกระทบ → ผลต่อเนื่อง; วาง `การเผชิญ / ความเปราะบาง / ความเสี่ยง` เป็นคำอธิบายภายนอกวงกลมด้วยเส้นสีเทา
- ใช้จุดสีควบคู่กับป้ายหมวดหมู่และตำแหน่งในลำดับ ห้ามใช้สีเป็นวิธีเดียวในการแยกความหมาย
- ลูกศรเส้นหลักสีเข้มหนากว่าเส้นคำอธิบายสีเทาเสมอ ห้ามเพิ่มเส้นเชื่อมข้ามแถวในต้นแบบแรก
- ภาพประกอบฉากแบบเรียบวางได้เฉพาะขอบหรือพื้นหลังของแต่ละแถว และห้ามทับวงกลม ลูกศร หรือข้อความ
- วางข้อความ `ตัวอย่างเชิงวิธีวิทยา` และรหัส `[S04] / [S02]` ใกล้ตัวอย่างทุกแถว เพื่อแยกวิธีวิเคราะห์ออกจากบริบทประเทศไทย
