# Generation Parameters — Roll-up 1

## Output role

Composition prototype / surrounding visual system.

The generated image should not be treated as final. Final IPCC diagrams, labels, source notes, and DCCE identity should be added in layout software.

## Canvas

- Physical format: 60 × 160 cm roll-up.
- Aspect ratio: 3:8 vertical.
- Orientation: portrait.
- Background: light pale grey.

## Required empty / reserved areas

- Header zone for title and subtitle.
- Upper context-strip zone for IPCC AR5→AR6 diagram.
- Large central reserved zone for IPCC AR6 response-risk diagram.
- Callout spaces around the central diagram.
- Lower module for key-risk chips and maladaptation warning.
- Footer/source strip.

## Style mode

- Scientific editorial infographic.
- Institutional climate-risk communication.
- Clean geometric vector.
- Subtle low-poly supporting icons only.
- Minimal shadows.
- Thin connector lines.

## Color mode

- Pale grey/white base.
- IPCC category accents:
  - hazard navy;
  - exposure cyan;
  - vulnerability orange;
  - risk magenta;
  - response amber/brown.
- Maladaptation warning: warm amber/orange.
- Institutional footer: restrained DCCE dark green.

## Text mode

No final rendered text in generated artwork.

Acceptable placeholders:

- simple blank rectangles;
- unlabeled chips;
- generic line placeholders.

Avoid pseudo-readable text.

## Scientific locked constraints

- `SRL-image-1.png` remains the main diagram anchor.
- `SRL-image-0.png` remains secondary context only.
- S03-only evidence boundary.
- No Thailand-specific examples on Roll-up 1.
- Key-risk examples are illustrative IPCC domains.
- Maladaptation must be visually emphasized as response risk that can create more risk.

## Iteration evaluation criteria

1. Main diagram area large enough.
2. Callouts do not crowd diagram.
3. Maladaptation warning is visible but not overpowering.
4. Key-risk module is compact.
5. Footer/source area is clean.
6. Overall style matches `DESIGN-01.md`.
