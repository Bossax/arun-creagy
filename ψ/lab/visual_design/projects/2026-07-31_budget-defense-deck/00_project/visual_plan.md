# Visual Plan: National Climate Adaptation Platform Widescreen Slide Deck
**ธีม: Minimal Corporate (รวมทั้ง 4 สไลด์)**

## 1. Widescreen Specifications
*   **Dimensions**: 1280px width x 2880px height total (consisting of 4 stacked 1280px x 720px 16:9 slides).
*   **Reading Direction**: Left-to-Right scanning grid on each slide.
*   **Dominant Visual Anchors**: 
    *   *Slide 1*: Comparison column grid showing legacy data vs. dynamic platform target state.
    *   *Slide 2*: Parallel Flowchart representing backend 3-layer data engine mapping to sitemap portal nodes.
    *   *Slide 3*: Data Lifecycle Block Schema outlining DGA-governance gates and BTR reporting flow.
    *   *Slide 4*: Horizontal roadmap detailing technical blocks for the 4 core FY2027 modules.

---

## 2. Palette & Visual Roles
*   **Background Canvas**: A controlled `--space-indigo` (#171738ff) to `--deep-twilight` (#2e1760ff) gradient.
*   **Card Backgrounds**: Translucent dark panels; no white card surfaces.
*   **Card Borders**: Thin 1px solid borders using `--glaucous` (#7180b9ff).
*   **Typography**:
*   Main headers: Large, bold `--honeydew` (#dff3e4ff).
*   Section sub-headers: Medium, bold `--honeydew` (#dff3e4ff).
*   Primary statistic metrics: Large, bold `--signal-yellow` (#fde74cff) text; one decisive use per slide.
*   Dividers/Dividing grids: `--glaucous` (#7180b9ff) solid lines.

* **Illustration System**: Abstract geometric vectors only—grids, nodes, arcs, planes, modules, and connectors. Illustrations are text-free, placed centre-right, and assembled as editable Canva groups.

---

## 3. Structural Slide Layouts

### Slide 1: Climate Economic Threat, Data Gaps & Digital Infrastructure
*   *Layout*: 3-column modular cards.
*   *Visuals*: Left Column (Climate Threat to Economy), Center Column (Existing Data Gaps), Right Column (Digital Infrastructure for Adaptation).

### Slide 2: User Demands & Frontend Sitemap Architecture
*   *Layout*: 2-column comparative layout (50/50 split).
*   *Left Column (Surveyed Demands)*: Details the 3 key stakeholder surveyed needs (township GIS maps, avoided losses CBA, design codes) and justifies the front/back integration.
*   *Right Column (Sitemap & Database)*: Displays the frontend sitemap tree structure (Home/Area Search, Policy Maker Center, Knowledge Cycle, Tools & Services, News & Contact) linked to the backend data management database foundation.

### Slide 3: Climate Data System Conceptual Design & A-BTR Showcase
*   *Layout*: Flow architecture layout.
*   *Content*: Maps the conceptual architecture from local sources through DGA-standard interoperability/validation gates into the discovery/sharing database, exporting directly into the BTR reporting portal and GDX G2G links.

### Slide 4: FY2027 Key Platform Deliverables
*   *Layout*: 4-column horizontal roadmap.
*   *Content Columns*: Data Pipeline, Metadata & Governance, Risk Search & GIS Map Viewer, and BTR Analysis & Reporting Dashboard.

---

## 4. Editable Text Zones & Safe Areas
*   *Editable*: Slide titles, headers, bullet list text, numerical values (e.g., 80.6%, 7%-14%, 25 ล้านบาท), and footnotes.
*   *Static Graphics*: Outline lock icons, flow arrows (`➔`), process containers, and database cylinder shapes.
*   *Padding & Gaps*: Keep 24px inner padding within all slide cards to prevent visual compression.
