# Canva Illustration Handoff — National Climate Adaptation Platform Budget Defense Deck

**Project:** National Climate Adaptation Platform Budget Defense Widescreen Deck
**Output:** Four separate 16:9 Canva slide compositions or illustration layers
**Rule:** Build abstract, geometric, technically legible visuals. Keep all Thai and English copy as editable Canva text layers; never bake body text, statistics, labels, or source citations into generated artwork.

## Non-negotiable visual system

Use this palette only. Do not introduce substitute greens, blues, neon colours, or stock-photo treatment.

| Token | Hex | Role | Maximum use |
| --- | --- | --- | --- |
| Space Indigo | `#171738` | Primary dark canvas, dominant type, structural field | 55% |
| Deep Twilight | `#2E1760` | Gradient depth and secondary panels | 20% |
| Vivid Royal | `#3423A6` | Active data paths and primary system emphasis | 10% |
| Glaucous | `#7180B9` | Grids, borders, inactive nodes, connector lines | 10% |
| Honeydew | `#DFF3E4` | White-space substitute, approved/healthy signal, high contrast | 4% |
| Signal Yellow | `#FDE74C` | Decisive metric, protected node, approval/priority moment only | 1% |

### Geometry and composition rules

- Use a dark Space Indigo to Deep Twilight gradient canvas; cards may be translucent dark panels with a 1px Glaucous outline.
- Build all visuals from precise circles, squares, isometric planes, thin lines, grids, arcs, and modular rectangles.
- Use flat vector geometry only. No humans, plants, globes, maps rendered as decoration, cartoons, clip-art, 3D photorealism, or generic stock icons.
- Reserve Honeydew for confirmed states and Signal Yellow only for one decisive visual moment per slide.
- Use no gradients inside icons or nodes; use gradients only in the background field.
- Leave a clear text-safe zone at upper left and a 15% bottom safe zone for citations and editable labels.

## Required illustrations

### Slide 1 — Fragmentation to protected national capability

Create an abstract geometric network that moves from fragmented left-side data blocks to a coherent protected core on the right.

- Left: scattered Glaucous document rectangles, isolated dots, and broken connector lines.
- Centre: a narrowing Vivid Royal routing path that consolidates the fragments.
- Right: a dense Honeydew core node lattice inside a single protective geometric arc.
- Use one Signal Yellow node inside the protected core to signify the nationally decisive capability.
- Purpose: show that the proposal transforms scattered information into trusted, protected decision infrastructure.

### Slide 2 — Demand-driven service surface and data foundation

Create an abstract two-plane architecture, not a literal website mock-up.

- Upper plane: five modular, floating outline blocks representing the public-facing service surface; use a simple 5-node horizontal hierarchy.
- Lower plane: a denser canonical data grid, divided into three aligned strata.
- Connect both planes with precise vertical Glaucous lines and a small number of Vivid Royal active paths.
- Use Honeydew only for the approved route from user demand through service modules to the shared data foundation.
- Purpose: demonstrate that user-facing services are inseparable from the governed data model below them.

### Slide 3 — Federated, traceable national data flow

Create a hub-and-spoke orbital geometry around one central square/circle core.

- Four satellite nodes represent source-agency systems; use distinct geometric silhouettes but no baked labels.
- Route their inputs through a ring of small Glaucous validation gates into the central NCAIF core.
- Extend one Vivid Royal outbound route to a final Honeydew reporting/output node.
- Place exactly one Signal Yellow checkpoint on the outbound route to signify auditable BTR reporting.
- Purpose: show sovereignty-preserving federation, validation, lineage, and reporting—not centralised data capture.

### Slide 4 — Build-ready module architecture

Create a four-module geometric blueprint with a clear left-to-right implementation path.

- Module 1: parallel ingest lines entering a rectangular staging block.
- Module 2: a registry/grid block with a small Honeydew verification mark.
- Module 3: a tessellated spatial mesh inside a framed square.
- Module 4: a concentric reporting/output structure.
- Connect modules through a single Vivid Royal route; reserve Signal Yellow for the final approved-output marker only.
- Purpose: establish that the procurement buys four coherent, build-ready modules rather than an undefined portal.

## Canva assembly instructions

1. Create each illustration as a separate grouped composition, positioned centre-right at 40–55% of the slide area.
2. Add titles, Thai copy, figures, source lines, and module labels only after the artwork is placed in Canva.
3. Keep every node, line, panel, and connector independently editable where Canva permits.
4. Use the layout prototype only for hierarchy, spacing, and text zones. This handoff supersedes earlier requests for glassmorphism, generic glowing imagery, or a single vertically stacked review graphic.

## Prohibited outputs

- Any text baked into an illustration.
- Decorative climate imagery that does not explain system logic.
- More than one Signal Yellow focal point per slide.
- Itemised cost visuals, pricing tables, or ROI formulas.
