# Adaptation Finance Roll-ups — Design System

## Selected reference

Primary visual reference: `climate finance un theme.jpg` in this folder.
Logo references: `dcce logo.jpg` and `Creagy_original_square.png` in this folder.
Composition benchmark: `../rollup_01/img/draft0.png`.

The image establishes the key theme: high-contrast editorial collage, grayscale documentary objects, geometric color fields, and a visual tension between money, infrastructure, nature, and public action. The Verdana Health system remains a secondary legibility reference only.

Draft 0 is a benchmark for **visual rhythm only**: bold headline zone, full-height narrative movement, distributed image crops, diagonal framing, and confident information density. It is not a template for its objects, copy, fund claims, or exact composition.

## Intended feel

Bold, editorial, civic, and action-oriented. The design should feel like a practical climate-finance briefing with visual urgency, while remaining clear enough for public-sector use.

## Tokens

- Ink `#111111`: titles, diagrams, and primary text
- Charcoal `#4A4A4A`: grayscale image treatment and secondary text
- Teal `#358799`: primary structure, GCF route, and directional rules
- Mint `#1DBF99`: readiness, selected path, and shared action states
- Sage `#95C6A6`: AF route and secondary structural panels
- Rose `#D9788D`: emphasis, key decisions, and important callouts
- Blush `#EBB8BB`: soft panel fills and quiet background blocks
- Background `#FFFFFF`: required primary canvas and card surface
- Pale gray `#F1F3F2`: secondary panels only, never the dominant background
- Ink `#1F2933`: body text, diagrams, and contrast
- Plus Jakarta Sans for headings; DM Sans for body; Fira Code for step numbers and amounts
- 8px spacing grid; 8px cards; generous whitespace

## Application

- Use white as the dominant background for both roll-ups.
- Use teal and sage as the main structural colors, with mint, rose, and blush as controlled accents—not as a full-page background.
- Use the supplied five-color palette as the signature system; do not introduce the prior DCCE–Creagy or UN-like cyan/yellow palette.
- Use several distributed grayscale collage fragments to create editorial rhythm across the full height; imagery should frame and energize the information architecture, not replace it.
- Roll-up 1 uses a teal lifecycle spine, mint readiness states, and rose decision points.
- Roll-up 2 uses a teal GCF lane, a sage AF lane, and mint shared readiness/endorsement checkpoints.
- Use icons with final editable text labels; do not rely on color alone.
- Keep all labels, numbers, and diagrams editable.

## Object and collage language

- Use oversized, grayscale photographic cut-outs rather than flat stock icons.
- Favor tactile objects with visible grain, paper texture, and strong light/dark contrast.
- Let selected objects crop beyond the panel edge to create scale and urgency. Use multiple medium-scale fragments at top, side, and lower zones rather than one isolated hero object.
- Use surreal scale shifts deliberately, but build an original object composition for each roll-up.
- For project-readiness visuals, use people around plans, generic banknotes, a calculator, funding documents, a bond/loan certificate, folders, maps, and project models.
- Keep the objects symbolic and editorial; they establish the theme, not quantitative evidence.
- Layer objects over hard-edged palette fields or tabs; use rose or blush only as small emphasis surfaces.
- Prefer cut-out silhouettes, visible shadows, and slight overlap; avoid glossy 3D renders, smooth corporate icons, or photorealistic full scenes.
- Use three to five distinct object fragments per panel, arranged around the information structure. Combined imagery should occupy roughly 25–35% of the composition while preserving clear text and diagram zones.

## Draft 0 composition principles to retain

- Strong title block with an asymmetric cropped image or color field at the opposite edge.
- A continuous full-height visual rhythm: spine or columns, framed by distributed image crops and diagonal color wedges.
- High contrast between ink, white space, colored rules, and grayscale imagery.
- Images act as chapter markers and edge anchors, not as a single central illustration.
- Content remains the primary proof: lifecycle in Roll-up 1; equal GCF–AF comparison in Roll-up 2.

## Originality guardrail

- The climate-finance image is a **style reference only**; do not reproduce its composition, object selection, crop, or arrangement.
- Do not use the pinched coin, piggy bank, wind-turbine, recycling-bin, watering-can, or yellow-triangle arrangement from the reference image.
- Use generic, unbranded financial instruments and banknotes with no readable denominations, logos, or text.
- Build the collage around the roll-up’s message: capacity building and project planning must be visibly connected to financing readiness.
