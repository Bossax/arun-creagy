# 18. Distillation Rules

When converting references into this design system:

1. Extract repeated visual logic, not isolated decoration.
2. Separate subject matter from style.
3. Prefer principles over exact measurements when references vary.
4. Record exact values only when they are stable across the reference set.
5. Distinguish essential features from optional motifs.
6. Identify contradictions between references.
7. Choose one dominant style when references are mixed.
8. Avoid reproducing a reference’s exact composition, proprietary graphics, or unique illustration.
9. Translate visual observations into actionable rules.
10. Test whether the rules can be applied to a different topic.

# 19. Style Fidelity Checklist

Before approving a new visual, confirm:

## Composition
- [ ] The composition follows the defined reading path.
- [ ] There is one dominant visual anchor.
- [ ] Negative space is preserved.
- [ ] Modules follow the grid.

## Illustration
- [ ] Shape language matches the reference set.
- [ ] Perspective is consistent.
- [ ] Detail level is controlled.
- [ ] Outlines, shading, and texture follow the rules.

## Color
- [ ] Palette proportions are respected.
- [ ] Accent color is used selectively.
- [ ] Semantic color use is consistent.
- [ ] Contrast is sufficient.

## Typography
- [ ] Type hierarchy matches the style.
- [ ] Body text remains readable.
- [ ] Text density is within limits.
- [ ] Final text was added outside the generated illustration.

## Data and science
- [ ] Visual claims are supported.
- [ ] Units and dates are correct.
- [ ] Maps and diagrams are accurate.
- [ ] Uncertainty is not concealed.
- [ ] No visual element overstates the evidence.

## Overall fidelity
- [ ] The result feels related to the references without copying them.
- [ ] The visual works with a different subject.
- [ ] The style remains coherent across all modules.
