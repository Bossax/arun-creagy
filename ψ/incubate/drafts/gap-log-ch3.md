# Gap log — บทที่ 3 (claims ที่ยังหาแหล่งอ้างอิงจากไฟล์ในโครงการไม่ได้)

1. **"ตามหลักการฟื้นฟูที่ดีกว่าเดิมและปลอดภัยกว่าเดิม" ("Build Back Better and Safer") — ทั้งในฐานะแนวปฏิบัติของกรมป้องกันและบรรเทาสาธารณภัยเอง และในฐานะหลักการสากล**
   - **อยู่ในส่วน:** 3.1
   - **สถานะ:** ไม่แทรกอ้างอิงใด ๆ ในร่างแล้ว — เดิมมีการอ้างอิง (กรมป้องกันและบรรเทาสาธารณภัย, ม.ป.ป.) เพื่อยืนยันว่ากรมป้องกันและบรรเทาสาธารณภัยใช้หลักการนี้ในกรอบ PDNA ของตนเอง (เอกสาร PDNA ของกรมป้องกันและบรรเทาสาธารณภัยเองใช้วลีนี้ตรงตัว) แต่ถอดออกแล้วตามคำสั่ง Boss เนื่องจากเอกสารต้นทางไม่ระบุปีพิมพ์ นอกจากนี้ยังไม่พบเอกสารใดในโครงการที่สืบต้นตอของหลักการนี้ไปถึงกรอบสากลต้นทาง (เช่น Sendai Framework for Disaster Risk Reduction หรือเอกสารแนวทางฟื้นฟูของ UN/World Bank)
   - **แหล่งที่ควรค้นหาต่อ (สำหรับรอบ web-search):** (ก) ปีพิมพ์ที่ยืนยันได้ของรายงาน PDNA ของกรมป้องกันและบรรเทาสาธารณภัยเอง (`inbox_source/Post Disaster Needs Assessment report by DDPM.md` — frontmatter ไม่ระบุปี) เพื่อกู้คืนการอ้างอิงระดับกรมฯ; (ข) เอกสารกรอบ Sendai Framework for Disaster Risk Reduction ฉบับเต็ม หรือเอกสารแนวทางการฟื้นฟูหลังภัยพิบัติของ UNDRR/World Bank ที่บัญญัติหลักการ "Build Back Better" เป็นทางการ หากต้องการอ้างถึงที่มาระดับสากล

2. **ฐานกฎหมายไทยด้านการจัดการสาธารณภัย (พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย / แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ)**
   - **อยู่ในส่วน:** 3.1 (โดยนัย — ร่างเนื้อหาปัจจุบันเอ่ยถึงเฉพาะชื่อหน่วยงาน "กรมป้องกันและบรรเทาสาธารณภัย" ไม่ได้อ้างถึงตัวบทกฎหมายหรือแผนชาติโดยตรง)
   - **สถานะ:** ไม่มีประโยคใดในร่างปัจจุบันที่จำเป็นต้องอ้างอิงรายการนี้จริง ๆ บันทึกไว้เนื่องจากโจทย์งานระบุให้เฝ้าระวังหัวข้อนี้สำหรับบทนี้ และไม่พบไฟล์ใดในโครงการที่มีรายละเอียดบรรณานุกรมจริง (เลขที่ราชกิจจานุเบกษา วันที่ประกาศ)
   - **แหล่งที่ควรค้นหาต่อ (สำหรับรอบ web-search):** ราชกิจจานุเบกษา ฉบับประกาศ พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550 (หรือฉบับแก้ไขล่าสุด) และ/หรือแผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติฉบับปัจจุบัน — ใช้เฉพาะกรณีที่ร่างเนื้อหาถูกแก้ไขในอนาคตให้เอ่ยถึงตัวบทกฎหมายหรือแผนชาติโดยตรง
