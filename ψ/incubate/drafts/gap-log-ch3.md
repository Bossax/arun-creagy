# Gap log — บทที่ 3 (claims ที่ยังหาแหล่งอ้างอิงจากไฟล์ในโครงการไม่ได้)

1. **"ตามหลักการฟื้นฟูที่ดีกว่าเดิมและปลอดภัยกว่าเดิม" ("Build Back Better and Safer") — ทั้งในฐานะแนวปฏิบัติของกรมป้องกันและบรรเทาสาธารณภัยเอง และในฐานะหลักการสากล**
   - **อยู่ในส่วน:** 3.1
   - **สถานะ:** ไม่แทรกอ้างอิงใด ๆ ในร่างแล้ว — เดิมมีการอ้างอิง (กรมป้องกันและบรรเทาสาธารณภัย, ม.ป.ป.) เพื่อยืนยันว่ากรมป้องกันและบรรเทาสาธารณภัยใช้หลักการนี้ในกรอบ PDNA ของตนเอง (เอกสาร PDNA ของกรมป้องกันและบรรเทาสาธารณภัยเองใช้วลีนี้ตรงตัว) แต่ถอดออกแล้วตามคำสั่ง Boss เนื่องจากเอกสารต้นทางไม่ระบุปีพิมพ์ นอกจากนี้ยังไม่พบเอกสารใดในโครงการที่สืบต้นตอของหลักการนี้ไปถึงกรอบสากลต้นทาง (เช่น Sendai Framework for Disaster Risk Reduction หรือเอกสารแนวทางฟื้นฟูของ UN/World Bank)
   - **แหล่งที่ควรค้นหาต่อ (สำหรับรอบ web-search):** (ก) ปีพิมพ์ที่ยืนยันได้ของรายงาน PDNA ของกรมป้องกันและบรรเทาสาธารณภัยเอง (`inbox_source/Post Disaster Needs Assessment report by DDPM.md` — frontmatter ไม่ระบุปี) เพื่อกู้คืนการอ้างอิงระดับกรมฯ; (ข) เอกสารกรอบ Sendai Framework for Disaster Risk Reduction ฉบับเต็ม หรือเอกสารแนวทางการฟื้นฟูหลังภัยพิบัติของ UNDRR/World Bank ที่บัญญัติหลักการ "Build Back Better" เป็นทางการ หากต้องการอ้างถึงที่มาระดับสากล

2. **ฐานกฎหมายไทยด้านการจัดการสาธารณภัย (พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย / แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ)**
   - **อยู่ในส่วน:** 3.1 (โดยนัย — ร่างเนื้อหาปัจจุบันเอ่ยถึงเฉพาะชื่อหน่วยงาน "กรมป้องกันและบรรเทาสาธารณภัย" ไม่ได้อ้างถึงตัวบทกฎหมายหรือแผนชาติโดยตรง)
   - **สถานะ:** ไม่มีประโยคใดในร่างปัจจุบันที่จำเป็นต้องอ้างอิงรายการนี้จริง ๆ บันทึกไว้เนื่องจากโจทย์งานระบุให้เฝ้าระวังหัวข้อนี้สำหรับบทนี้ และไม่พบไฟล์ใดในโครงการที่มีรายละเอียดบรรณานุกรมจริง (เลขที่ราชกิจจานุเบกษา วันที่ประกาศ)
   - **แหล่งที่ควรค้นหาต่อ (สำหรับรอบ web-search):** ราชกิจจานุเบกษา ฉบับประกาศ พ.ร.บ. ป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550 (หรือฉบับแก้ไขล่าสุด) และ/หรือแผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติฉบับปัจจุบัน — ใช้เฉพาะกรณีที่ร่างเนื้อหาถูกแก้ไขในอนาคตให้เอ่ยถึงตัวบทกฎหมายหรือแผนชาติโดยตรง

3. **"กรอบการประเมินความเสี่ยงสากล" ที่ระบบแผนที่ความเสี่ยงเชิงพื้นที่ของกรม สส. อ้างอิง**
   - **อยู่ในส่วน:** `crdb-full-report-3.1` (ทบทวนและสังเคราะห์ข้อมูลพื้นฐานและผลิตภัณฑ์ข้อมูลสารสนเทศ ณ ปัจจุบัน — คนละหัวข้อกับรายการที่ 1–2 ข้างต้นซึ่งอยู่ใน exec-summary 3.1)
   - **สถานะ:** รายงานฉบับกลาง (`inbox_source/2026-03-23_interim-report-1st-submission.md` บทที่ 2 §2.2) ระบุชื่อกรอบไว้ตรงตัวว่า IPCC AR6 แต่การตรวจสอบย้อนกลับของโครงการเอง (`2026-08-29_crdb-citation-gap-audit.md`) เคยตรวจข้อความ IPCC risk framework (hazard×exposure×vulnerability) ที่มีลักษณะเดียวกันในส่วนอื่นของรายงานแล้วพบว่าเป็น GAP คือไม่พบเอกสาร IPCC ต้นฉบับที่ยืนยันได้ในโครงการ ร่าง `polished-5.3.1.md` จึงยังคงใช้ถ้อยคำกลาง ๆ ว่า "กรอบการประเมินความเสี่ยงสากล" โดยไม่ระบุชื่อ IPCC AR6 ตรง ๆ รอ Boss ตัดสินใจว่าจะระบุชื่อกรอบตรง ๆ (โดยอ้างว่ารายงานฉบับกลางเป็นแหล่งที่มา) หรือคงไว้แบบไม่ระบุชื่อ
   - **แหล่งที่ควรค้นหาต่อ (สำหรับรอบ web-search):** เอกสาร IPCC AR6 ฉบับที่เกี่ยวข้องกับกรอบ hazard-exposure-vulnerability (WG2) เพื่อยืนยันว่าเป็นกรอบที่ระบบของกรม สส. ใช้จริง ไม่ใช่เพียงคำกล่าวอ้างในรายงานฉบับกลาง

4. **การจัดกลุ่มช่องว่างเชิงระบบสามด้าน (มาตรฐานร่วม metadata และพจนานุกรมข้อมูล / ความแตกต่างของรอบอัปเดตและขอบเขตพื้นที่ / ข้อจำกัดการเข้าถึงและธรรมาภิบาลข้อมูล)**
   - **อยู่ในส่วน:** `crdb-full-report-3.1`, ย่อหน้ารายการ 3 ข้อท้ายส่วน
   - **สถานะ:** เป็นการสังเคราะห์ของทีมที่ปรึกษาเอง เขียนขึ้นครั้งแรกในร่างของที่ปรึกษา (`output/archive/interim-report/5.3.1-Interim-Report-v3-prose-draft.md`) ไม่ใช่ข้อค้นพบที่ยกมาโดยตรงจากรายงานฉบับกลาง ข้อความที่ใกล้เคียงที่สุดในรายงานฉบับกลาง (บทที่ 2 §2.4) ระบุปัจจัยสามด้านเช่นกัน แต่เป็นคนละชุด คือ ความถี่ในการปรับปรุง ระดับพื้นที่ และข้อจำกัดเชิงปฏิบัติการ ไม่ได้พูดถึงมาตรฐาน metadata หรือธรรมาภิบาลข้อมูลในฐานะช่องว่างโดยตรง
   - **แหล่งที่ควรค้นหาต่อ:** ไม่ใช่กรณีที่ต้องค้นหาแหล่งภายนอกเพิ่ม แต่รอ Boss ตัดสินใจว่าจะระบุตรง ๆ ว่าเป็นการสังเคราะห์ของที่ปรึกษา หรือปรับถ้อยคำให้ตรงกับสามด้านที่รายงานฉบับกลาง §2.4 ระบุไว้จริง

5. **"ได้รับการยอมรับในวงสนทนาระดับจังหวัดและระดับนโยบาย" (ระบบแผนที่ความเสี่ยงเชิงพื้นที่ของกรม สส.)**
   - **อยู่ในส่วน:** `crdb-full-report-3.1`
   - **สถานะ:** ไม่พบเอกสารในโครงการที่ยืนยันการยอมรับนี้โดยตรง ทั้งในรายงานฉบับกลาง บันทึกการสัมภาษณ์ และผลการประชุมระดมความเห็น
   - **แหล่งที่ควรค้นหาต่อ:** ไม่มีแหล่งภายในให้ค้น หากต้องการคงข้อความนี้ไว้ ต้องหาหลักฐานเพิ่ม (เช่น บันทึกการประชุมระดับจังหวัดหรือระดับนโยบายที่กล่าวถึงระบบนี้) มิฉะนั้นควรตัดหรือปรับถ้อยคำ

6. **หน่วยงานที่ปรากฏในรายงานฉบับกลางแต่ยังไม่ได้กล่าวถึงในตาราง 3 ของ `polished-5.3.1.md`**
   - **อยู่ในส่วน:** `crdb-full-report-3.1`
   - **สถานะ:** สำนักงานนโยบายและแผนการขนส่งและจราจร (กำลังพัฒนาศูนย์ข้อมูลเปิดด้านคมนาคมที่รองรับการประเมินความเสี่ยงโครงสร้างพื้นฐาน) และเครื่องมือวิเคราะห์ความเสี่ยงทางกายภาพของภาคธนาคาร (ใช้ข้อมูลอุทกภัยและแผนที่ความเสี่ยงจากผู้ให้บริการหลายแหล่ง) ทั้งสองรายอยู่ในรายงานฉบับกลาง บทที่ 2 §2.2–2.3 แต่ไม่ได้นำเข้าตาราง 3 รอ Boss ตัดสินใจว่าจะเพิ่มเข้าไปหรือไม่
   - **แหล่งที่ควรค้นหาต่อ:** ไม่ต้องค้นเพิ่ม ข้อมูลอยู่ในโครงการแล้ว เป็นเรื่องขอบเขตเนื้อหาที่ต้องตัดสินใจ ไม่ใช่ช่องว่างหลักฐาน
