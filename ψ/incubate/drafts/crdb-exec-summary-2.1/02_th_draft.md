# 2.1 ขอบเขตของบัญชีรายการ

บัญชีรายการแบ่งเป็นสองชุดตามบทบาทของสิ่งที่รวบรวม ได้แก่ บัญชีรายการชุดข้อมูลพื้นฐาน (Baseline Data Inventory) ซึ่งบันทึกข้อมูลต้นทางสำหรับการวิเคราะห์หรือพัฒนาผลิตภัณฑ์ต่อ และบัญชีรายการผลิตภัณฑ์ข้อมูลและสารสนเทศ (Information Product Inventory) ซึ่งครอบคลุมรายงาน แดชบอร์ด API เครื่องมือ และแอปพลิเคชัน คณะที่ปรึกษาใช้เกณฑ์การรวมรายการสามชั้น เพื่อให้บัญชีทั้งสองชุดครอบคลุมทั้งข้อมูลที่กรมฯ มีส่วนพัฒนาและข้อมูลจากแหล่งอื่นที่เกี่ยวข้องกับภารกิจด้านการปรับตัว ดังนี้

1. ใช้ผลิตภัณฑ์และบริการที่กรมฯ พัฒนาเองหรือมีส่วนร่วมพัฒนาเป็นจุดตั้งต้น
2. สำรวจผลิตภัณฑ์ข้อมูลที่เผยแพร่อยู่แล้วในระดับโลก ระดับภูมิภาค และภายในประเทศ รวมถึงแพลตฟอร์มต่างประเทศที่เป็นที่ยอมรับในงานประเมินความเสี่ยงและวางแผนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ
3. เติมผลิตภัณฑ์และชุดข้อมูลของหน่วยงานอื่นที่เกี่ยวข้องกับภารกิจด้านการปรับตัว เช่น การบริหารจัดการน้ำและการตอบสนองต่อภัยพิบัติ

คณะที่ปรึกษาจัดหมวดหมู่รายการที่ผ่านเกณฑ์ตามโดเมนข้อมูลของแบบจำลองข้อมูลเชิงแนวคิด (Conceptual Data Model) ซึ่งออกแบบให้ครอบคลุมมิติของความเสี่ยงด้านภูมิอากาศ โดเมนข้อมูลจึงเป็นขอบเขตเชิงความหมายร่วมของบัญชีทั้งสองชุด พร้อมกันนี้ กรอบเมทาดาทาใช้มาตรฐาน มสพร. 1-2564 ของสำนักงานพัฒนารัฐบาลดิจิทัล (องค์การมหาชน) เป็นฐานเริ่มต้น โดยคัดเลือกเฉพาะฟิลด์ที่เหมาะกับบริบทของโครงการ และเพิ่มฟิลด์เฉพาะสำหรับข้อมูลความเสี่ยงและการปรับตัว เช่น โดเมนข้อมูลและมิติเวลาที่แยกข้อมูลในอดีตออกจากข้อมูลคาดการณ์อนาคต การออกแบบดังกล่าวช่วยให้ผู้ใช้ค้นหา ทำความเข้าใจ และเชื่อมโยงรายการจากบัญชีทั้งสองชุดได้ภายใต้กรอบเดียวกัน
