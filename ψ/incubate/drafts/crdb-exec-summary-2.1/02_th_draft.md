# 2.1 ขอบเขตของบัญชีรายการ

บัญชีรายการชุดข้อมูลพื้นฐาน (Baseline Data Inventory) บันทึกข้อมูลต้นทางสำหรับการวิเคราะห์หรือพัฒนาผลิตภัณฑ์ต่อ และบัญชีรายการผลิตภัณฑ์ข้อมูลและสารสนเทศ (Information Product Inventory) ซึ่งครอบคลุมรายงาน แดชบอร์ด API เครื่องมือ และแอปพลิเคชัน คณะที่ปรึกษาใช้เกณฑ์การรวมรายการ 3 ข้อ 
1. ใช้ผลิตภัณฑ์และบริการที่กรมฯ พัฒนาเองหรือมีส่วนร่วมพัฒนาเป็นจุดตั้งต้น
2. สำรวจผลิตภัณฑ์ข้อมูลที่เผยแพร่อยู่แล้วในระดับโลก ระดับภูมิภาค และภายในประเทศ รวมถึงแพลตฟอร์มต่างประเทศที่เป็นที่ยอมรับในงานประเมินความเสี่ยงและวางแผนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศ
3. ผลิตภัณฑ์และชุดข้อมูลของหน่วยงานอื่นที่เกี่ยวข้องกับภารกิจด้านการปรับตัว เช่น การบริหารจัดการน้ำและการตอบสนองต่อภัยพิบัติ

คณะที่ปรึกษาจัดหมวดหมู่รายการที่ผ่านเกณฑ์ตามโดเมนข้อมูลของแบบจำลองข้อมูลเชิงแนวคิด (Conceptual Data Model) ซึ่งออกแบบให้ครอบคลุมมิติของความเสี่ยงด้านภูมิอากาศและการปรับตัว โดเมนข้อมูลจึงเป็นนิยามกลางที่บัญชีทั้งสองชุดอ้างอิงถึง พร้อมกันนี้ กรอบข้อมูลอภิพันธ์ที่ใช้บันทึกระเบียนชุดข้อมูล ยึดตามมาตรฐาน มสพร. 1-2564 ของสำนักงานพัฒนารัฐบาลดิจิทัล เป็นจุดเริ่มต้น โดยคัดเลือกเฉพาะเขตข้อมูลที่เหมาะกับบริบทของโครงการ และเพิ่มเขตข้อมูลเฉพาะสำหรับข้อมูลความเสี่ยงและการปรับตัว เช่น โดเมนข้อมูลและมิติเวลาที่แยกข้อมูลในอดีตออกจากข้อมูลคาดการณ์อนาคต การออกแบบดังกล่าวช่วยให้ผู้ใช้ค้นหา ทำความเข้าใจ และเชื่อมโยงรายการจากบัญชีทั้งสองชุดได้ภายใต้กรอบเดียวกัน
