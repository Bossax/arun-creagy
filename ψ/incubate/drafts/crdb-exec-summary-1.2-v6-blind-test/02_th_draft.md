เนื้อหาและเมนูนำทางของเว็บไซต์กรมฯ ในปัจจุบันจัดเรียงตามหน่วยงานที่ผลิตเนื้อหาและโครงการที่ให้ทุน ผู้ใช้ที่เข้าเว็บไซต์ต้องคลิกผ่านชื่อกองหรือชื่อโครงการก่อน แล้วจึงค้นหาเองว่าเนื้อหาด้านภูมิอากาศ ความเสี่ยง มาตรการปรับตัว หรือกรณีศึกษาอยู่ในระบบย่อยใด แทนที่จะเริ่มจากคำถามหรือภารกิจของผู้ใช้เอง การประเมินฐานสารสนเทศเดิมของกรมฯ ในหัวข้อนี้จึงเริ่มจากการกำหนดว่าผู้ใช้แต่ละกลุ่มต้องทำอะไรให้สำเร็จ แล้วจึงตรวจสอบว่าสิ่งที่มีอยู่ตอบโจทย์นั้นได้มากน้อยเพียงใด ไม่ใช่เริ่มจากบัญชีรายการที่มีอยู่แล้วไล่หาข้อจำกัดต่อการใช้งานของแต่ละรายการ

โครงสร้างข้อมูลฯ ที่ต้องรองรับการวิเคราะห์และการรวบรวมข้อมูลเชิงนโยบายต้องการข้อมูลที่มีโครงสร้างและนำกลับมาใช้ซ้ำได้ ไม่ใช่เอกสารที่ต้องอ่านและคีย์ข้อมูลใหม่ด้วยมือ สัดส่วนที่เอนหนักไปทางเอกสารและเบาทางข้อมูลที่ระบบประมวลผลได้เช่นนี้ จึงชี้ตรงไปยังจุดที่การลงทุนระยะแรกของโครงสร้างข้อมูลฯ ควรมุ่งไป โดยไม่ต้องคาดเดาลำดับความสำคัญเอง

**ความพร้อมด้านการจัดการข้อมูลยังไม่เท่ากันทั่วทั้งกรมฯ**

กองขับเคลื่อนการลดก๊าซเรือนกระจกมีสายการจัดการข้อมูลที่ครบวงจรที่สุดในกรมฯ ตามผลการประชุมกลุ่มย่อยครั้งที่ 1 กลุ่มบัญชีก๊าซเรือนกระจกกำหนดขั้นตอนไว้ชัดเจน จุดติดต่อ (focal point) ของแต่ละภาคส่วนส่งข้อมูล ผ่านการตรวจสอบคุณภาพ (QA/QC) โดย AD&ADF จากนั้นส่งต่อ DET แล้วจึงเข้าสู่ขั้นตอนคำนวณเบื้องต้น (Pre-calculation) และการทบทวนโดย CRT ตามรอบรายงานทุกสองปี พร้อมเชื่อมต่อ API การปล่อยก๊าซเรือนกระจกเข้ากับระบบบัญชีข้อมูลและ CRT %%too many acronyms. too detailed for executive summary%%

การดูแลฐานทรัพย์สินดิจิทัล 391 รายการทั้งกรมฯ กระจายอยู่ในหลายสิบหน่วยงาน โดยกลุ่มงานประชาสัมพันธ์และสื่อสารสิ่งแวดล้อมถือครองอยู่ 214 รายการ คิดเป็นร้อยละ 55 ของทั้งหมด ซึ่งเป็นผลจากการที่หน่วยงานนี้ผลิตสื่อข่าวและวิดีโอเป็นหลัก ไม่ได้มาจากการได้รับมอบหมายบทบาทด้านธรรมาภิบาลข้อมูลโดยตรง เมื่อรวมกับกองยุทธศาสตร์และความร่วมมือระหว่างประเทศ (57 รายการ) และกลุ่มพัฒนาเทคโนโลยีดิจิทัล (25 รายการ) สามหน่วยงานแรกถือครองรวมกันถึง 296 รายการ หรือร้อยละ 76 ของทั้งหมด กลุ่มพัฒนาเทคโนโลยีดิจิทัลเองกำลังดำเนินโครงการศูนย์ข้อมูล CCIC เพื่อวิเคราะห์และรวมข้อมูลจากทุกกองเข้าเป็นฐานเดียว ซึ่งเป็นความพยายามแก้ปัญหาความกระจัดกระจายนี้ที่กรมฯ ริเริ่มขึ้นเอง

สายการจัดการข้อมูลที่ครบวงจรของกองขับเคลื่อนการลดก๊าซเรือนกระจกแสดงรูปแบบการทำงานที่โครงสร้างข้อมูลฯ ต่อยอดได้โดยไม่ต้องออกแบบใหม่ทั้งหมด ส่วนการกระจุกตัวของภาระดูแลข้อมูลที่เกิดจากผู้ที่ผลิตสื่อมากที่สุดเพียงอย่างเดียว แสดงให้เห็นว่าการจัดหมวดหมู่เนื้อหาใหม่ตามหัวข้อเพียงอย่างเดียวไม่สามารถแก้ปัญหาความรับผิดชอบที่ยังไม่ชัดเจนในส่วนอื่นของกรมฯ %%jumpy content%%

การประชุมกลุ่มย่อยกับเจ้าหน้าที่จากหลายกองระบุปัญหาการจัดการข้อมูลตรงกันสามเรื่อง

1. คำนิยามและคำศัพท์ด้านการปรับตัวฯ ยังไม่ตรงกันระหว่างกรมฯ กับหน่วยงานอื่น เช่น กระทรวงศึกษาธิการ เจ้าหน้าที่เสนอให้มีหน่วยงานกลางทำหน้าที่กำหนดคำนิยามให้เป็นมาตรฐานเดียวกัน
2. การตรวจสอบคุณภาพข้อมูล (QA/QC) ดำเนินการต่างกันไปในแต่ละกลุ่มงาน โดยไม่มีขั้นตอนมาตรฐานร่วมกัน และยังไม่ชัดเจนว่าหน่วยงานใดรับผิดชอบการตรวจสอบคุณภาพทั้งด้านข้อมูลนำเข้าและข้อมูลนำออก
3. ข้อมูลที่ส่งถึงปลายทางเผยแพร่มักล่าช้า ไม่ครบถ้วน หรืออยู่ในรูปแบบที่ไม่ตรงกับความต้องการ และยังไม่สามารถเชื่อมโยงผ่าน API กับสำนักงานทรัพยากรธรรมชาติและสิ่งแวดล้อมจังหวัด (ทสจ.) ได้

ปัญหาทั้งสามข้อนี้เจ้าหน้าที่ภายในกองต่าง ๆ ระบุขึ้นเองโดยอิสระต่อกัน จึงสะท้อนอุปสรรคระดับปฏิบัติงานจริงที่การจัดเรียงเนื้อหาใหม่เพียงอย่างเดียวแก้ไม่ได้ การจัดเมนูหรือหมวดหมู่เนื้อหาใหม่ไม่ช่วยแก้คำนิยามที่ยังไม่ตรงกัน ไม่ช่วยกำหนดผู้รับผิดชอบคุณภาพข้อมูล และไม่ช่วยสร้างรอบการส่งมอบข้อมูลที่แน่นอน ปัญหาทั้งสามข้อจึงเป็นเงื่อนไขขั้นต่ำที่การออกแบบกรอบธรรมาภิบาลข้อมูลของโครงสร้างข้อมูลฯ ต้องแก้ไขให้ได้

**ข้อสรุปสำหรับการตัดสินใจ 

จากข้อค้นพบข้างต้น สรุปได้เป็นสามข้อสำหรับการตัดสินใจกำหนดขอบเขตการลงทุนระยะถัดไป

1. องค์ความรู้ที่กรมฯ เผยแพร่อยู่แล้ว รวมทั้งรายงาน NAP และ A-BTR และระบบข้อมูลความเสี่ยงเชิงพื้นที่ พร้อมนำมาต่อยอดเป็นเนื้อหาตั้งต้นของโครงสร้างข้อมูลฯ ได้ทันที โดยไม่ต้องสร้างใหม่
2. สายการจัดการข้อมูลของกองขับเคลื่อนการลดก๊าซเรือนกระจก และการจัดจำแนกระดับการเปิดเผยข้อมูลที่กรมฯ มีอยู่แล้ว เป็นโครงร่างธรรมาภิบาลข้อมูลที่ต่อยอดได้ โดยไม่ต้องออกแบบใหม่ทั้งหมด
3. ช่องว่างที่บางที่สุดและเร่งด่วนที่สุดคือชุดข้อมูลที่เครื่องอ่านได้  (machine readable)  และผลิตภัณฑ์ข้อมูล ควบคู่กับปัญหาด้านธรรมาภิบาลสามเรื่องที่ถูกระบุในกระบวนการจัดประชุม ได้แก่ คำนิยามที่ยังไม่ตรงกัน ผู้รับผิดชอบคุณภาพข้อมูลที่ยังไม่ชัดเจน และรอบการปรับปรุงข้อมูลที่ยังไม่แน่นอน ซึ่งการจัดหมวดหมู่เนื้อหาใหม่เพียงอย่างเดียวไม่สามารถแก้ไม่ได้

การแยกสิ่งที่นำมาต่อยอดได้ทันทีออกจากสิ่งที่ต้องพัฒนาขึ้นใหม่เช่นนี้ คือข้อมูลที่ผู้บริหารต้องใช้ในการอนุมัติขอบเขตและลำดับความสำคัญของการลงทุนโครงสร้างข้อมูลฯ ในระยะถัดไป
