# กติกาการเขียนใหม่

- เขียนรายงานใหม่ทั้งฉบับโดยไม่แก้ประโยคจากร่างเดิม
- เนื้อหาสำหรับผู้อ่านมีเฉพาะโดเมนข้อมูล หน่วยข้อมูล ความสัมพันธ์ cardinality และกฎทางธุรกิจ
- ใช้คำว่า “โดเมนข้อมูล” และ “หน่วยข้อมูล”
- คงชื่อรหัสภาษาอังกฤษเพื่ออ้างอิงรายการข้อมูล
- ไม่กล่าวถึงไฟล์ แหล่งข้อมูล เวอร์ชัน trace การตรวจ การอนุมัติ หรือเหตุผลของผู้เขียน
- ไม่อธิบายกระบวนการออกแบบและไม่เสนอแนวทางพัฒนาระยะถัดไป
- เรียบเรียงภาษาไทยใหม่ตามหลักไวยากรณ์ ไม่แทนศัพท์อังกฤษแบบคำต่อคำ
- ใช้คำอธิบายสั้นและตรง โดยให้ตารางเป็นส่วนอ้างอิงหลัก

## สิ่งที่รักษาจากร่างก่อน

- จำนวน 8 โดเมนข้อมูล 45 หน่วยข้อมูล และ 51 ความสัมพันธ์
- ชื่อรหัส ประเภทคีย์หลัก cardinality และกฎทางธุรกิจ
- การจัดกลุ่มหน่วยข้อมูลและความสัมพันธ์เพื่อช่วยการค้นหา

## สิ่งที่ตัดออก

- ย่อหน้าว่าด้วยแหล่งข้อมูลและลำดับความน่าเชื่อถือ
- เหตุผลระหว่างออกแบบและการอธิบายว่าหน่วยข้อมูลใด “แก้ปัญหา” อะไร
- คำแนะนำต่อกรมฯ หรือผู้พัฒนาระบบ
- ข้อความประเมินคุณค่าและข้อความรับรองความถูกต้อง
- สำนวนที่เกิดจากการแทนศัพท์แบบคำต่อคำ
