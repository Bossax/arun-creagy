# แผนการเขียนหนังสือขอความเห็นชอบแนวทางการประเมินผลโครงการ

## หน้าที่ของหนังสือ

ขอให้กรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อมพิจารณาให้ความเห็นชอบแบบประเมินโครงการก่อนนำไปใช้รวบรวมความคิดเห็น เพื่อสนับสนุนการจัดทำผลการประเมินตาม TOR ข้อ 5.6

## โครงเรื่องและหน้าที่ของย่อหน้า

1. อ้างถึงโครงการ สัญญา และขอบเขตงานตาม TOR ข้อ 5.6
2. สรุปแนวทางประเมินในระดับภาพรวม ได้แก่ การรวบรวมความคิดเห็นจากผู้เข้าร่วม การพิจารณาความพึงพอใจและการรับรู้หรือความเข้าใจ และการวิเคราะห์ข้อมูลเชิงปริมาณร่วมกับข้อเสนอแนะเชิงคุณภาพ
3. ระบุว่ารายละเอียดปรากฏตามสิ่งที่ส่งมาด้วย และขอความเห็นชอบจากกรมฯ ก่อนนำแบบประเมินไปใช้ โดยสิ่งที่ส่งมาด้วยคือ “แบบประเมินโครงการพัฒนาชุดข้อมูล องค์ความรู้ ความเสี่ยง และผลกระทบจากการเปลี่ยนแปลงสภาพภูมิอากาศของประเทศไทย”

## ฐานข้อมูล

- `ψ/incubate/drafts/TOR5.6.md` — สาระของแนวทางและผลการประเมินที่แนวทางดังกล่าวรองรับ
- `ψ/incubate/DCCE/CRDB/inbox_source/ตัวอย่างหนังสือขอความเห็นชอบ.md` — รูปแบบและระดับรายละเอียดของหนังสือราชการตัวอย่าง
- ไม่พบ trace log ที่เกี่ยวข้องโดยตรงกับการขอความเห็นชอบแนวทางการประเมินผล จึงไม่นำ trace เรื่อง approval gate สำหรับการพัฒนาระบบมาใช้ เพราะเป็นคนละวัตถุประสงค์

## กติกาเฉพาะ

- ใช้ภาษาหนังสือทางการ กระชับ และมุ่งให้ผู้รับตัดสินใจ
- ใช้ “คณะที่ปรึกษา” เป็นผู้ดำเนินการเชิงวิชาการ และใช้ “บริษัทฯ” ในบริบทการยื่นหนังสือ
- กล่าวถึงวิธีประเมินในระดับภาพรวมเท่านั้น
- ไม่ใส่คะแนนเฉลี่ย รายละเอียดผู้ตอบ รายการข้อเสนอแนะ วิธีคำนวณ หรือข้อสรุปผลการประเมินในตัวหนังสือ
- ไม่กล่าวถึงผลการประเมินซึ่งจะเกิดขึ้นภายหลังการนำแบบประเมินไปใช้
- ไม่กล่าวว่ากรมฯ ได้ให้ความเห็นชอบแล้ว และไม่สรุปว่าการประเมินได้รับการรับรองก่อนมีหนังสือตอบรับ
- เว้นเลขที่หนังสือ วันที่ เลขที่สัญญา ชื่อผู้รับ และผู้ลงนามเป็นช่องสำหรับข้อมูลจริง
