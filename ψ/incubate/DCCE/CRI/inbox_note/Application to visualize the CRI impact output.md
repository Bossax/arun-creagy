
# Functions
1. visualize the 4 metrics from the gold layer database (csv) with several options
	1. Choose between the whole country map or a province map (Default whole country map,. Default province Chiang Mai, default metric percentile of affected household)
	2. Options to choose a specific year or the whole period (2560 to 2567) (default, whole period)
2. map plotting options
	1. percentile compared to the whole country's tambons
	2. absolute values
		1. option to add log scale
	3. show tambon name and value when hover the mouse above it
	4. show top 10 tambon's names (and provinces for the whole country map) and their values on the top right corner of the plot
	5. put the color bar at the bottom of the plot
	6. option to switch to histogram of percentiles
		1. show count and value when hovering the mouse over a bar
3. option to export the shown plot to png
