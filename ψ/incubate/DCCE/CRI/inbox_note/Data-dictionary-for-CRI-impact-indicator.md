## หมวดข้อมูลพื้นฐานของเหตุการณ์

| **หัวข้อข้อมูล**                                     | **รายละเอียด**                                                                                                                                       |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ประเภทภัย (Disaster Type)**                        | ระบุประเภทของสาธารณภัยที่เกิดขึ้น เช่น อัคคีภัย อุทกภัย หรือวาตภัย เพื่อใช้ในการจัดกลุ่มและวิเคราะห์ความเสี่ยง                                       |
| **วันที่เกิดภัย (Disaster Date)**                    | วันที่เริ่มเกิดเหตุการณ์จริง เพื่อใช้ในการลำดับเหตุการณ์                                                                                             |
| **วันที่ประกาศเขตช่วยเหลือ (Relief Declared Date)**  | วันที่ทางราชการออกประกาศเขตการให้ความช่วยเหลือผู้ประสบภัยพิบัติกรณีฉุกเฉิน ซึ่งเป็นจุดเริ่มต้นของการใช้เงินทดรองราชการ                               |
| **วันที่ประกาศพื้นที่ประสบภัย (Disaster Area Date)** | วันที่ออกประกาศระบุเขตพื้นที่ที่ได้รับผลกระทบจากสาธารณภัย เพื่อให้ส่วนราชการสามารถเข้าไปบริหารจัดการและให้ความช่วยเหลือประชาชนได้อย่างเต็มที่        |
| **วันที่ประกาศยุติภัย (End Disaster Date)**          | วันที่ทางการออกประกาศยืนยันความชัดเจนถึงการยกเลิกสถานการณ์ หรือวันที่เหตุการณ์สาธารณภัยในพื้นที่นั้นสิ้นสุดลงและเข้าสู่สภาวะปกติ                     |
| **สถานะ (Status) และ สถานการณ์ (Situation)**         | ระบุขั้นตอนปัจจุบันของเหตุการณ์ เช่น “ยุตเหตุการณ์” หรือ “คลี่คลาย” เพื่อให้ทราบว่าอยู่ในระยะตอบโต้หรือระยะฟื้นฟู                                    |
| **ชื่อเรื่อง (Title)**                               | ชื่อเรียกสรุปหรือชื่อในการแจ้งเหตุของเหตุการณ์สาธารณภัยที่เกิดขึ้นในแต่ละครั้ง เพื่อใช้ในการอ้างอิงและจำแนกเหตุการณ์ในระบบฐานข้อมูล                  |
| **ลักษณะ / สาเหตุ (Cause)**                          | มูลเหตุหรือต้นตอที่ทำให้เกิดภัยนั้น ๆ ซึ่งอาจเกิดจากธรรมชาติ (เช่น ฝนตกหนักต่อเนื่อง) หรือเกิดจากการกระทำของมนุษย์ (เช่น อุบัติเหตุ หรือการวางเพลิง) |

## หมวดผลกระทบต่อพื้นที่และการปกครอง (Affected Area)

|**หัวข้อข้อมูล**|**รายละเอียด**|
|---|---|
|**รหัสจังหวัด / อำเภอ / ตำบล เทศบาล / หมู่บ้าน (Code)**|รหัสมาตรฐานที่ใช้ในการระบุพิกัดการปกครอง เพื่อให้ข้อมูลสามารถเชื่อมโยงกับฐานข้อมูลอื่นได้|
|**จำนวนอำเภอ / ตำบล / เทศบาล / หมู่บ้านที่ประสบภัย (Name)**|ยอดรวมของพื้นที่การปกครองที่ได้รับความเสียหายในเหตุการณ์|
|**ชื่อศูนย์เขต (Zone Center Name)**|ศูนย์ป้องกันและบรรเทาสาธารณภัยเขตที่รับผิดชอบในพื้นที่นั้น ๆ|

## หมวดผลกระทบต่อบุคคล (Impact on people)

|**หัวข้อข้อมูล**|**รายละเอียด**|
|---|---|
|**ผู้ได้รับผลกระทบ (คน) (Affected People)**|จำนวนประชากรที่อาศัยอยู่ในพื้นที่ประสบภัยและได้รับความเดือดร้อนโดยตรง นับตามจำนวนคนจริง|
|**ผู้ที่ได้รับผลกระทบ (ครัวเรือน) (Affected Households)**|หน่วยที่ใช้ในการรับเพื่อการเยียวยา โดย 1 ครัวเรือนอาจประกอบด้วยสมาชิกหลายคน ข้อมูลนี้จะใช้ในการอนุมัติงบประมาณช่วยเหลือต่อครอบครัว|
|**ผู้อพยพ (คน/ครัวเรือน) (Evacuated People & Households)**|จำนวนผู้ที่ต้องย้ายออกจากที่อยู่อาศัยเดิมไปยังศูนย์พักพิงชั่วคราว หรือพื้นที่ปลอดภัยเนื่องจากไม่สามารถอาศัยอยู่ในบ้านเรือนได้|
|**ผู้เสียชีวิต (Deaths)**|จำนวนผู้ที่เสียชีวิตยืนยันจากเหตุการณ์|
|**ผู้สูญหาย (Missing)**|จำนวนผู้ที่ยังไม่สามารถระบุที่อยู่ได้หลังเกิดเหตุ|
|**ผู้บาดเจ็บ (Injured)**|จำนวนผู้ที่ได้รับอันตรายแก่กายจากการประสบภัย|

## หมวดความเสียหายด้านทรัพย์สินและเศรษฐกิจ (Damage Categories)

|**หัวข้อข้อมูล**|**รายละเอียด**|
|---|---|
|**ด้านที่อยู่อาศัย (Housing Damage)**|จำนวนบ้านเรือนที่ถูกทำลายหรือเสียหาย (หน่วย: แห่ง)|
|**ด้านธุรกิจ (Business Damage)**|จำนวนสถานประกอบการหรือร้านค้าที่ได้รับผลกระทบ (หน่วย: แห่ง)|
|**ด้านการเกษตร (Agriculture Damage)**|พื้นที่ทำการเกษตรที่ได้รับความเสียหาย (หน่วย: ไร่)|
|**ด้านปศุสัตว์ (Livestock Damage)**|จำนวนของสัตว์เลี้ยงที่ตายหรือสูญหายจากเหตุการณ์ภัยพิบัติ ครอบคลุมถึงสัตว์เศรษฐกิจ เช่น โค กระบือ สุกร และสัตว์ปีก (หน่วย: ตัว)|
|**ด้านประมง (Fishing Damage)**|พื้นที่หรือลักษณะของกิจการเพาะเลี้ยงสัตว์น้ำที่ได้รับความเสียหาย เช่น บ่อปลา บ่อกุ้ง กระชัง หรือพื้นที่ทำการประมงอื่น ๆ ที่ได้รับผลกระทบ (หน่วย: บ่อ / กระชัง / ไร่)|
|**ด้านคมนาคม (Transport Damage)**|จำนวนจุดหรือสถานที่ของเส้นทางสัญจรที่ได้รับความเสียหายจนไม่สามารถใช้งานได้ตามปกติ เช่น ถนนชำรุด สะพานขาด หรือท่อระบายน้ำสาธารณะเสียหาย (หน่วย: แห่ง)|
|**ด้านสาธารณสุข (Health Damage)**|จำนวนสถานพยาบาล โรงพยาบาลส่งเสริมสุขภาพตำบล หรือศูนย์บริการสาธารณสุข ที่ได้รับความเสียหายจากภัยพิบัติ (หน่วย: แห่ง)|
|**ด้านศาสนาวัฒนธรรม (Culture Damage)**|จำนวนศาสนสถานหรือแหล่งโบราณสถานที่ได้รับผลกระทบ เช่น วัด มัสยิด โบสถ์ สำนักสงฆ์ หรือโบราณคดีที่สำคัญในพื้นที่ (หน่วย: แห่ง)|
|**ด้านสถานศึกษา (Education Damage)**|จำนวนอาคารเรียน โรงเรียน หรือสนามกีฬาในสังกัดสถานศึกษาที่ได้รับความเสียหายจนส่งผลกระทบต่อการเรียนการสอน (หน่วย: แห่ง)|
|**ด้านสาธารณูปโภค (Utilities Damage)**|จำนวนจุดติดตั้งหรือระบบโครงสร้างพื้นฐานที่จำเป็นต่อการดำรงชีพที่เสียหาย เช่น ระบบไฟฟ้า ประปา หรือระบบโทรคมนาคมสาธารณะ (หน่วย: แห่ง)|
|**ด้านสถานที่ราชการ (Govt Damage)**|จำนวนอาคารสำนักงาน หรือสถานที่ปฏิบัติราชการของหน่วยงานภาครัฐที่ได้รับความเสียหายจากเหตุการณ์ (หน่วย: แห่ง)|
|**ด้านสาธารณประโยชน์อื่น (Other Public Benefits 1)**|จำนวนสิ่งก่อสร้างเพื่อประโยชน์สาธารณะอื่น ๆ ที่ไม่อยู่ในหมวดหมู่ข้างต้น (หน่วย: แห่ง)|
|**ด้านทรัพย์สินราชการ/เอกชน (Other Public Benefits 2)**|จำนวนสิ่งของ อุปกรณ์ หรือทรัพย์สินในเชิงหน่วยนับ ทั้งในส่วนของทางราชการและเอกชนที่เกี่ยวข้องกับการจัดบริการสาธารณประโยชน์ (หน่วย: หน่วย)|

## หมายเหตุและข้อจำกัดของข้อมูล

- **การสูญหายของข้อมูล (Missing Data):** ในบางรายการอาจปรากฏช่องว่าง ซึ่งไม่ได้หมายความว่าความเสียหายเป็น 0 แต่อาจเกิดจากหน่วยงานในพื้นที่ยังไม่ได้รายงานข้อมูลเข้ามาในระบบกลาง หรือข้อมูลบางส่วนถูกบันทึกไว้ในหน่วยงานเฉพาะทางอื่น (เช่น กระทรวงเกษตรและสหกรณ์)
