# README — ตัวชี้วัด 4 ตัวที่แสดงบนแผนที่ (จ.เชียงราย)

เอกสารนี้อธิบาย “ตัวชี้วัด 4 ตัว” ที่ถูกนำไปแสดงบนแผนที่ระดับตำบล ว่าคำนวณอย่างไร และควรตีความอย่างไร

## 1) Affected Households — ครัวเรือนที่ได้รับผลกระทบสะสม

**ความหมาย**: จำนวนครัวเรือนที่ได้รับผลกระทบจากเหตุภัยพิบัติ (รวมสะสมตามช่วงปีที่กำหนด)

**วิธีคำนวณ (แนวคิด)**
- รวม (`sum`) ค่า *Affected Households* ของทุกเหตุการณ์ที่อยู่ในตำบลเดียวกัน ภายในช่วงปีวิเคราะห์

**การตีความ**
- ค่าสูง = ตำบลนั้นมีภาระผลกระทบต่อ “ครัวเรือน” มาก (ตามข้อมูลที่บันทึก)
- ค่า 0 อาจหมายถึง “ไม่มีบันทึกเหตุการณ์ที่มีครัวเรือนได้รับผลกระทบ” ในช่วงปีนั้น ๆ (ไม่ใช่ข้อผิดพลาดของแผนที่โดยอัตโนมัติ)

## 2) Affected People — จำนวนประชาชนที่ได้รับผลกระทบสะสม

**ความหมาย**: จำนวนประชาชนที่ได้รับผลกระทบจากเหตุภัยพิบัติ (รวมสะสมตามช่วงปีที่กำหนด)

**วิธีคำนวณ (แนวคิด)**
- รวม (`sum`) ค่า *Affected People* ของทุกเหตุการณ์ที่อยู่ในตำบลเดียวกัน ภายในช่วงปีวิเคราะห์

**การตีความ**
- ค่าสูง = ตำบลนั้นมีภาระผลกระทบต่อ “คน” มาก (ตามข้อมูลที่บันทึก)
- เป็น “จำนวนคน” (absolute) ยังไม่ normalize ด้วยจำนวนประชากร ดังนั้นอย่าตีความเป็นอัตราต่อหัว

## 3) Deaths — จำนวนผู้เสียชีวิตสะสม

**ความหมาย**: จำนวนผู้เสียชีวิตจากเหตุภัยพิบัติ (รวมสะสมตามช่วงปีที่กำหนด)

**วิธีคำนวณ (แนวคิด)**
- รวม (`sum`) ค่า *Deaths* ของทุกเหตุการณ์ที่อยู่ในตำบลเดียวกัน ภายในช่วงปีวิเคราะห์

**การตีความ**
- ค่าสูง = ความรุนแรงด้านชีวิตสูง หรือมีเหตุที่นำไปสู่การเสียชีวิตบ่อย/มาก
- ตัวเลขมักมีสเกลเล็กและกระจุกในบางพื้นที่ → แนะนำให้อ่านร่วมกับชนิดภัย/ปี และข้อจำกัดของการรายงาน

## 4) Avg YoY Change — การเปลี่ยนแปลงเทียบปีก่อน (YoY) ของครัวเรือนที่ได้รับผลกระทบ

ตัวชี้วัดนี้ใช้เพื่อดู “แนวโน้มเทียบปี” ของ *Affected Households* (เช่น ปี 2567 เทียบปี 2566) ในระดับตำบล

**ความหมาย**: อัตราการเปลี่ยนแปลงของจำนวนครัวเรือนที่ได้รับผลกระทบในปีเป้าหมาย เทียบกับปีก่อนหน้า

**วิธีคำนวณ**
- ให้ `HH_2567` = ผลรวม *Affected Households* ในปี 2567 ของตำบลนั้น
- ให้ `HH_2566` = ผลรวม *Affected Households* ในปี 2566 ของตำบลนั้น
- คำนวณเป็น **percent change**:
  - `(HH_2567 - HH_2566) / HH_2566`

**เงื่อนไขสำคัญ**
- ถ้า `HH_2566` ไม่มีข้อมูล หรือ `HH_2566 = 0` ⇒ **คำนวณไม่ได้** (แสดงเป็นค่าว่าง/NaN)
  - เหตุผล: หารด้วย 0 หรือไม่มี baseline จะทำให้เปอร์เซ็นต์ผิดความหมาย

**การตีความ**
- ค่า > 0 : ปี 2567 เพิ่มขึ้นเมื่อเทียบปี 2566
- ค่า < 0 : ปี 2567 ลดลงเมื่อเทียบปี 2566
- ค่า = 1.0 หมายถึงเพิ่มขึ้น 100% (เป็น 2 เท่าของปี 2566)
- เป็นตัวชี้วัด “แนวโน้มเทียบปี” ไม่ใช่ปริมาณผลกระทบสะสมระยะยาว
