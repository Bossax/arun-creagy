# Checklist การปรับปรุงเล่มร่างรายงานฉบับสมบูรณ์ (Final Report)

**โครงการ:** พัฒนาชุดข้อมูลองค์ความรู้ความเสี่ยงและผลกระทบจากการเปลี่ยนแปลงสภาพภูมิอากาศของประเทศไทย

**การส่งมอบ:** งวดที่ 4 (ความเห็นของคณะกรรมการ)

## 1. บทที่ 2: พัฒนาโครงสร้างข้อมูลด้านการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศของประเทศ (National Climate Adaptation Information Framework)

- [x] **ข้อ 5.2.7 ปรับปรุงเพิ่มเติมต่อ (ร่าง) โครงสร้างข้อมูลด้านการปรับตัวฯ และ (ร่าง) โครงสร้างการบริหารจัดการข้อมูลฯ**
    
    - [x] จัดทำรายละเอียดข้อมูลการปรับปรุงแก้ไข โดยระบุ:
        
        - [x] ส่วนหรือหัวข้อของเนื้อหาที่ดำเนินการปรับปรุง
            
        - [x] ประเด็นที่มีการแก้ไข
            
        - [x] รายละเอียดของเนื้อหาที่ปรับปรุงหรือเพิ่มเติม เพื่อให้เห็นสาระสำคัญและขอบเขตของการปรับปรุงแก้ไขในแต่ละส่วนอย่างชัดเจน
            
- [x] **ข้อ 5.2.8 จัดประชุมกลุ่มย่อย (Focus group) เพื่อหารือกับเจ้าหน้าที่ สคส.**
    
    - [x] ปรับปรุงชื่อหัวข้อให้ถูกต้องตามขอบเขตของงาน (TOR) ที่กำหนด
        

## 2. บทที่ 3: การจัดทำบัญชีรายการผลิตภัณฑ์ข้อมูลและสารสนเทศ และบัญชีรายการชุดข้อมูลพื้นฐานฯ

- [x] **ข้อ 5.3.1 ทบทวนและสังเคราะห์ข้อมูลพื้นฐานและสารสนเทศ ณ ปัจจุบัน**
    
    - [x] เพิ่มเติมรายละเอียดเนื้อหาเพื่ออธิบายที่มาและแหล่งข้อมูลของข้อมูลที่นำมาใช้ประกอบการจัดทำรายงาน
        
    - [x] ระบุแหล่งอ้างอิงที่เกี่ยวข้องให้ชัดเจน เพื่อให้สามารถตรวจสอบที่มาและความถูกต้องของข้อมูลได้
        
- [x] **ข้อ 5.3.2 ประเมินสถานะของข้อมูลพื้นฐานและสารสนเทศ และความต้องการใช้ข้อมูล (สัมภาษณ์เชิงลึก Key Stakeholders)**
    
    - [x] ปรับเอกสารแนบ: นำใบลงทะเบียนเข้าร่วมการสัมภาษณ์ออก โดยคงไว้เฉพาะรายชื่อผู้เข้าร่วมประชุมและภาพถ่ายประกอบการสัมภาษณ์
        
    - [x] การสัมภาษณ์ครั้งที่ 7: ปรับปรุงรายชื่อผู้เข้าร่วมการสัมภาษณ์ โดยเพิ่มเติมชื่อ-นามสกุลจริงของผู้เข้าร่วม ลำดับที่ 6–9 ให้ครบถ้วนและถูกต้อง
        
- [x] **ข้อ 5.3.3 จัดประชุมระดมความเห็นกับหน่วยงานที่เกี่ยวข้อง**
    
    - [x] สรุปรายชื่อผู้เข้าร่วมประชุม โดยแยกและระบุจำนวนผู้เข้าร่วมตามรูปแบบการเข้าร่วม:
        
        - [x] ระบบออนไลน์ (Online)
            
        - [x] ณ สถานที่จัดประชุม (On-site)
            
    - [x] ย้ายรายงานการประชุมไปอยู่ในส่วนเนื้อหาหลักของรายงาน เพื่อให้สอดคล้องกับลำดับและโครงสร้างของเนื้อหา
        
    - [x] จัดรูปภาพประกอบทั้งหมดไปแสดงไว้ในส่วนภาคผนวก
        
- [x] **ข้อ 5.3.8 วิเคราะห์ช่องว่างระหว่างอุปทานและอุปสงค์ของข้อมูล (Gap Analysis)**
    
    - [x] ทำการวิเคราะห์ข้อมูลใหม่ โดยพิจารณาความต้องการใช้ข้อมูลให้ครอบคลุมและสอดคล้องกับวัตถุประสงค์ของการดำเนินงาน
        
    - [x] เปรียบเทียบข้อมูลและผลการวิเคราะห์ความต้องการของข้อมูล
        
    - [x] จัดทำบัญชีรายการข้อมูล (Data Inventory) ให้ครบถ้วนสมบูรณ์
