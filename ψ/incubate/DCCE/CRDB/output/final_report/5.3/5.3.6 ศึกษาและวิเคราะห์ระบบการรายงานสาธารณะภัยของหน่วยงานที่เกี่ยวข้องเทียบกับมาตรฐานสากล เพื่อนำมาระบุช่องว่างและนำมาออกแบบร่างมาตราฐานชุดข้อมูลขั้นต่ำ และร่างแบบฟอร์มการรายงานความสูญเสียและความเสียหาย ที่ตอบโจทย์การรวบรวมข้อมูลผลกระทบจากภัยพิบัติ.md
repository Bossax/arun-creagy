# 5.3.6 ศึกษาและวิเคราะห์ระบบการรายงานสาธารณภัยของหน่วยงานที่เกี่ยวข้องเทียบกับมาตรฐานสากล เพื่อนำมาระบุช่องว่างและนำมาออกแบบร่างมาตรฐานชุดข้อมูลขั้นต่ำ และร่างแบบฟอร์มการรายงานความสูญเสียและความเสียหาย ที่ตอบโจทย์การรวบรวมข้อมูลผลกระทบจากภัยพิบัติ

### 1. การทบทวนกลไกการจัดการความเสี่ยงจากสาธารณภัยของประเทศไทย
การจัดการความเสี่ยงจากสาธารณภัยของประเทศไทยตั้งอยู่บนพระราชบัญญัติป้องกันและบรรเทาสาธารณภัย พ.ศ. 2550 และแผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติ พ.ศ. 2564–2570 ที่กำหนดให้รัฐต้องดำเนินงานครอบคลุมตั้งแต่ระยะก่อนเกิดภัย ระยะเผชิญเหตุ และระยะหลังเกิดภัยอย่างต่อเนื่อง โดยข้อมูลของหน่วยงานภาครัฐระบุว่า ประเทศไทยใช้วงจรการจัดการภัยพิบัติที่ครอบคลุม 4 ระยะ ได้แก่ การเตรียมพร้อม การลดความเสี่ยง การตอบสนอง และการฟื้นฟู พร้อมทั้งเน้นการเปลี่ยนผ่านจากการรับมือเหตุการณ์เฉพาะหน้าไปสู่การบริหารความเสี่ยงแบบองค์รวมมากขึ้น ใจความสำคัญของกรอบนี้คือการกำหนดว่าในแต่ละช่วงของภัยพิบัติ หน่วยงานใดต้องทำหน้าที่อะไร ใช้ข้อมูลชนิดใด และส่งต่อข้อมูลผ่านกลไกใดเพื่อให้การตัดสินใจของรัฐเกิดขึ้นได้อย่างรวดเร็วและมีประสิทธิภาพ

ในระยะการเตรียมพร้อม แผนการป้องกันและบรรเทาสาธารณภัยแห่งชาติได้ระบุหน่วยงานจำนวนมากที่เกี่ยวข้อง เช่น กรมอุตุนิยมวิทยา กรมทรัพยากรน้ำ กระทรวงเกษตรและสหกรณ์ กองทัพ เป็นต้น ในการเฝ้าระวัง การแจ้งเตือนภัย และการเตรียมกำลังตอบสนอง โดยในทางปฏิบัติมีการใช้ระบบเตือนภัยล่วงหน้าที่เชื่อมกับเครื่องมือตรวจวัดอัตโนมัติ สถานีวัดระดับน้ำทะเล สถานีวัดปริมาณฝน ตลอดจนเครือข่ายอาสาสมัครและบุคลากรในพื้นที่เพื่อกระจายคำเตือนไปถึงชุมชน ข้อมูลที่ใช้ในระยะนี้จึงเป็นข้อมูลเพื่อการตรวจจับความเสี่ยง การระบุพื้นที่เสี่ยง และการเตรียมการปฏิบัติงานล่วงหน้า

ในระยะการลดความเสี่ยง กลไกของประเทศขยายจากการเฝ้าระวังไปสู่การจัดการปัจจัยเสี่ยงด้านโครงสร้างพื้นฐาน ผ่านการจัดทำฐานข้อมูลความเสี่ยงรายภัย การพัฒนาแผนที่พื้นที่เสี่ยงน้ำท่วม ดินถล่ม และแผ่นดินไหว ตลอดจนการผลักดันให้การลดความเสี่ยงถูกบูรณาการเข้าสู่แผนงานของหน่วยงานภาคส่วนต่าง ๆ ความหมายทางวิชาการของระยะนี้คือ ข้อมูลต้องรองรับการประเมินความเสี่ยง การจัดลำดับความสำคัญของการลงทุน และการกำหนดมาตรการป้องกันในระดับพื้นที่และระดับกลุ่มงาน เพื่อวางรากฐานในการป้องกันและลดโอกาสการเกิดผลกระทบในพื้นที่ต่าง ๆ

เมื่อเข้าสู่ระยะการตอบสนอง โครงสร้างการจัดการสาธารณภัยของไทยจะทำงานผ่านสายการบัญชาการแบบลำดับชั้นตามระดับความรุนแรงของสถานการณ์ โดยผู้อำนวยการท้องถิ่นและผู้อำนวยการอำเภอทำหน้าที่ควบคุมและสั่งการในเหตุขนาดเล็ก ผู้อำนวยการจังหวัดทำหน้าที่บัญชาการในเหตุขนาดกลาง ส่วนเหตุขนาดใหญ่จะยกระดับไปสู่กองบัญชาการป้องกันและบรรเทาสาธารณภัยแห่งชาติ และในกรณีร้ายแรงอย่างยิ่งอาจยกระดับถึงนายกรัฐมนตรีหรือรองนายกรัฐมนตรีที่ได้รับมอบหมาย ภายใต้โครงสร้างนี้ องค์กรปกครองส่วนท้องถิ่นทำหน้าที่เป็นหน่วยงานหลักรับมือด่านแรกในระดับพื้นที่ ขณะที่ข้อมูลสถานการณ์ ข้อมูลความเสียหายเบื้องต้น การปฏิบัติงานช่วยเหลือ และความต้องการเร่งด่วนจะถูกส่งต่อจากระดับพื้นที่ ผ่านระดับอำเภอและจังหวัด ก่อนบูรณาการเข้าสู่ส่วนกลางเพื่อใช้ประกอบการตัดสินใจหน้างาน ผลที่ตามมาคือ ข้อมูลในระยะเผชิญเหตุถูกออกแบบเพื่อรองรับการรายงานสถานการณ์ที่รวดเร็วและการสั่งการช่วยเหลือประชาชนเป็นสำคัญ

สำหรับระยะการฟื้นฟู ประเทศไทยให้ความสำคัญกับหลักการฟื้นฟูที่ดีกว่าเดิมและทนทานต่อภัยพิบัติในอนาคต (Build Back Better) และใช้กระบวนการประเมินความต้องการหลังเกิดภัยเพื่อสนับสนุนการวางแผนฟื้นฟู การจัดหาแหล่งเงิน และการลงทุนในโครงสร้างพื้นฐานเพื่อลดความเปราะบางในอนาคต ระยะนี้ต้องการข้อมูลที่มีความละเอียดและชัดเจน โดยวิเคราะห์ระดับของผลกระทบต่อทรัพย์สิน ภาคการผลิต บริการสาธารณะ และความต้องการฟื้นฟูของแต่ละภาคส่วนอย่างเป็นระบบ เพื่อเป็นข้อมูลประกอบการจัดสรรงบประมาณฟื้นฟูและการบูรณะระบบสาธารณูปโภคได้อย่างถูกต้อง

### 2. แนวปฏิบัติด้านการจัดเก็บข้อมูลของกรมป้องกันและบรรเทาสาธารณภัย (ปภ.) และมาตรฐาน PDNA

ภายใต้การดำเนินงานตามกรอบการจัดการสาธารณภัยทั้ง 4 ระยะดังกล่าว กรมป้องกันและบรรเทาสาธารณภัย (ปภ.) ทำหน้าที่เป็นหน่วยงานกลางในการกำหนดแนวทาง ประสานงาน สนับสนุนการดำเนินงาน และเชื่อมการทำงานระหว่างหน่วยงานภาคส่วนต่าง ๆ ส่วนองค์กรปกครองส่วนท้องถิ่นรับผิดชอบการจัดการความเสี่ยงในเขตพื้นที่ของตนโดยตรง โครงสร้างเช่นนี้ทำให้การจัดการสาธารณภัยของไทยมีความชัดเจนในเรื่องอำนาจหน้าที่และการสั่งการ ทว่าในด้านข้อมูลแล้ว ข้อมูลเกี่ยวกับความเสี่ยง ความเสียหาย การช่วยเหลือ และความต้องการฟื้นฟู ถูกสำรวจ เก็บรวบรวมและถือครองโดยหลายหน่วยงานตั้งแต่ต้นทาง ซึ่งทำให้การเข้าใจความเสียหายจากภัยพิบัติในมิติสถิติตัวเลขมีความท้าทายด้านข้อมูลเป็นอย่างมาก

นอกจากนั้น เนื่องจากข้อบังคับทางกฎหมายที่มอบหมายให้กรมป้องกันและบรรเทาสาธารณภัยเป็นหน่วยงานกลางในการบูรณาการข้อมูลสถานการณ์และจัดทำรายงานข้อมูลสาธารณภัยของประเทศ กรมป้องกันและบรรเทาสาธารณภัยจึงจัดเก็บข้อมูลโดยมีจุดมุ่งหมายหลักเพื่อการรับรู้สถานการณ์อย่างรวดเร็วสำหรับการตัดสินใจ การประสานความช่วยเหลือ และการดำเนินการช่วยเหลือของภาครัฐ โดยแบบรายงานหลักที่ใช้อยู่ในปัจจุบันคือ "แบบรายงานเหตุด่วนสาธารณภัย" ซึ่งองค์กรปกครองส่วนท้องถิ่นรายงานต่ออำเภอ อำเภอรายงานต่อจังหวัด และจังหวัดบันทึกข้อมูลเข้าสู่ระบบศูนย์ข้อมูลสาธารณภัยของประเทศ เพื่อใช้เป็นข้อมูลกลางในการติดตามภาพรวมของเหตุการณ์ทั่วประเทศ การใช้งานข้อมูลลักษณะนี้จึงเน้นการติดตามและรายงาน (Reporting and Monitoring) เป็นหลัก แทนการคำนวณมูลค่าทางเศรษฐกิจโดยตรง

อีกวัตถุประสงค์สำคัญที่กำหนดรูปแบบการเก็บข้อมูลคือภารกิจการช่วยเหลือผู้ประสบภัยตามระเบียบกระทรวงการคลังว่าด้วยเงินทดรองราชการ เพื่อช่วยเหลือผู้ประสบภัยพิบัติกรณีฉุกเฉินโดยตรง กล่าวคือ ข้อมูลที่ถูกจัดเก็บต้องมีความจำเป็นและเพียงพอต่อการตรวจสอบขอบเขตภัยพิบัติ จำนวนประชาชนที่ประสบภัย ความเสียหายของทรัพย์สินสิ่งปลูกสร้าง และความต้องการเบื้องต้นในพื้นที่ ข้อมูลดังกล่าวจึงเป็นข้อมูลเพื่อการรายงานสถานการณ์และประกอบขั้นตอนการอนุมัติวงเงินช่วยเหลือผู้ประสบภัยตามระเบียบทางคลัง ซึ่งแตกต่างจากการรวบรวมเพื่อวิเคราะห์ผลกระทบทางเศรษฐกิจสะสมในระยะฟื้นฟู

ชุดข้อมูลที่ปรากฏในฐานข้อมูลเปิดของ ปภ. ที่แสดงระดับผลกระทบเบื้องต้นแบ่งออกเป็นสองกลุ่มข้อมูล กลุ่มแรกเป็นชุดข้อมูลจากแบบประเมินระยะต้น ซึ่งเน้นการระบุจำนวนและจำแนกข้อมูลความเสียหายและผลกระทบพื้นฐาน ได้แก่ จำนวนประชาชนที่ได้รับผลกระทบ ผู้บาดเจ็บ ผู้สูญหาย ผู้เสียชีวิต ข้อมูลประชากรแฝงและกลุ่มเปราะบาง รวมถึงความเสียหายของบ้านเรือนและสาธารณูปโภคที่ระบุลักษณะความเสียหายเป็นเสียหายบางส่วนแต่ยังอยู่อาศัยได้ เสียหายบางส่วนและไม่สามารถอยู่อาศัยได้ หรือเสียหายทั้งหมด

นอกจากข้อมูลผลกระทบโดยตรงแล้ว ปภ. ยังมีชุดข้อมูลการเบิกจ่ายเงินทดรองราชการของส่วนราชการเพื่อดำเนินงานในด้านต่าง ๆ ที่เกี่ยวข้องกับการตอบสนองและฟื้นฟูหลังเกิดภัย เช่น การบรรเทาสาธารณภัย ด้านเกษตร ด้านประมง ด้านการดำรงชีพของประชาชน ด้านการแพทย์และสาธารณสุข และการดำเนินงานด้านการป้องกันภัยล่วงหน้า โดยการดำเนินงานด้านการป้องกันล่วงหน้าคือเงินงบประมาณเบิกจ่ายเพื่อเตรียมการลดผลกระทบก่อนเกิดภัย ทว่าเงินส่วนนี้มีเงื่อนไขและขั้นตอนการอนุมัติที่ซับซ้อน เนื่องจากผู้ว่าราชการจังหวัดในฐานะผู้อนุมัติจะต้องมีรายละเอียดคำชี้แจงความจำเป็นหากท้ายที่สุดไม่เกิดภัยพิบัติจริง ตัวเลขเหล่านี้รวบรวมและสรุปโดยกรมป้องกันและบรรเทาสาธารณภัยส่วนกลาง ขณะที่ตัวเลขความเสียหายทางมูลค่าที่ระบุในรายงานเหตุด่วนสาธารณภัยซึ่งท้องถิ่นสำรวจ มักเป็นเพียงค่าประมาณการเบื้องต้นของหน่วยงานท้องถิ่น เนื่องจากข้อจำกัดด้านความเร็วและเครื่องมือในการประเมินราคาซ่อมสร้างจริงในพื้นที่ อีกทั้งหลักเกณฑ์การจ่ายช่วยเหลือของรัฐได้รับการกำหนดเพดานขั้นสูงต่อครัวเรือนไว้แล้วโดยคณะรัฐมนตรี ซึ่งไม่สะท้อนถึงมูลค่าความเสียหายจริงของสิ่งปลูกสร้าง ทำให้การประเมินราคาความเสียหายที่แท้จริงในพื้นที่ประสบภัยยังไม่สามารถสะท้อนผลกระทบได้อย่างสมบูรณ์

อย่างไรก็ตาม เมื่อความต้องการของรัฐขยับจากการรับรู้สถานการณ์และการจัดสรรความช่วยเหลือเร่งด่วน ไปสู่การประเมินผลกระทบเพื่อการฟื้นฟูหลังภัยพิบัติ กรอบการทำงานที่ใช้ย่อมต้องปรับปรุงตามไปด้วย ในจุดนี้ กรอบการประเมินความต้องการหลังเกิดภัยพิบัติ (Post Disaster Need Assessment: PDNA) ทำหน้าที่เป็นกระบวนการประเมินระยะหลังที่เริ่มทำงานเมื่อสถานการณ์แจ้งเหตุฉุกเฉินสิ้นสุดลง โดยกรอบการประเมินความต้องการหลังเกิดภัยพิบัติประเทศไทยที่ถูกพัฒนาขึ้นโดยกรม ปภ. ได้แบ่งลำดับงานออกเป็นระยะตามช่วงเวลาหลังเกิดภัย ระยะที่ 0 ถึง 2 เป็นการประเมินความเสียหายและความต้องการความช่วยเหลือเบื้องต้น (Damage and Need Assessment: DaNA) ขณะที่ระยะที่ 3 คือการประเมินความต้องการหลังเกิดภัยพิบัติ (PDNA) และระยะที่ 4 คือการจัดทำยุทธศาสตร์การฟื้นฟู ซึ่งหากการสำรวจและจัดเก็บข้อมูลดำเนินงานตามแนวทางนี้ หน่วยงานภาครัฐจะมีข้อมูลสนับสนุนการตัดสินใจในแต่ละช่วงได้อย่างเหมาะสม เช่น ในช่วงแรกสามารถเข้าใจผลกระทบเบื้องต้นและจัดสรรสิ่งบรรเทาทุกข์ เมื่อภัยพิบัติสิ้นสุดลงสามารถรวบรวมรายละเอียดทรัพย์สินเสียหายเพื่อคำนวณงบประมาณฟื้นฟูตามหลักการฟื้นฟูที่ดีกว่าเดิมและปลอดภัยกว่าเดิม

หลักการของกระบวนการประเมินความต้องการหลังภัยพิบัติต้องอาศัยการเปรียบเทียบระหว่างสภาวะปกติก่อนเกิดภัย กับ สภาวะหลังเกิดภัย โดยแยกผลกระทบจากเหตุการณ์ภัยพิบัติออกเป็น 3 มิติ ได้แก่ ความเสียหายทางกายภาพ (Damage) ความสูญเสียทางเศรษฐกิจ (Loss) และความต้องการฟื้นฟู (Recovery Need) ความเสียหายทางกายภาพ (Damage) หมายถึง ทรัพย์สิน โครงสร้างพื้นฐาน หรือปัจจัยการผลิตที่ถูกทำลายหรือชำรุดเสียหายโดยตรงจากเหตุการณ์ เช่น บ้านเรือนพังเสียหาย พื้นที่เพาะปลูกน้ำท่วม หรือเครื่องจักรชำรุดเสียหาย ส่วนความสูญเสีย (Loss) หมายถึง การเปลี่ยนแปลงของผลผลิต รายได้ บริการ หรือค่าใช้จ่ายที่เกิดขึ้นในช่วงฟื้นฟูเมื่อเทียบกับสภาพปกติ เช่น รายได้เกษตรที่หายไปจากผลผลิตที่เสียหาย หรือค่าใช้จ่ายดำเนินงานที่เพิ่มขึ้นเพื่อให้การทำงานดำเนินต่อไปได้ ความแตกต่างนี้มีนัยสำคัญต่อการประเมินความเชื่อมโยงระหว่างระดับความเสียหายทางกายภาพกับการสะดุดลงของระบบเศรษฐกิจและวิถีชีวิตประชาชนในพื้นที่

เมื่อพิจารณารายละเอียดข้อมูลที่ต้องรวบรวมตลอดวงจรการจัดการสาธารณภัย จะเห็นว่าข้อมูลที่จำเป็นนั้น มีความละเอียดมากขึ้นในขั้นตอนถัดไป เช่น ระยะที่ 0 หรือระยะเตรียมพร้อม กำหนดให้ใช้แบบฟอร์มเพื่อรวบรวมข้อมูลฐาน (Baseline) ของพื้นที่ เช่น จำนวนประชากร ข้อมูลครัวเรือน กลุ่มเปราะบาง ที่ตั้งของหน่วยงาน บริการสาธารณสุข โครงสร้างพื้นฐานไฟฟ้า ประปา ถนน ระบบสื่อสาร พื้นที่เกษตร แหล่งน้ำ ข้อมูลอุตุนิยมวิทยา ข้อมูลอุทกวิทยา แผนที่การใช้ประโยชน์ที่ดิน และประวัติการเกิดภัยย้อนหลัง ซึ่งข้อมูลชุดนี้มีบทบาทสำคัญในการสร้างแบบจำลองกรณีฐานสำหรับการประเมินเปรียบเทียบในอนาคต ระยะที่ 1 คือช่วง 0–72 ชั่วโมงหลังเกิดภัย ข้อมูลที่จัดเก็บจะเป็นข้อมูลรายงานเหตุฉุกเฉินและผลกระทบหลัก เช่น ประเภทภัย วันเวลา พื้นที่ได้รับผลกระทบ สถิติจำนวนผู้ได้รับผลกระทบ ผู้บาดเจ็บ ผู้สูญหาย ผู้เสียชีวิต ข้อมูลสิ่งปลูกสร้างและโครงสร้างพื้นฐานชำรุดเบื้องต้น และความต้องการบรรเทาทุกข์เร่งด่วน ส่วนระยะที่ 2 ภายใน 14 วันหลังเกิดภัย จะขยายการสำรวจผลกระทบในมิติต่าง ๆ เช่น แหล่งรายอาชีพ ครอบครัว ความเสียหายสาธารณูปโภค น้ำ สุขาภิบาล สุขภาพ ที่พักชั่วคราว การศึกษา และรายการความช่วยเหลือที่ได้รับมอบแล้ว

ในระยะที่ 3 และ 4 ซึ่งเป็นช่วงเชื่อมต่อระหว่างการกู้ภัยและการฟื้นฟู กรอบการประเมินความต้องการหลังเกิดภัยพิบัติจะเข้ามามีบทบาทหลักเพื่อรวบรวมและวิเคราะห์ข้อมูลความสูญเสียทางเศรษฐกิจรวมถึงแผนการบูรณะ โดยในภาคเกษตรกรรมจะเริ่มจากการจัดเตรียมข้อมูลฐาน (Baseline) รายครัวเรือนเกษตร เช่น ขนาดครัวเรือน พื้นที่ทำกิน รายได้ รายจ่าย ปริมาณและราคาผลผลิตเฉลี่ย และการถือครองเครื่องมือทำการเกษตร เมล็ดพันธุ์ และปัจจัยการผลิตต่าง ๆ จากนั้นจึงเข้าสู่ขั้นตอนประเมินความเสียหายทางกายภาพและวิเคราะห์ปริมาณผลผลิตหรือรายได้ที่สูญเสียไปในช่วงฟื้นฟูเพื่อตรวจสอบความถูกต้องของข้อมูลร่วมกับผู้แทนภาคส่วนต่าง ๆ ก่อนสรุปเป็นแผนงานบูรณะฟื้นฟูระบบการผลิตในพื้นที่ต่อไป

เมื่อมองตามขั้นตอนเหล่านี้ ความท้าทายของการนำมาตรฐาน PDNA มาใช้ปฏิบัติงานจึงตั้งอยู่บนวัตถุประสงค์และขอบเขตข้อมูลที่แตกต่างกัน โดยระบบรายงานของ ปภ. ในระยะแรกมุ่งเน้นการรายงานสถานการณ์ที่รวดเร็วเพื่อสั่งการและเบิกจ่ายเยียวยาเบื้องต้น ขณะที่ PDNA เริ่มต้นจากความต้องการวิเคราะห์เปรียบเทียบข้อมูลฐานก่อนและหลังเกิดภัย การแยกมิติความเสียหายและความสูญเสีย รวมถึงการทวนสอบสถิติร่วมกับผู้แทนจากหน่วยงานต่าง ๆ ดังนั้น จุดสำคัญของการพัฒนาระบบข้อมูลด้านความสูญเสียและความเสียหายของประเทศคือการกำหนดความเชื่อมโยงของข้อมูลที่รายงานในช่วงเหตุฉุกเฉินไปใช้ในการประเมินผลกระทบเพื่อการฟื้นฟู 

### 3. การทบทวนมาตรฐานข้อมูลสาธารณภัยระดับสากล

มาตรฐานข้อมูลสาธารณภัยระดับสากลที่เลือกมาศึกษาวิเคราะห์ประกอบด้วย DesInventar และ DaLA ซึ่งพัฒนาขึ้นโดยองค์กรระหว่างประเทศเพื่อสร้างมาตรฐานในการจัดเก็บและวิเคราะห์ข้อมูลภัยพิบัติร่วมกันทั่วโลก และใช้เป็นต้นแบบกรอบทฤษฎีสำหรับประยุกต์ใช้ในบริบทของประเทศไทย

**DesInventar**
DesInventar ได้รับการสนับสนุนหลักจากสำนักงานเพื่อการลดความเสี่ยงจากภัยพิบัติแห่งสหประชาชาติ (UNDRR) มีจุดเริ่มต้นจากการจัดทำระบบบันทึกในภูมิภาคละตินอเมริกาเพื่อปรับปรุงฐานข้อมูลให้สามารถบันทึกเหตุการณ์ภัยพิบัติขนาดเล็กและขนาดกลางที่เกิดขึ้นบ่อยครั้งในระดับท้องถิ่น นอกเหนือจากเหตุการณ์ขนาดใหญ่ที่มีรายงานเด่นชัด เนื่องจากเหตุการณ์ย่อยเหล่านี้ส่งผลกระทบสะสมต่อชีวิตและความเป็นอยู่ของประชาชนในพื้นที่อย่างเป็นระบบ DesInventar เป็นเครื่องมือเชิงระเบียบวิธีและซอฟต์แวร์ในการทำทะเบียนบันทึกเหตุการณ์ระดับชาติ มุ่งรวบรวมและวิเคราะห์ข้อมูลผลกระทบตามรูปแบบมาตรฐานเดียวกันเพื่อประโยชน์ในการเปรียบเทียบสถิติ โดยมีวัตถุประสงค์หลักเพื่อสร้างระบบข้อมูลกลางที่เพียงพอสำหรับการจัดทำแผนภูมิความเสี่ยงและการประเมินแนวโน้มภัยพิบัติในระยะยาว

ขั้นตอนการดำเนินงานของ DesInventar เริ่มจากรวบรวมข้อมูลเหตุการณ์จากระบบข้อมูลของราชการ รายงานสถานการณ์ บทความวิชาการ และแหล่งข่าวสารในพื้นที่ นำมาบันทึกข้อมูลตามช่องมาตรฐานที่กำหนดไว้ เช่น มิติด้านเวลา มิติด้านพื้นที่ ประเภทภัย สาเหตุ และผลกระทบต่อชีวิต ทรัพย์สิน และโครงสร้างพื้นฐาน โดยมีจุดตั้งต้นเป็นระเบียนข้อมูลภัยพิบัติ (Data Card) บันทึกประเภทเหตุการณ์ วันเวลา พื้นที่ จำนวนผู้เสียชีวิต ผู้บาดเจ็บ ผู้สูญหาย และประชากรที่ประสบภัย พร้อมเชื่อมโยงกับรหัสพื้นที่ปกครองอย่างสม่ำเสมอ เพื่อให้สามารถคัดกรองข้อมูลสถิติและประมวลผลผ่านตาราง กราฟ หรือแผนที่วิเคราะห์การกระจายตัวของภัยพิบัติในระดับพื้นที่ย่อยได้อย่างแม่นยำ

ข้อมูลนำเข้าของ DesInventar จึงเป็นรายละเอียดพื้นฐานของเหตุการณ์และสถิติผลกระทบขั้นต่ำที่รายงานจากพื้นที่ประสบภัย เช่น รายการความสูญเสียด้านประชากรและการชำรุดเสียหายเบื้องต้นของทรัพย์สินทางการเกษตรหรือสาธารณูปโภค ส่วนผลลัพธ์ของระบบคือสารสนเทศทะเบียนภัยพิบัติระดับประเทศที่สนับสนุนการสืบค้น วิเคราะห์ซ้ำ และสร้างรายงานเชิงลึกเพื่อส่งมอบให้แก่หน่วยงานวางแผนนโยบายใช้ประกอบการจัดทำระบบประเมินความเสี่ยงและกำหนดทิศทางเตรียมความพร้อมในอนาคต

**DaLA (Damage, Loss, and Need Assessment)**

DaLA เป็นระเบียบวิธีประเมินผลกระทบหลังภัยพิบัติที่พัฒนาขึ้นโดยคณะกรรมาธิการเศรษฐกิจแห่งสหประชาชาติสำหรับภูมิภาคละตินอเมริกาและแคริบเบียน (UNECLAC) และนำมาใช้อย่างแพร่หลายโดยธนาคารโลก (World Bank) วัตถุประสงค์หลักของ DaLA คือการแปลงผลกระทบทางกายภาพของภัยพิบัติเป็นมูลค่าความเสียหายทางเศรษฐกิจ เพื่อสนับสนุนขั้นตอนการวางแผนฟื้นฟู การจัดลำดับความสำคัญของภาคการผลิต และการระดมงบประมาณช่วยเหลือบนฐานการวิเคราะห์ข้อมูลทางเศรษฐศาสตร์

หัวใจการประเมินของ DaLA อยู่ที่แบบจำลองสินทรัพย์และกระแสกิจกรรมทางเศรษฐกิจ (Asset-Flow Model) ซึ่งแบ่งผลกระทบออกเป็น 2 มิติหลัก ได้แก่:
1. **สินทรัพย์ทางกายภาพ**: รายการทรัพย์สินและสิ่งปลูกสร้างที่มีตัวตน เช่น อาคาร บ้านเรือน ถนน ระบบไฟฟ้า หรือเครื่องมือทำการผลิต
2. **กระแสกิจกรรมทางเศรษฐกิจ**: บริการ ผลผลิต รายได้ และค่าใช้จ่ายดำเนินงานที่เกิดขึ้นหลังภัยพิบัติจนกว่าระบบการทำงานจะเข้าสู่สภาวะปกติ

ความเสียหาย (Damage) ตามคำนิยามนี้ หมายถึง มูลค่าทรัพย์สินทางกายภาพที่ถูกทำลายหรือเสียหายโดยตรง ประเมินจากต้นทุนซ่อมแซมหรือจัดหาทดแทนตามราคาตลาดในสภาวะปกติ ขณะที่ความสูญเสีย (Loss) หมายถึง รายได้ ผลผลิต หรือบริการทางเศรษฐกิจที่ขาดหายไปในช่วงเวลาฟื้นฟู รวมถึงค่าใช้จ่ายดำเนินงานที่เพิ่มขึ้นจากภาวะปกติ การวิเคราะห์ด้วยวิธีนี้ทำให้เห็นว่าภัยพิบัติไม่เพียงส่งผลกระทบสะสมต่อตัวทรัพย์สินในทันที แต่ยังสร้างความเสียหายต่อเนื่องในรูปของรายได้หรือกระแสเศรษฐกิจที่หยุดชะงักลงเป็นระยะเวลานาน

ขั้นตอนการประเมิน DaLA เริ่มจากการกำหนดขอบเขตภาคส่วนที่ได้รับผลกระทบ การจัดเตรียมข้อมูลฐาน (Baseline) ก่อนเกิดภัยในแต่ละสาขา เช่น ราคากลาง มูลค่าการผลิตปกติ จากนั้นสำรวจความเสียหายทางกายภาพหลังภัยพิบัติเพื่อบันทึกส่วนต่างและคำนวณมูลค่ารวมของความเสียหายและความสูญเสียทางเศรษฐกิจรายภาคส่วน เพื่อเสนอแผนงานและจัดสรรงบประมาณฟื้นฟูไปยังกระทรวงที่เกี่ยวข้องและองค์กรสนับสนุนทางการเงินต่อไป

หากเปรียบเทียบในเชิงหน้าที่ DesInventar ทำหน้าที่สนับสนุนระบบทะเบียนเหตุการณ์และการระบุพิกัดภัยพิบัติในระดับพื้นที่เพื่อวิเคราะห์ประวัติความเสี่ยงระยะยาว ส่วน DaLA ทำหน้าที่เป็นระบบคำนวณมูลค่าความเสียหายทางเศรษฐกิจรายภาคส่วนเพื่อจัดทำแผนบูรณะฟื้นฟู ซึ่งข้อมูลของทั้งสองระบบสามารถประสานงานร่วมกันเพื่อเพิ่มประสิทธิภาพการจัดการภัยพิบัติ

การศึกษามาตรฐานสากลทั้งสองระบบชี้ให้เห็นแนวทางการปรับปรุงระบบจัดเก็บข้อมูลของประเทศไทย โดยควรบูรณาการข้อมูลจากฐานการสำรวจปกติของหน่วยงานในพื้นที่เข้ากับกรอบวิเคราะห์ที่ได้มาตรฐาน เพื่อประยุกต์ใช้ข้อมูลเหล่านี้ในการสนับสนุนการกำหนดนโยบายและมาตรการป้องกันภัยพิบัติระดับชาติอย่างแท้จริง

### 4. การเปรียบเทียบ: ข้อกำหนดตามมาตรฐาน PDNA กับสภาพความเป็นจริงของข้อมูล ปภ.

เมื่อเปรียบเทียบข้อกำหนดของมาตรฐาน PDNA กับแนวปฏิบัติการจัดเก็บข้อมูลของกรม ปภ. จะพบช่องว่างสำคัญระหว่างโครงสร้างข้อมูลในอุดมคติกับสภาพความเป็นจริง แม้ไทยจะมีกรอบประเมินผลกระทบระยะหลังรองรับ แต่ทางปฏิบัติยังขาดทรัพยากรสำหรับหน่วยงานท้องถิ่น ขาดฐานข้อมูลกลางด้านมูลค่าทรัพย์สิน ขาดข้อมูลฐาน (Baseline) ก่อนเกิดภัยเพื่อเปรียบเทียบ และยังต้องมีกระบวนการทวนสอบที่ซับซ้อน การประเมินตามกรอบ PDNA แบบเต็มรูปแบบจึงสร้างภาระเกินกว่าสภาพความเป็นจริงของเจ้าหน้าที่ระดับท้องถิ่น

อย่างไรก็ตาม ระบบปัจจุบันไม่ได้ไร้ประสิทธิภาพเสียทีเดียว เพราะหน่วยงานท้องถิ่นและจังหวัดมีการจัดเก็บสถิติผลกระทบพื้นฐานอยู่แล้ว เช่น จำนวนผู้บาดเจ็บ ผู้สูญหาย การอพยพ และจำนวนสิ่งปลูกสร้างชำรุดเสียหาย ซึ่งตอบโจทย์การรายงานเหตุด่วนและการเยียวยาเบื้องต้นได้อย่างรวดเร็ว แต่หากต้องการวิเคราะห์มูลค่าความสูญเสียทางเศรษฐกิจเพื่อจัดทำแผนฟื้นฟูตามมาตรฐาน PDNA ข้อมูลที่มีอยู่ยังจำเป็นต้องได้รับการพัฒนาเพิ่มเติม เนื่องจากข้อมูลสถิติเชิงปริมาณเบื้องต้น ยังไม่สามารถแปลงเป็นมูลค่าความเสียหายเชิงเศรษฐศาสตร์ได้อย่างสมบูรณ์ 

ข้อจำกัดทั้งหมดนี้ชี้ให้เห็นว่า การบังคับใช้แบบฟอร์ม PDNA ที่ซับซ้อนกับทุกท้องถิ่นตั้งแต่ต้นทาง เป็นไปได้ยากในทางปฏิบัติ ทางออกที่เป็นไปได้ในเชิงปฏบัติจึงไม่ใช่การรื้อระบบเดิมทิ้ง แต่คือการนำชุดข้อมูลที่ท้องถิ่นเก็บอยู่แล้ว มาใช้เป็นพื้นฐานแล้วสร้างกลไกเชื่อมโยงข้อมูล (Data Mapping) ไปสู่การประเมินมูลค่าทางเศรษฐกิจในระยะต่อไป

### 5. หลักการออกแบบชุดข้อมูลพื้นฐานขั้นต่ำ (MVD Design Principles)
การออกแบบชุดข้อมูลพื้นฐานขั้นต่ำในส่วนนี้เริ่มจากการนำชุดข้อมูลเหตุการณ์และผลกระทบที่มีอยู่ในระบบปฏิบัติงานของกรมป้องกันและบรรเทาสาธารณภัยมาประยุกต์ร่วมกับมาตรฐานสากล เพื่อยกระดับความสามารถในการวิเคราะห์ความเสียหาย ความสูญเสีย และความต้องการฟื้นฟูให้มีระดับความน่าเชื่อถือและสอดคล้องกับแนวทางการประเมินผลกระทบทางเศรษฐกิจของสำนักงานสภาพัฒนาการเศรษฐกิจและสังคมแห่งชาติ ดังนั้น หลักการออกแบบชุดข้อมูลพื้นฐานขั้นต่ำ หรือ Minimum Viable Dataset (MVD) จึงกำหนดขึ้นเพื่อสร้างจุดเชื่อมต่อระหว่างข้อมูลเหตุการณ์ปัจจุบัน ช่องว่างเชิงระบบเมื่อเทียบกับสากล และความต้องการข้อมูลสนับสนุนการตัดสินใจระดับประเทศ

หลักการแรก คือ การต่อยอดและขยายขีดความสามารถของข้อมูลในระบบปฏิบัติงานปกติของกรมป้องกันและบรรเทาสาธารณภัย มุ่งบูรณาการข้อมูลเบื้องต้นที่จัดเก็บได้จริงในระดับท้องถิ่น เช่น สถิติจำนวนผู้ได้รับผลกระทบ การอพยพ ผู้เสียชีวิต ผู้บาดเจ็บ และหมวดความเสียหายเบื้องต้นรายภาคส่วน (เช่น ที่อยู่อาศัย เกษตร ประมง ปศุสัตว์ และสาธารณูปโภค) โครงสร้างข้อมูลที่ออกแบบใหม่จำเป็นต้องสอดคล้องกับขั้นตอนการกรอกข้อมูลของเจ้าหน้าที่ในพื้นที่ เพื่อลดขั้นตอนและภาระงานในการปฏิบัติงานจริง

หลักการที่สอง คือ การแยกเก็บประเภทข้อมูลตามวัตถุประสงค์และการใช้งานอย่างชัดเจน โดยเฉพาะการจำแนกข้อมูลเหตุการณ์ ข้อมูลผลกระทบ รายการความเสียหายทางกายภาพ รายการความสูญเสียทางเศรษฐกิจ และรายละเอียดความต้องการฟื้นฟู เนื่องจากปัญหาสำคัญของโครงสร้างข้อมูลเดิมคือการจัดเก็บข้อมูลคนละประเภทปะปนในระบบรายงานเดียวกัน เช่น ตัวเลขสถิติสิ่งปลูกสร้างเสียหายกับวงเงินช่วยเหลือที่รัฐอนุมัติ ซึ่งตัวเลขเงินชดเชยเป็นข้อมูลสะท้อนการจัดสรรงบประมาณเยียวยาของรัฐ แต่ไม่สะท้อนถึงมูลค่าความเสียหายจริงของสิ่งปลูกสร้าง การแยกโครงสร้างข้อมูลประเภทต่าง ๆ อย่างชัดเจนตั้งแต่ต้นจะป้องกันความสับสนในการวิเคราะห์และการนำข้อมูลไปเปรียบเทียบในระยะยาว

หลักการที่สาม คือ การจัดตารางบันทึกข้อมูลความเสียหายทางกายภาพและความสูญเสียทางเศรษฐกิจแยกส่วนจากกัน เนื่องจากขั้นตอนประเมินและแหล่งข้อมูลของทั้งสองส่วนมีความแตกต่างกัน โดยข้อมูลความเสียหายทางกายภาพประเมินจากปริมาณและลักษณะชำรุดของทรัพย์สินร่วมกับต้นทุนราคาตลาดสำหรับการทดแทนหรือซ่อมสร้าง ขณะที่ความสูญเสียทางเศรษฐกิจประเมินจากการหยุดชะงักของผลผลิต รายได้ หรือค่าใช้จ่ายที่เพิ่มขึ้นในช่วงเวลาบูรณะฟื้นฟู ดังนั้น ฐานข้อมูลเป้าหมายจึงจัดเก็บข้อมูลสองประเภทนี้แยกจากกันเพื่อความถูกต้องแม่นยำในการคำนวณและประมวลผล

หลักการที่สี่ คือ การบันทึกข้อมูลกำกับบริบทและแหล่งที่มาของข้อมูลการประเมินควบคู่กับสถิติตัวเลขเสมอ เพื่อใช้ตรวจสอบและยืนยันน้ำหนักความน่าเชื่อถือ โดยระบบรายงานต้องมีเขตข้อมูลที่เก็บบริบทแวดล้อม เช่น ระยะเวลาประเมิน วิธีประเมิน รายชื่อหน่วยงานและทีมผู้รับผิดชอบ สถานะการทวนสอบสถิติ และเอกสารหลักเกณฑ์ที่ใช้อ้างอิง เพื่อให้ผู้ใช้งานสามารถทวนสอบประวัติและความถูกต้องย้อนหลังของข้อมูลแต่ละชุดได้อย่างเป็นระบบ

หลักการที่ห้า คือ การกำหนดให้ข้อมูลความต้องการฟื้นฟูและก่อสร้างใหม่เป็นผลลัพธ์ปลายทางที่มาจากการวิเคราะห์เปรียบเทียบข้อมูลผลกระทบ โดยกำหนดบันทึกข้อมูลเมื่อผ่านพ้นระยะประเมินผลกระทบที่ชัดเจนแล้ว แนวทางนี้ช่วยแยกแยะข้อมูลข้อเสนอทางนโยบายหรือแผนจัดสรรทรัพยากรออกจากรายงานสถิติข้อเท็จจริงในพื้นที่ประสบภัยอย่างเด่นชัด โดยข้อมูลความต้องการเหล่านี้ต้องมีกลไกเชื่อมโยงย้อนกลับไปยังระเบียนข้อมูลความเสียหายและกระแสเศรษฐกิจที่ชำรุดเสียหายเพื่อรองรับน้ำหนักของแผนบูรณะโครงการนั้น ๆ

ชุดข้อมูลขั้นต่ำของความสูญเสียและความเสียหาย (Loss and Damage Minimum Viable Data) ที่จะนำเสนอในส่วนถัดไป ยึดตามหลักการออกแบบทั้ง 5 ข้อนี้ เพื่อจัดทำตารางฐานข้อมูลที่มีความสมบูรณ์และเอื้อต่อการปฏิบัติงาน โดยไม่สร้างภาระเพิ่มเติมแก่หน่วยงานปฏิบัติงานในพื้นที่เกินความจำเป็น เพื่อให้ชุดข้อมูลสามารถนำไปใช้งานอย่างแพร่หลายในอนาคต

### 6. มาตรฐานชุดข้อมูลขั้นต่ำและร่างแบบฟอร์มการรายงานความสูญเสียและความเสียหาย
โครงสร้างทางเทคนิคของชุดข้อมูลขั้นต่ำที่เสนอในหัวข้อนี้ มีจุดประสงค์เพื่อแปลงหลักการออกแบบในหัวข้อก่อนหน้าให้เป็นโครงสร้างข้อมูลที่ใช้งานได้จริง โดยยึดหลักสำคัญว่า ข้อมูลแจ้งเหตุ ข้อมูลผลกระทบเบื้องต้น ข้อมูลประเมินความเสียหาย ข้อมูลความสูญเสีย และข้อมูลความต้องการฟื้นฟู ไม่ควรถูกเก็บปะปนกันในฐานข้อมูลเดียว แต่ควรถูกแยกออกเป็นฐานข้อมูลเชิงสัมพันธ์ (Relational Database) ที่ทำหน้าที่ต่างกันแต่เชื่อมโยงกันอย่างชัดเจน

ตารางหลักที่เสนอสำหรับ MVD มี 6 ตาราง โดยแต่ละตารางทำหน้าที่ต่างกัน ดังนี้

| ตาราง | หน้าที่หลัก | ใช้ตอบคำถามอะไร | ช่วงเวลาที่ข้อมูลเริ่มถูกบันทึก |
| :--- | :--- | :--- | :--- |
| `DISASTER_EVENT` | ระเบียนหลักของเหตุการณ์ | เกิดอะไรขึ้น เมื่อไร ภัยประเภทใด และกระทบคนเบื้องต้นอย่างไร | ช่วงแจ้งเหตุและประเมินระยะแรก |
| `EVENT_LOCATION` | รายละเอียดพื้นที่ที่ได้รับผลกระทบ | เหตุการณ์เดียวกระทบพื้นที่ใดบ้าง | ช่วงแจ้งเหตุและทวนสอบพื้นที่ |
| `ASSESSMENT_CONTEXT` | บริบทของการประเมิน | ข้อมูลชุดนี้มาจากระยะใด ใช้วิธีใด ใครประเมิน และผ่านการทวนสอบหรือยัง | ทุกระยะที่มีการประเมิน |
| `LD_PHYSICAL_DAMAGE` | ข้อมูลความเสียหายทางกายภาพ | อะไรเสียหาย เสียหายเท่าไร และประเมินมูลค่าอย่างไร | หลังมีการประเมินทรัพย์สิน/โครงสร้าง |
| `LD_ECONOMIC_LOSS` | ข้อมูลความสูญเสียทางเศรษฐกิจ | รายได้ ผลผลิต หรือบริการที่หายไปมีมูลค่าเท่าใดเมื่อเทียบกับสภาวะปกติ | หลังมีข้อมูลฐานและช่วงเวลาวิเคราะห์ |
| `LD_RECOVERY_RECONSTRUCTION_NEEDS` | ข้อมูลความต้องการฟื้นฟูและก่อสร้างใหม่ | ต้องใช้ทรัพยากรอะไรในการฟื้นฟูหรือสร้างกลับ | หลังการประเมินและทวนสอบ |

ความสัมพันธ์หลักของตารางสามารถอธิบายได้อย่างย่อดังนี้

- `DISASTER_EVENT` 1 รายการ เชื่อมไปสู่ `EVENT_LOCATION` ได้หลายรายการ
- `DISASTER_EVENT` 1 รายการ เชื่อมไปสู่ `ASSESSMENT_CONTEXT` ได้หลายรายการ
- `ASSESSMENT_CONTEXT` 1 รายการ เชื่อมไปสู่ `LD_PHYSICAL_DAMAGE` ได้หลายรายการ
- `ASSESSMENT_CONTEXT` 1 รายการ เชื่อมไปสู่ `LD_ECONOMIC_LOSS` ได้หลายรายการ
- `ASSESSMENT_CONTEXT` 1 รายการ เชื่อมไปสู่ `LD_RECOVERY_RECONSTRUCTION_NEEDS` ได้หลายรายการ

ตาราง `ASSESSMENT_CONTEXT` มีความสำคัญเป็นพิเศษ เพราะเป็นจุดที่ช่วยแยกข้อมูลแจ้งเหตุระยะแรกออกจากข้อมูลประเมินระยะหลัง หากไม่มีตารางนี้ ตัวเลขจากการรายงานเร่งด่วนในช่วงต้นของเหตุการณ์อาจถูกอ่านปนกับตัวเลขที่ผ่านการทวนสอบในระยะหลังได้ง่าย การมีตารางนี้จึงทำให้ฐานข้อมูลสามารถเก็บได้ว่าข้อมูลชุดหนึ่งอยู่ในระยะใด ใครเป็นผู้จัดทำ ใช้วิธีใด และผ่านการทวนสอบแล้วหรือยัง

เพื่อให้ผู้อ่านเข้าใจโครงสร้างได้ชัดเจนในระดับเขตข้อมูล ส่วนต่อไปนี้เป็นพจนานุกรมข้อมูล (Data Dictionary) ของแต่ละตารางหลัก

**1) พจนานุกรมข้อมูล (Data Dictionary): `DISASTER_EVENT`**

| ชื่อเขตข้อมูล | ชนิดข้อมูล | ความหมาย / การใช้งาน |
| :--- | :--- | :--- |
| `disaster_event_id` | VARCHAR(50) | รหัสอ้างอิงหลักของเหตุการณ์ ใช้เป็นกุญแจหลักของฐานข้อมูล |
| `source_assessment_ref` | VARCHAR(100) | รหัสอ้างอิงจากแบบประเมินต้นทางของหน่วยงาน เมื่อมีการใช้จริง |
| `hazard_type` | ENUM | ประเภทภัยตามการจัดหมวดหมู่กลาง |
| `event_name` | VARCHAR(255) | ชื่อเหตุการณ์ในรูปแบบที่มนุษย์อ่านเข้าใจ |
| `event_start_date` | DATE | วันที่เริ่มเกิดเหตุหรือวันที่ยืนยันผลกระทบครั้งแรก |
| `event_end_date` | DATE | วันที่เหตุยุติหรือวันที่ผลกระทบอยู่ในระดับคงที่ |
| `event_duration_days` | INT | จำนวนวันของเหตุการณ์ คำนวณจากวันเริ่มและวันสิ้นสุดเมื่อมีข้อมูล |
| `event_status` | ENUM | สถานะของเหตุการณ์ เช่น รับรายงาน อยู่ระหว่างประเมิน ยืนยันแล้ว หรือปิดเหตุ |
| `reporting_level` | ENUM | ระดับของการรายงาน เช่น จังหวัด อำเภอ ตำบล หรือหลายพื้นที่ |
| `num_affected_pop` | INT | จำนวนประชาชนที่ได้รับผลกระทบโดยตรง |
| `num_evacuated` | INT | จำนวนประชาชนที่อพยพ |
| `num_dead` | INT | จำนวนผู้เสียชีวิตที่ยืนยันแล้ว |
| `num_missing` | INT | จำนวนผู้สูญหายที่ยืนยันแล้ว |
| `num_injured` | INT | จำนวนผู้บาดเจ็บที่ยืนยันแล้ว |
| `response_phase_note` | TEXT | หมายเหตุสำคัญเกี่ยวกับเงื่อนไขของการรับข้อมูลหรือข้อจำกัดของข้อมูลระยะแรก |
| `created_by_agency` | VARCHAR(255) | หน่วยงานที่สร้างหรือดูแลระเบียนเหตุการณ์ |
| `record_created_at` | DATETIME | วันเวลาในการสร้างระเบียน |
| `record_updated_at` | DATETIME | วันเวลาที่ปรับปรุงข้อมูลครั้งล่าสุด |

**2) พจนานุกรมข้อมูล (Data Dictionary): `EVENT_LOCATION`**

| ชื่อเขตข้อมูล | ชนิดข้อมูล | ความหมาย / การใช้งาน |
| :--- | :--- | :--- |
| `event_location_id` | VARCHAR(50) | รหัสประจำระเบียนพื้นที่ที่ได้รับผลกระทบ |
| `disaster_event_id` | VARCHAR(50) | รหัสเชื่อมกลับไปยัง `DISASTER_EVENT` |
| `admin_level` | ENUM | ระดับพื้นที่ เช่น จังหวัด อำเภอ ตำบล หมู่บ้าน หรือขอบเขตพื้นที่อื่น |
| `location_code` | VARCHAR(20) | รหัสพื้นที่ตามมาตรฐานที่ใช้อ้างอิง |
| `location_name` | VARCHAR(255) | ชื่อพื้นที่ที่มนุษย์อ่านเข้าใจ |
| `is_primary_impact_area` | BOOLEAN | ใช้ระบุว่าพื้นที่นี้เป็นพื้นที่ผลกระทบหลักหรือไม่ |
| `spatial_reference_note` | TEXT | หมายเหตุเรื่องขอบเขตพื้นที่ แหล่งที่มา หรือความคลาดเคลื่อนของพิกัดพื้นที่ |

**3) พจนานุกรมข้อมูล (Data Dictionary): `ASSESSMENT_CONTEXT`**

| ชื่อเขตข้อมูล | ชนิดข้อมูล | ความหมาย / การใช้งาน |
| :--- | :--- | :--- |
| `assessment_context_id` | VARCHAR(50) | รหัสประจำบริบทของการประเมินแต่ละครั้ง |
| `disaster_event_id` | VARCHAR(50) | รหัสเชื่อมกลับไปยัง `DISASTER_EVENT` |

- `DISASTER_EVENT` ตอบว่าเกิดอะไรขึ้น และกระทบใครบ้างในภาพรวม
- `EVENT_LOCATION` ตอบว่าเหตุเดียวกันกระทบพื้นที่ใดบ้าง
- `ASSESSMENT_CONTEXT` ตอบว่าข้อมูลชุดหนึ่งถูกสร้างขึ้นเมื่อใด โดยใคร และผ่านการทวนสอบหรือยัง
- `LD_PHYSICAL_DAMAGE` ตอบว่าอะไรเสียหาย เสียหายเท่าไร และตีมูลค่าอย่างไร
- `LD_ECONOMIC_LOSS` ตอบว่าผลกระทบทางเศรษฐกิจที่เกิดขึ้นหลังภัยมีมูลค่าเท่าใดเมื่อเทียบกับสภาวะปกติ
- `LD_RECOVERY_RECONSTRUCTION_NEEDS` ตอบว่าหลังประเมินแล้ว ต้องใช้ทรัพยากรอะไรในการฟื้นฟูหรือสร้างกลับ
