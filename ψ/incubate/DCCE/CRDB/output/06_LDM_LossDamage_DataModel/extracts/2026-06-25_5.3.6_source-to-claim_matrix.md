## Anti-generic rewrite controls for [`5.3.6`](ψ/incubate/DCCE/CRDB/inbox_source/CRDB%20-%20TOR.md:190)

1. Replace any vague phrase like “international standards suggest” with a named contrast: intake registry vs. expert assessment vs. sector module vs. macro synthesis.
2. Replace any vague phrase like “DDPM has limitations” with the precise limitation class: reimbursement orientation, taxonomy weakness, missing macro layer, local data noise, or missing valuation inputs.
3. Replace any vague phrase like “PDNA can be used” with the sharper formulation: PDNA is a later-phase, cross-agency, recovery-oriented enrichment logic.
4. Replace any vague phrase like “metadata should be included” with a named control set: event id, source record, observation date, geographic resolution, method, uncertainty/status, and revision history.

## Main weaknesses to carry into rewrite control

- Current opening is too general and could be made more authoritative by foregrounding the national-standard gap and the fact of an already-operational DDPM intake chain.
- Current standards paragraphs blur together event-registry logic and post-disaster valuation logic.
- Current PDNA treatment still risks sounding like DDPM already runs a PDNA-based field collection system.
- Current design paragraphs underplay semantic and provenance controls.
