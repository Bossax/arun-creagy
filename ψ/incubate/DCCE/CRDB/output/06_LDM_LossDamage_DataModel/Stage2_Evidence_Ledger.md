## Scope

Integrated evidence ledger for [`TOR 5.3.6`](../../inbox_source/CRDB%20-%20TOR.md:190) and [`TOR 5.3.7`](../../inbox_source/CRDB%20-%20TOR.md:192), following the Stage 2 requirements in [`plans/2026-06-25_crdb-ldm-5.3.6-5.3.7-execution-plan.md`](../../../../../../plans/2026-06-25_crdb-ldm-5.3.6-5.3.7-execution-plan.md:60).

## Classification rule

- **Confirmed** = explicitly evidenced in the reviewed source set.
- **Proposed** = explicitly recommended by a source, but not evidenced as current practice.
- **Inferred** = analytically necessary bridge or design implication derived from multiple sources; requires later confirmation in Stage 3 or human review.

## Provisional entity set emerging from evidence

1. **Confirmed anchor entity:** event/disaster occurrence record.
2. **Confirmed anchor entity:** sector/asset/livelihood impact observation record.
3. **Inferred support entity:** valuation reference / unit-cost record.
4. **Inferred support entity:** baseline reference snapshot.
5. **Inferred support entity:** provenance and workflow audit record.
