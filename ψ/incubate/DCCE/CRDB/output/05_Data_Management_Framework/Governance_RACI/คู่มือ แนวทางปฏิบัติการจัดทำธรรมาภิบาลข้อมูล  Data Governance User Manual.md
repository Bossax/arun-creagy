# นโยบายธรรมาภิบาลข้อมูลของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม 
นโยบายธรรมาภิบาลข้อมูลของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม ถูกกำหนดขึ้นเพื่อให้การดำเนินการด้านข้อมูลของกรมฯ เป็นไปอย่างมีประสิทธิภาพ สอดคล้องกับพระราชบัญญัติการบริหารงานและการให้บริการภาครัฐผ่านระบบดิจิทัล พ.ศ. 2562 รวมถึงเพื่อให้การได้มาและการนำข้อมูลไปใช้นั้นมีความถูกต้อง ครบถ้วน เป็นปัจจุบัน รักษาความเป็นส่วนบุคคล และเชื่อมโยงแลกเปลี่ยนกันได้อย่างมั่นคงปลอดภัย

โดยนโยบายดังกล่าวประกอบด้วย 7 ข้อหลัก 

1. **จัดให้มีคณะกรรมการด้านการกำกับดูแลข้อมูล** ของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม เพื่อทำหน้าที่บริหารจัดการข้อมูลให้เป็นไปตามธรรมาภิบาลข้อมูลภาครัฐ
2. **กำหนดสิทธิ หน้าที่ และความรับผิดชอบ** ในการบริหารจัดการข้อมูล ซึ่งรวมไปถึงสิทธิและหน้าที่ของผู้ครอบครองหรือผู้ที่ควบคุมข้อมูลในทุกๆ ขั้นตอน
3. **จัดให้มีระบบบริหารและกระบวนการจัดการและคุ้มครองข้อมูลที่ครบถ้วน** โดยครอบคลุมตั้งแต่ขั้นตอนการจัดทำ การจัดเก็บ การจำแนกหมวดหมู่ การประมวลผลหรือใช้ข้อมูล การปกปิดหรือเปิดเผยข้อมูล การตรวจสอบ ไปจนถึงการทำลายข้อมูล
4. **จัดให้มีมาตรการในการควบคุมและพัฒนาคุณภาพข้อมูล** เพื่อให้มั่นใจได้ว่าข้อมูลมีความถูกต้อง ครบถ้วน พร้อมใช้งาน และเป็นปัจจุบันอยู่เสมอ รวมถึงต้องมีการวัดผลการบริหารจัดการข้อมูลด้วย
5. **กำหนดกฎเกณฑ์การเข้าถึงและใช้ประโยชน์จากข้อมูลที่ชัดเจน** ตลอดจนมีระบบบริหารจัดการ มาตรการ และหลักประกันในการคุ้มครองข้อมูลที่อยู่ในความครอบครองให้มีความมั่นคงปลอดภัย
6. **จัดให้มีมาตรฐานคำอธิบายข้อมูล (Metadata) และพจนานุกรมข้อมูล (Data Dictionary)** สำหรับข้อมูลดิจิทัลของกรมฯ เพื่อให้สามารถทราบถึงรายละเอียดที่สำคัญ เช่น โครงสร้างของข้อมูล เนื้อหาสาระ รูปแบบการจัดเก็บ แหล่งที่มาของข้อมูล และสิทธิในการเข้าถึงข้อมูลเหล่านั้น
7. **จัดให้มีการทบทวนนโยบายธรรมาภิบาลข้อมูลภาครัฐ อย่างน้อยปีละ 1 ครั้ง** พร้อมทั้งดำเนินการปรับปรุงอย่างต่อเนื่องเพื่อเพิ่มประสิทธิภาพในการดำเนินงาน

| ลำดับ  | คำศัพท์                                         | คำจำกัดความ                                                                                                                                                                        |
| :----- | :---------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1**  | **ข้อมูล (Data)**                               | สิ่งที่สื่อความหมายให้รู้เรื่องราวข้อเท็จจริงหรือเรื่องอื่นใด ไม่ว่าจะจัดทำไว้ในรูปเอกสาร แฟ้ม รายงาน แผนที่ ภาพถ่าย การบันทึกเสียง หรือวิธีอื่นใดที่ทำให้สิ่งที่บันทึกไว้ปรากฏได้ |
| **2**  | **ข้อมูลที่มีโครงสร้าง (Structured Data)**      | ข้อมูลที่เก็บอยู่ในรูปแบบของขอบเขตข้อมูลและมีแบบจำลองข้อมูลอธิบายว่าข้อมูลนั้นมีการนำเสนออย่างไร                                                                                   |
| **3**  | **ข้อมูลที่ไม่มีโครงสร้าง (Unstructured Data)** | ข้อมูลที่ไม่อยู่ในรูปแบบของขอบเขตข้อมูลและไม่ได้อยู่ในฐานข้อมูลระบบใดๆ เช่น เอกสาร MS Word, สไลด์, วีดีโอ และไฟล์เสียง                                                             |
| **4**  | **ข้อมูลที่มีชั้นความลับ (Classified Data)**    | ข้อมูลที่ถูกจัดชั้นว่าเป็นความลับ และไม่ให้เปิดเผยต่อสาธารณชน                                                                                                                      |
| **5**  | **ข้อมูลสาธารณะ (Public Data)**                 | ข้อมูลทั่วไปที่เปิดเผยสู่สาธารณะผ่านทางเว็บไซต์ สิ่งตีพิมพ์ หรือวิธีการอื่นๆ รวมถึงการแชร์ข้อมูลจากหน่วยงานภายนอก                                                                  |
| **6**  | **พจนานุกรมข้อมูล (Data Dictionary)**           | ตารางข้อมูลที่ใช้อธิบายรายละเอียดของข้อมูลในแต่ละแถวหรือคอลัมภ์                                                                                                                    |
| **7**  | **แบบจำลองข้อมูล (Data Model)**                 | นิยามของความสัมพันธ์ระหว่างองค์ประกอบของคำอธิบายข้อมูล (Metadata) หรือความสัมพันธ์ของคุณสมบัติข้อมูลต่อโลกแห่งความจริง                                                             |
| **8**  | **คำอธิบายข้อมูล (Metadata)**                   | ข้อมูลที่อธิบายข้อมูลอื่นๆ เป็นคำอธิบายที่มีโครงสร้างรวมถึงเนื้อหา เงื่อนไขการใช้งาน ระดับการเข้าถึง และคุณลักษณะอื่นๆ ของข้อมูล                                                   |
| **9**  | **บัญชีข้อมูล (Data Catalog)**                  | เอกสารแสดงรายการคำอธิบายข้อมูล (Metadata) ที่จำแนกแยกแยะโดยการจัดกลุ่มหรือประเภทข้อมูลที่หน่วยงานรัฐครอบครองอยู่                                                                   |
| **10** | **คุณภาพข้อมูล (Data Quality)**                 | ความถูกต้อง ความสอดคล้อง ครบถ้วนของคำอธิบายข้อมูล (Metadata) รวมถึงความถี่ในการรวบรวมและปรับปรุงให้ล่าสุด                                                                          |
| **11** | **ความถูกต้อง (Accuracy)**                      | ระดับของความถูกต้องและเที่ยงตรงต่อวัตถุการวัดหรือธุรกรรมใดๆ ของคำอธิบายข้อมูล (Metadata)                                                                                           |
| **12** | **ความสอดคล้อง (Consistency)**                  | ระดับข้อมูลที่เหมือนกันในเขตของข้อมูลสำหรับคำอธิบายข้อมูล (Metadata) ที่ได้จากการเก็บรวบรวมจากหน่วยงานและผู้เกี่ยวข้อง                                                             |
| **13** | **ความครบถ้วน (Completeness)**                  | ข้อมูลต่างๆ ที่เกี่ยวข้องมีความพร้อมเมื่อมีความต้องการใช้งาน                                                                                                                       |
| **14** | **การเก็บรวบรวม (Acquisition)**                 | การกระทำเพื่อให้ได้มาซึ่งข้อมูลจากแหล่งต่างๆ ทั้งทางตรงและทางอ้อม                                                                                                                  |
| **15** | **การควบคุม (Control)**                         | อำนาจของส่วนงานในการกำหนดวัตถุประสงค์และวิธีการในการประมวลผลข้อมูล                                                                                                                 |
| **16** | **การประมวลผล (Processing)**                    | การดำเนินการใดๆ กับข้อมูล (ทั้งแบบอัตโนมัติหรือไม่ก็ตาม) เช่น การรวบรวม บันทึก ใช้งาน ปรับเปลี่ยน เผยแพร่ ปิดกั้น ลบ หรือทำลาย                                                     |
| **17** | **การเปิดเผยข้อมูล (Disclosure)**               | การกระทำในการจัดทำข้อมูลที่มีให้แก่บุคคลภายนอกกรม                                                                                                                                  |
| **18** | **ข้อมูลส่วนบุคคล (Personal Data)**             | ข้อมูลเกี่ยวกับบุคคลที่สามารถยืนยันตัวตนได้ ไม่ว่าจะเป็นจริงหรือเท็จ                                                                                                               |
| **19** | **การให้ความยินยอม (Consent)**                  | ข้อตกลงที่ได้รับแจ้งจากบุคคลหรือนิติบุคคลเพื่อประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลความลับ โดยอาจเป็นไปโดยชัดแจ้งหรือโดยนัย                                                            |


# โครงสร้างของบุคลากรที่รับผิดชอบในการจัดทำธรรมาภิบาลข้อมูล (Data Governance Structure) ของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม  

**1. คณะกรรมการด้านการกำกับดูแลข้อมูล**
- **องค์ประกอบ:** ประกอบด้วย 14 ตำแหน่งสำคัญ
	1. **อธิบดีกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม** ปฏิบัติหน้าที่ ประธานกรรมการ
	2. **ผู้บริหารเทคโนโลยีสารสนเทศระดับสูงระดับกรม (DCIO)** ของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม ปฏิบัติหน้าที่ รองประธานกรรมการ
	3. **ผู้บริหารด้านการรักษาความปลอดภัยระดับสูง (CSO)** ของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม ปฏิบัติหน้าที่ กรรมการ
	4. **เลขานุการกรม** ปฏิบัติหน้าที่ กรรมการ
	5. **ผู้อำนวยการกองขับเคลื่อนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม** ปฏิบัติหน้าที่ กรรมการ
	6. **ผู้อำนวยการกองยุทธศาสตร์และความร่วมมือระหว่างประเทศ** ปฏิบัติหน้าที่ กรรมการ
	7. **ผู้อำนวยการกองส่งเสริมการมีส่วนร่วมต่อการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม** ปฏิบัติหน้าที่ กรรมการ
	8. **ผู้อำนวยการศูนย์วิจัยการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม** ปฏิบัติหน้าที่ กรรมการ
	9. **ผู้อำนวยการกลุ่มตรวจสอบภายใน** ปฏิบัติหน้าที่ กรรมการ
	10. **ผู้อำนวยการกลุ่มพัฒนาระบบบริหาร** ปฏิบัติหน้าที่ กรรมการ
	11. **หัวหน้ากลุ่มงานจริยธรรม** ปฏิบัติหน้าที่ กรรมการ
	12. **ผู้อำนวยการกลุ่มพัฒนาเทคโนโลยีดิจิทัล** ปฏิบัติหน้าที่ กรรมการ
	13. **ผู้อำนวยการกองขับเคลื่อนการลดก๊าซเรือนกระจก** ปฏิบัติหน้าที่ กรรมการและเลขานุการ
	14. **ผู้อำนวยการกลุ่มฐานข้อมูลกลางด้านการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม** ปฏิบัติหน้าที่ กรรมการและผู้ช่วยเลขานุการ
- **อำนาจหน้าที่:** มีหน้าที่สำคัญในการกำหนดแนวทาง ขอบเขต และวัตถุประสงค์ของการกำกับดูแลข้อมูล, จัดทำนโยบาย มาตรฐาน กฎ ระเบียบ และคู่มือต่างๆ, บริหารจัดการข้อมูลของกรมให้มีคุณภาพ มั่นคงปลอดภัย และเปิดให้ทุกภาคส่วนเข้าถึงและใช้ประโยชน์ร่วมกันได้, รวมถึงวางแผนพัฒนาข้อมูล ติดตามพิจารณาผลการดำเนินงาน และรายงานผล,

**2. ทีมบริกรข้อมูล (Data Steward Team)** แบ่งบทบาทหน้าที่ตามความเชี่ยวชาญ ดังนี้:
- **หัวหน้าทีมบริกรข้อมูล (Lead Data Steward):** รับผิดชอบโดย==ผู้อำนวยการกองขับเคลื่อนการลดก๊าซเรือนกระจก== มีหน้าที่บริหารจัดการ ควบคุมการดำเนินงานของทีมให้เป็นไปตามนโยบายของคณะกรรมการฯ รวมถึงติดตามการดำเนินงานและเสนอแนะต่อผู้บริหาร
- **บริกรข้อมูลด้านธุรกิจ (Business Data Stewards):** บุคคลที่ทำหน้าที่รับผิดชอบในการนิยามความ ต้องการด้านคุณภาพและความมั่นคงปลอดภัยซึ่งอาจจะได้รับมาจากผู้ใช้ข้อมูล (Data Users) รวมถึงการกำหนด ทบทวน ปรับปรุงกระบวนการ กำหนดนิยามคำอธิบายข้อมูล (Metadata) จัดทำบัญชีข้อมูลให้ครบถ้วนตามความต้องการ และรายงานผลลัพธ์ไปยังคณะกรรมการฯ
- **บริกรข้อมูลด้านเทคนิค (Technical Data Stewards):** ทำหน้าที่ให้การสนับสนุนด้านเทคโนโลยีสารสนเทศแก่บริกรข้อมูลด้านธุรกิจ ให้ข้อเสนอแนะเชิงเทคนิค รวมถึงกำหนดรายละเอียดการออกแบบโครงสร้างพื้นฐานระบบเทคโนโลยีสารสนเทศ เพื่อคุ้มครองข้อมูลและรักษาความมั่นคงปลอดภัย %% This is data custodian in DGA's term %%
- **บริกรข้อมูลด้านคุณภาพข้อมูล (Data Quality Stewards):** ทำหน้าที่วิเคราะห์ความพร้อมของธรรมาภิบาลข้อมูลและความต้องการด้านคุณภาพข้อมูล วางแผน วัดผล ตรวจสอบ ประเมินผลการดำเนินงาน และรายงานผลลัพธ์

**3. บทบาทของเจ้าของข้อมูลและผู้ใช้งาน**,
- **เจ้าของข้อมูล (Data Owner):** คือหน่วยงานภายในกรมที่เก็บรวบรวมหรือรับข้อมูล มีหน้าที่กำหนดแนวทางจัดการคำอธิบายข้อมูล (Metadata) จัดทำทะเบียนข้อมูล กำหนดชั้นความลับและแนวทางดูแลคุณภาพ กำหนดสิทธิในการเข้าถึง และพิจารณาอนุญาตการให้ข้อมูลแก่ผู้อื่น รวมถึงต้องทบทวนเงื่อนไขความยินยอมในการประมวลผลข้อมูล,
- **ผู้ใช้ข้อมูล (Data User):** คือหน่วยงานหรือบุคคลใดๆ ที่นำข้อมูลของกรมไปใช้หรือเปิดเผย ซึ่งจะต้องนำข้อมูลไปใช้ตามวัตถุประสงค์และเงื่อนไขที่ตกลงไว้ รวมทั้งมีส่วนร่วมในการดูแลรักษาความมั่นคงปลอดภัยของข้อมูลตามแนวปฏิบัติ

## ส่วนที่ 2 การสร้างและการจัดเก็บรักษาข้อมูล (Data Creating and Storage)

- จัดการประชุม อบรม และประชาสัมพันธ์เพื่อให้ความรู้ความเข้าใจเกี่ยวกับวิธีการสร้าง จัดเก็บรักษา และควบคุมคุณภาพข้อมูล
- การสร้างและรวบรวมข้อมูลต้องคำนึงถึง**การรักษาความมั่นคงปลอดภัยและความเป็นส่วนบุคคล**ตามกฎหมาย
- เจ้าของข้อมูลและทีมบริกรข้อมูลต้อง**จำแนกหมวดหมู่ของข้อมูล** (ข้อมูลส่วนบุคคล, ข้อมูลความมั่นคง, ข้อมูลความลับทางราชการ, ข้อมูลสาธารณะ) และ**กำหนดชั้นความลับ** (ชั้นลับ, ชั้นลับมาก, ชั้นลับที่สุด)
- ร่วมกันออกแบบมาตรฐานข้อมูล **จัดทำบัญชีข้อมูล (Data Catalog)** และ**พจนานุกรมข้อมูล (Data Dictionary)** รวมถึงออกแบบการจัดเก็บให้เอื้อต่อการรักษาความปลอดภัยและคุณภาพข้อมูล แล้วจึงนำเสนอขอความเห็นชอบและประกาศใช้
- ผู้ดูแลระบบรวบรวมบัญชีและพจนานุกรมข้อมูลเพื่อจัดทำระบบจัดเก็บและแสดงผลในระบบ Cloud ภายในของกรม

## ส่วนที่ 3 การประมวลผลและการใช้ข้อมูล
- กำหนดวิธีการประมวลผลและใช้ข้อมูลให้เป็นมาตรฐานเดียวกันทั้งกรม
- หากต้องประมวลผล**ข้อมูลที่เป็นความลับ** ต้องดำเนินการผ่านระบบของกรมฯ เพื่อบันทึกวันและเวลาการเข้าถึง และต้องกำหนดรหัสผ่าน (สำหรับ Server) หรือเข้ารหัสข้อมูล (สำหรับ PC)
- ผู้ใช้ข้อมูลต้องระบุตัวตน (Username/Password) ทุกครั้งที่ Login และ Logout
- ต้องประมวลผลและใช้ข้อมูล**ตรงตามวัตถุประสงค์ที่แจ้งไว้** หากต้องการใช้นอกเหนือวัตถุประสงค์ต้องได้รับความยินยอมจากเจ้าของข้อมูลก่อน
- ผู้ดูแลระบบต้อง**บันทึกประวัติการใช้ข้อมูล (Log File)** เพื่อให้สามารถตรวจสอบได้ตามกฎหมาย

## ส่วนที่ 4 การเปิดเผยข้อมูล แลกเปลี่ยนและเชื่อมโยงข้อมูล
- **ห้าม**เปิดเผยข้อมูลที่ขัดต่อกฎหมาย ระเบียบ ข้อบังคับ หรือนโยบายของกรม และหากเกี่ยวข้องกับข้อมูลส่วนบุคคลต้องได้รับความยินยอมจากเจ้าของข้อมูล
- จัดทำข้อมูลที่จะเปิดเผยให้อยู่ใน**รูปแบบที่ง่ายต่อการนำไปใช้** เช่น CSV หรือ API
- คัดเลือกและพิจารณาคำอธิบายข้อมูล (Metadata) ที่มีคุณภาพและอยู่ในชั้นที่สามารถเผยแพร่ได้
- กำหนดวิธีและช่องทางการเปิดเผยข้อมูลที่เข้าถึงง่าย ตามมาตรฐานความปลอดภัย
- จัดทำ Metadata ควบคู่ไปกับข้อมูลที่เปิดเผย (เช่น วัตถุประสงค์ ขอบเขต วันที่ แหล่งที่มา) เพื่อให้ผู้ใช้เข้าใจบริบท
- กำหนดผู้รับผิดชอบในการนำ Metadata ขึ้นเผยแพร่ผ่านช่องทางต่างๆ เช่น เว็บไซต์ของหน่วยงาน ศูนย์กลางข้อมูลเปิดภาครัฐ และต้องมี**ช่องทางรับฟังความคิดเห็น/ร้องขอข้อมูล**

## ส่วนที่ 5 การติดตาม ตรวจสอบ ประเมินผล
- กำหนดวิธีปฏิบัติเพื่อ**ตรวจสอบการเปิดเผยข้อมูล**ให้เหมาะสมและรักษาคุณภาพข้อมูล
- ทีมบริกรข้อมูลร่วมกัน**ประเมินคุณภาพของข้อมูลใน 6 ด้าน** ได้แก่ ความถูกต้อง (Accuracy), ความครบถ้วน (Completeness), ความต้องกัน (Consistency), ความเป็นปัจจุบัน (Timeliness), ตรงตามความต้องการ (Relevancy), และมีความพร้อมใช้ (Availability)
- จัดทำรายงานเสนอต่อคณะกรรมการด้านการกำกับดูแลข้อมูล

## ส่วนที่ 6 การจัดเก็บและทำลาย
- กำหนด**ระยะเวลาในการจัดเก็บ**และเลือกเครื่องมือจัดเก็บที่เป็นมาตรฐานสากล
- กำหนด**วิธีปฏิบัติการทำลายข้อมูล**ที่ไม่ขัดต่อกฎหมาย เมื่อข้อมูลไม่ถูกใช้งานหรือเก็บไว้นานเกินกำหนด
- ควรเก็บคำอธิบายข้อมูล (Metadata) ไว้ตรวจสอบภายหลังการทำลายข้อมูล
- ต้องมีการ**ยืนยันตัวบุคคล**ของผู้ดำเนินการทำลายข้อมูล
- จัดการอบรมให้ความรู้เรื่องการจัดเก็บและทำลายข้อมูลแก่หน่วยงานที่เกี่ยวข้อง

# หน้าที่และสิ่งที่เจ้าของข้อมูล (Data Owner) ต้องทำ

- **การบริหารจัดการพื้นฐาน:** เป็นผู้กำหนดแนวทางจัดการคำอธิบายข้อมูล (Metadata) จัดทำทะเบียนข้อมูล **กำหนดชั้นความลับ** แนวทางดูแลรักษาคุณภาพ และกำหนดสิทธิในการเข้าถึงข้อมูล รวมทั้งพิจารณาอนุญาตให้ผู้อื่นใช้ข้อมูล ตลอดจนต้องทบทวนเงื่อนไขว่าข้อมูลนั้นยังสามารถใช้ฐานเดิมในการจัดเก็บและประมวลผลได้อยู่หรือไม่
- **การสร้าง การจัดเก็บ และทำลาย:** ต้องจำแนกหมวดหมู่ของข้อมูล (เช่น ข้อมูลส่วนบุคคล, ข้อมูลความมั่นคง, ข้อมูลสาธารณะ) และกำหนดชั้นความลับ เป็นผู้ศึกษาขนาดและชนิดของข้อมูลเพื่อเลือกเครื่องมือจัดเก็บที่เป็นมาตรฐาน กำหนดระยะเวลาจัดเก็บ รวมถึง**ต้องกำหนดให้มีการยืนยันตัวบุคคลของผู้ดำเนินการทำลายข้อมูล**
- **การเปิดเผยข้อมูลและการตรวจสอบ:** กำหนดผู้รับผิดชอบหลักและช่องทางการเผยแพร่ข้อมูล โดยต้องพิจารณาคัดเลือกคำอธิบายข้อมูล (Metadata) เพื่อเผยแพร่ควบคู่ไปกับข้อมูล และเป็นผู้กำหนดวิธีปฏิบัติเพื่อตรวจสอบการเปิดเผยข้อมูลเพื่อรักษาคุณภาพข้อมูล

# หน้าที่และสิ่งที่ทีมบริกรข้อมูล (Data Steward Team) ต้องทำ 
ทีมบริกรข้อมูลมีหน้าที่สร้างเครื่องมือ เช่น จัดทำ Template ตรวจสอบและวัดผล และควบคุมการปฏิบัติงานด้านข้อมูลให้ครบตามวงจรชีวิตข้อมูล โดยแบ่งการทำงานตามบทบาท ดังนี้

- **หัวหน้าทีมบริกรข้อมูล:** บริหารและควบคุมการดำเนินงานของทีมให้เป็นไปตามนโยบาย ติดตามผล และเสนอแนะต่อผู้บริหาร
- **บริกรข้อมูลด้านธุรกิจ:** **กำหนดและทบทวนความต้องการด้านคุณภาพข้อมูล** จัดทำกระบวนการให้สอดคล้องกับนโยบาย **กำหนดนิยามคำอธิบายข้อมูล (Metadata)** และจัดทำบัญชีข้อมูล
- **บริกรข้อมูลด้านเทคนิค:** ให้ข้อเสนอแนะเชิงเทคนิคและกำหนดรายละเอียดการออกแบบระบบ/โครงสร้างพื้นฐาน เพื่อคุ้มครองข้อมูลส่วนบุคคลและรักษาความปลอดภัย
- **บริกรข้อมูลด้านคุณภาพข้อมูล:** วิเคราะห์ ตรวจสอบ วัดผล และประเมินคุณภาพการดำเนินงาน รวมถึง**ร่วมกันประเมินคุณภาพของข้อมูลใน 6 ด้าน** ได้แก่ ความถูกต้อง, ความครบถ้วน, ความต้องกัน, ความเป็นปัจจุบัน, ตรงตามความต้องการ, และมีความพร้อมใช้

**สิ่งที่เจ้าของข้อมูลและบริกรข้อมูลต้องดำเนินการร่วมกัน:**

- **ออกแบบและกำหนดมาตรฐานข้อมูล:** ร่วมกันจัดทำ**บัญชีข้อมูล (Data Catalog)** และ**พจนานุกรมข้อมูล (Data Dictionary)** รวมถึงออกแบบรูปแบบการจัดเก็บที่เอื้อต่อการรักษาความมั่นคงปลอดภัย
- **การประมวลผลข้อมูล:** ร่วมกันกำหนดวิธีการประมวลผลและการใช้ข้อมูลให้เป็นมาตรฐานเดียวกันทั้งกรม
- **การทำลายข้อมูล:** ร่วมกันกำหนด**วิธีปฏิบัติการทำลายข้อมูล**ที่ไม่ขัดต่อกฎหมายเมื่อหมดอายุการใช้งาน โดยควรเก็บคำอธิบายข้อมูล (Metadata) ไว้สำหรับการตรวจสอบภายหลัง
