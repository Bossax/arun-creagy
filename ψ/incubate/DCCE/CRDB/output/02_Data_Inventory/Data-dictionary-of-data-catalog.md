# Data dictionary
Note: the tables might not contain all columns

| Column              | คำอธิบาย (Description)                                                                             |
|---------------------|----------------------------------------------------------------------------------------------------|
| Source_ID           | รหัสอ้างอิงแหล่งที่มาของข้อมูล กำหนดจากตัวย่อหน่วยงานตามด้วยลำดับที่                               |
| Source_Agency_TH    | ชื่อหน่วยงานเจ้าของข้อมูลเป็นภาษาไทยอย่างเป็นทางการ                                                |
| Source_Agency_Abrv  | ตัวย่อชื่อหน่วยงานเจ้าของข้อมูลตามที่ใช้อย่างเป็นทางการ                                            |
| Source_Name         | ชื่อระบบหรือฐานข้อมูลต้นทางที่เผยแพร่ชุดข้อมูล                                                     |
| Source_Type         | ประเภทของแหล่งที่มา เช่น ฐานข้อมูลภาครัฐ ระบบสารสนเทศภูมิศาสตร์ หรือรายงาน                         |
| Access_Level        | ระดับการเข้าถึงแหล่งข้อมูลโดยรวม โดย Open แปลว่า เข้าถึงได้เอง Restricted แปลว่า ต้องมีการขอข้อมูล |
| URL (Source)        | ที่อยู่อินเทอร์เน็ตของแหล่งข้อมูลต้นทาง                                                            |
| Remarks (Source)    | หมายเหตุเพิ่มเติมเกี่ยวกับแหล่งที่มา                                                               |
| Dataset ID          | รหัสประจำชุดข้อมูล ใช้เพื่อการอ้างอิงภายในระบบ                                                     |
| Dataset Name (Thai) | ชื่อชุดข้อมูลเป็นภาษาไทย                                                                           |
| Domain              | ขอบข่ายของข้อมูลตามกรอบการดำเนินงานด้านการเปลี่ยนแปลงสภาพภูมิอากาศ                                 |
| Component           | องค์ประกอบย่อยภายใต้ขอบข่ายข้อมูล                                                                  |
| Category            | หมวดหมู่ของชุดข้อมูลตามการจำแนกประเภท                                                              |
| Related Hazards     | ประเภทของภัยที่เกี่ยวข้องกับชุดข้อมูล                                                              |
| Sectors             | สาขาหรือภาคส่วนที่เกี่ยวข้องกับชุดข้อมูล                                                           |
| Temporal Dimension  | มิติด้านเวลาของข้อมูล เช่น ข้อมูลในอดีต ปัจจุบัน หรือคาดการณ์อนาคต                                 |
| Time Period         | ช่วงเวลาที่ข้อมูลครอบคลุม                                                                          |
| Unit                | หน่วยวัดของข้อมูล                                                                                  |
| Temporal Resolution | ความถี่หรือความละเอียดเชิงเวลาของข้อมูล เช่น รายวัน รายเดือน รายปี                                 |
| Spatial Scope       | ขอบเขตเชิงพื้นที่ที่ข้อมูลครอบคลุม เช่น ระดับประเทศ ภูมิภาค หรือจังหวัด                            |
| Spatial Resolution  | ความละเอียดเชิงพื้นที่ของข้อมูล เช่น ระดับตำบล อำเภอ หรือกริดเซลล์                                 |
| Format              | รูปแบบไฟล์หรือโครงสร้างของข้อมูล เช่น Shapefile, CSV, GeoTIFF                                      |
| URL / Limitations   | ที่อยู่อินเทอร์เน็ตของชุดข้อมูล และข้อจำกัดหรือช่องว่างของข้อมูลที่ตรวจพบ                          |
| Remarks             | หมายเหตุเพิ่มเติมเกี่ยวกับชุดข้อมูล                                                                |
