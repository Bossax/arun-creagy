# 1. วัตถุประสงค์และขอบเขต

คู่มือนี้กำหนดวิธีทบทวนความเหมาะสมของตัวชี้วัดที่เชื่อมกับกิจกรรมใน Action Plan และวิธีพิจารณาว่าควรคงตัวชี้วัดเดิม เพิ่มตัวชี้วัดจาก M&E Platform ตัดตัวชี้วัดที่ไม่เหมาะสม หรือเสนอสร้างตัวชี้วัดใหม่ โดยใช้ความสอดคล้องเชิงโครงสร้างควบคู่กับความเหมาะสมเชิงเนื้อหาและเส้นทางผลลัพธ์

หน่วยประเมินหลักคือกิจกรรม โดยอ่านกิจกรรมภายใต้บริบทของสาขา แนวทาง และมาตรการที่กิจกรรมนั้นสังกัด เพื่อไม่ให้การตัดสินรายตัวชี้วัดขาดบริบทของผลลัพธ์ระดับที่สูงขึ้น

การประเมินใช้ผล Moderate เป็นข้อเสนอหลัก ส่วน Strict ใช้ตรวจความคงทนของข้อสรุปภายใต้เกณฑ์ที่เข้มงวดกว่า และ Preserve Existing ใช้ตรวจความไวของข้อสรุปเมื่อให้ความสำคัญกับความต่อเนื่องและการเปรียบเทียบย้อนหลัง

# 3. หลักการสำคัญของการประเมิน

|**หลักการ**|**แนวทางปฏิบัติ**|
|---|---|
|1. ยึด architecture ร่วม|เริ่มจากสาขา แนวทาง และมาตรการของ Action Plan แล้วเชื่อมไปยัง topic/guideline ของ M&E Platform ที่สอดคล้อง ก่อนพิจารณารายตัวชี้วัด|
|2. ประเมินตัวชี้วัดเดิมก่อน|ตัวชี้วัดเดิมทุกตัวต้องได้รับการประเมินครบก่อนเปิด M&E candidate pool เพื่อให้เห็นคุณภาพและช่องว่างของชุดเดิมอย่างโปร่งใส|
|3. เปิด M&E candidate pool หลังประเมินตัวเดิม|หลังประเมินตัวชี้วัดเดิม ให้ตรวจ M&E candidate ของสาขาเดียวกันตาม architecture crosswalk แม้ตัวชี้วัดเดิมจะผ่าน Moderate|
|4. M&E สามารถเพิ่มได้เมื่อ fit ดีกว่า|ตัวชี้วัดที่มีอยู่แล้วใน M&E Platform สามารถเพิ่มได้เมื่อ substantive fit, operational fit หรือคุณค่าด้าน harmonization ดีกว่าตัวเดิม แม้ความต่างจะไม่มากและไม่มี significant gap ทั้งนี้ต้องผ่านเกณฑ์เนื้อหา เส้นทางผลลัพธ์ ระดับผล และขอบเขต|
|5. ไม่เพิ่ม metric ที่เทียบเท่าซ้ำ|หาก M&E candidate วัดสาระเดียวกันหรือเกือบเดียวกันกับตัวชี้วัดเดิมที่ผ่าน Moderate ให้เก็บเป็น harmonization/crosswalk reference แทนการนับเป็นความสัมพันธ์ใหม่|
|6. ใช้ M&E ก่อนสร้างตัวชี้วัดใหม่|ตัวชี้วัดใหม่นอก M&E สร้างเฉพาะเมื่อไม่มีทั้งตัวเดิมและ M&E ที่เหมาะสมจริง และควรใช้ shared indicator เมื่อหลายกิจกรรมวัด outcome เดียวกัน|
|7. Architecture ไม่แทน substantive fit|แม้ candidate อยู่ใน node ที่ตรงกัน ก็ยังต้องพิสูจน์ว่าเนื้อหา เส้นทางผลลัพธ์ ระดับผล และขอบเขตสอดคล้องกับกิจกรรม|

# 4. ลำดับการประเมิน

1. อ่านกิจกรรมเพื่อระบุสิ่งที่ทำ กลุ่มเป้าหมาย พื้นที่ ความเสี่ยง ประเภทมาตรการ ผลที่คาดว่าจะเกิดขึ้น และระดับผลที่กิจกรรมสามารถมีส่วนทำให้เกิดขึ้น

2. ระบุตำแหน่งของกิจกรรมในโครงสร้าง Action Plan ได้แก่ สาขา แนวทาง และมาตรการ แล้วจัดทำ crosswalk ไปยัง topic/guideline ของ M&E Platform ที่เกี่ยวข้อง

3. ประเมินตัวชี้วัดเดิมทุกตัวด้วย C1-C6 และคำนวณคะแนน Strict, Moderate และ Preserve Existing

4. สรุปตัวชี้วัดเดิมที่ผ่าน Moderate และระบุว่าตัวใดเป็น direct indicator ตัวใดเป็น contribution/proxy และมีมิติใดที่ยังอ่อนหรือไม่ครบ

5. เปิด M&E candidate pool ของสาขาเดียวกันตาม architecture crosswalk และประเมิน candidate ด้วย C1-C5 แม้มีตัวชี้วัดเดิมผ่าน Moderate แล้ว

6.       เพิ่ม M&E candidate เมื่อให้ substantive/operational fit หรือ harmonization value ที่ดีกว่า และไม่เพิ่มซ้ำหาก metric เทียบเท่ากับตัวเดิม

7.       หากผลสำคัญยังไม่มีตัวชี้วัดที่เหมาะสมจากทั้งชุดเดิมและ M&E Platform จึงพิจารณาสร้างตัวชี้วัดใหม่ โดยตรวจ shared indicator ก่อน

8.       บันทึกคะแนน เหตุผล แหล่งที่มา สถานะการตัดสิน และความสอดคล้องกับ architecture เพื่อให้ตรวจสอบย้อนกลับได้

# 5. ประเด็นที่ใช้ในการประเมิน

|**รหัส**|**ประเด็น**|**คำถามประเมิน**|
|---|---|---|
|C1|ความสัมพันธ์เชิงเนื้อหา|สิ่งที่ตัวชี้วัดวัดสัมพันธ์กับสาระของกิจกรรมหรือผลสำคัญที่คาดว่าจะเกิดขึ้นหรือไม่|
|C2|เส้นทางเชิงเหตุผล/ผลลัพธ์|สามารถอธิบาย กิจกรรม -> การเปลี่ยนแปลง -> ผลที่ตัวชี้วัดวัด ได้ชัดเจนเพียงใด|
|C3|ความสอดคล้องของระดับผล|ระดับ output, outcome หรือ sector result เหมาะกับระดับอิทธิพลที่กิจกรรมสามารถมีส่วนทำให้เกิดขึ้นหรือไม่|
|C4|ความสอดคล้องของขอบเขตและ architecture|กลุ่มเป้าหมาย พื้นที่ ความเสี่ยง ประเภทมาตรการ หน่วยที่วัด และตำแหน่ง M&E topic/guideline สอดคล้องกันเพียงใด|
|C5|ความจำเป็น/ไม่ซ้ำซ้อน/คุณค่าเพิ่ม|ตัวชี้วัดให้สารสนเทศหรือคุณค่าในการติดตามเพิ่มหรือไม่ โดยความหมายแตกต่างตามแหล่งตัวชี้วัด|
|C6|ความต่อเนื่อง/เปรียบเทียบย้อนหลัง|ใช้สำหรับตัวชี้วัดเดิมใน Preserve Existing เพื่อสะท้อน continuity และ historical comparability|

## 5.1 การตีความ C5 ตามแหล่งตัวชี้วัด

|**แหล่งตัวชี้วัด**|**ความหมายของ C5**|
|---|---|
|ตัวชี้วัดเดิม|พิจารณาความจำเป็นและความซ้ำซ้อนในชุดเดิม ถ้าให้ข้อมูลสำคัญที่ยังจำเป็นหรือช่วยรักษาชุดให้ครบมิติ ให้คะแนนสูงขึ้น|
|M&E candidate|C5 = 4 เมื่อปิด significant gap; C5 = 3 เมื่อเพิ่ม substantive/operational fit หรือ harmonization value; C5 <= 2 เมื่อเทียบเท่ากับตัวเดิมหรือไม่ได้ดีกว่าอย่างมีประโยชน์|
|ตัวชี้วัดใหม่นอก M&E|ตีความเป็น gap necessity ต้องพิสูจน์ว่าไม่มีตัวเดิมและไม่มี M&E candidate ที่เหมาะสมเพียงพอ|

# 6. มาตราส่วนคะแนน 0 ถึง 4

|**คะแนน**|**ระดับ**|**แนวทางตีความ**|
|---|---|---|
|4|สูงมาก/ตรงมาก|ความสัมพันธ์หรือความเหมาะสมชัดเจนโดยตรง มีเหตุผลรองรับ และขอบเขตตรง|
|3|สูง|มีความสัมพันธ์ชัดเจน แม้อาจมีระยะทางเชิงผลลัพธ์หรือข้อจำกัดเล็กน้อย|
|2|ปานกลาง|สัมพันธ์ทางอ้อมหรือขอบเขตกว้างกว่า แต่ยังอธิบาย contribution pathway ได้สมเหตุสมผล|
|1|ต่ำ|สัมพันธ์เพียงบางส่วน ความเชื่อมโยงอ่อน หรือเสี่ยงต่อการตีความเกินขอบเขต|
|0|ไม่สอดคล้อง|ไม่พบเส้นทางเชิงเหตุผล หรือขอบเขตผิดประเด็นอย่างชัดเจน|

# 7. การถ่วงน้ำหนักและสูตรคะแนน

คะแนนรวมเป็น weighted rubric บนสเกล 0 ถึง 100 คำนวณจากคะแนนรายเกณฑ์ 0 ถึง 4 คูณน้ำหนักของแต่ละรูปแบบแล้วหารด้วย 4 คะแนนใช้เพื่อทำให้เหตุผลโปร่งใสและทำซ้ำได้ แต่ไม่ใช้คะแนนรวมเพียงอย่างเดียว ต้องผ่าน minimum criteria และ Critical Fail ด้วย

|                                                                            |
| -------------------------------------------------------------------------- |
| **สูตรคะแนน**<br><br>Score(mode) = Sum [คะแนนเกณฑ์ x น้ำหนักของรูปแบบ] / 4 |

# 8. เกณฑ์ตัดสินและ Critical Fail

|**ประเภท**|**รูปแบบ**|**คะแนนรวม**|**Minimum criteria**|**ผลเมื่อผ่าน**|
|---|---|---|---|---|
|ตัวชี้วัดเดิม|Strict|>= 80|C1, C2, C4 >= 3|คงไว้ใน robustness check|
|ตัวชี้วัดเดิม|Moderate|>= 65|C1, C2, C4 >= 2|คงไว้ในชุดหลัก|
|ตัวชี้วัดเดิม|Preserve Existing|>= 55|C1, C2, C4 >= 1|คงไว้ใน continuity sensitivity|
|M&E / ตัวชี้วัดเสนอเพิ่ม|Strict|>= 80|C1, C2, C4, C5 >= 3|เพิ่มภายใต้ Strict|
|M&E / ตัวชี้วัดเสนอเพิ่ม|Moderate|>= 70|C1, C2, C4 >= 2 และ C5 >= 3|เพิ่มในชุดหลัก|
|M&E / ตัวชี้วัดเสนอเพิ่ม|Preserve Existing|>= 85|C1, C2, C4 >= 3 และ C5 = 4|เพิ่มเฉพาะเมื่อจำเป็นชัดเจนมาก|

|   |
|---|
|**Critical Fail**<br><br>หาก C1, C2 หรือ C4 เท่ากับ 0 ให้ตัดตัวชี้วัดเดิมหรือไม่เพิ่ม candidate ทันที แม้คะแนนรวมจะสูงจากมิติอื่น และ M&E candidate ที่มาจากคนละสาขากับกิจกรรมไม่สามารถนำมาใช้ได้|

# 9. วิธีพิจารณา M&E candidate

หลังประเมินตัวชี้วัดเดิม ให้เปิด candidate pool จาก M&E Platform ของสาขาเดียวกันตาม best-fit crosswalk และเปรียบเทียบ candidate กับชุด Moderate ที่มีอยู่ โดยพิจารณาทั้ง substantive fit, operational fit และ harmonization value

|**ผลการพิจารณา**|**ใช้เมื่อ**|
|---|---|
|เพิ่มจาก M&E Platform|M&E candidate ผ่านเกณฑ์ Moderate และให้ความตรง ความเฉพาะเจาะจง ความสามารถในการติดตาม หรือคุณค่าด้านการเชื่อมระบบสูงกว่า สามารถเพิ่มได้แม้ตัวเดิมผ่าน Moderate และไม่มี significant gap|
|ไม่เพิ่มซ้ำ - harmonization reference|M&E candidate วัดสาระเดียวกันหรือเกือบเดียวกันกับตัวชี้วัดเดิมที่ผ่าน Moderate จึงไม่สร้างความสัมพันธ์ใหม่ แต่เก็บรหัส M&E ไว้เป็น crosswalk/harmonization reference|
|ไม่เพิ่ม|Candidate อยู่ใน architecture ที่เกี่ยวข้อง แต่ substantive/operational fit ไม่ดีกว่าตัวเดิมหรือไม่มี value เพิ่มเพียงพอ|

- M&E indicator หนึ่งตัวสามารถเชื่อมกับหลายกิจกรรมได้ หากกิจกรรมเหล่านั้นสนับสนุน outcome เดียวกันและขอบเขตสอดคล้อง
- ถ้าโครงสร้าง Action Plan และ M&E ไม่ตรงแบบหนึ่งต่อหนึ่ง ให้ใช้ best-fit crosswalk จากสาระของแนวทาง/มาตรการ และบันทึกเหตุผล
- การตรงกันของคำหรือชื่อหัวข้อเพียงอย่างเดียวไม่ถือเป็น substantive fit

# 10. สถานะที่ใช้ในชุดข้อเสนอหลัก

|**สถานะ**|**ความหมาย**|
|---|---|
|คงไว้|ตัวชี้วัดเดิมผ่าน Moderate และยังมีคุณค่าในการติดตามกิจกรรม|
|เพิ่มจาก M&E Platform|M&E candidate ผ่าน Moderate และให้ fit หรือ harmonization value ที่เพียงพอ|
|เพิ่มใหม่ (นอก M&E Platform)|ไม่มีตัวเดิมและไม่มี M&E candidate ที่เหมาะสมจริง และผลดังกล่าวสำคัญต่อการติดตาม|
|ตัดออก|ตัวชี้วัดเดิมไม่ผ่าน Moderate หรือเกิด Critical Fail/ขอบเขตผิดประเด็น|

## 10.1 รูปแบบ coverage ระดับกิจกรรม

| **รูปแบบ coverage**            | **การตีความ**                                                                                            |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Existing sufficient            | ตัวชี้วัดเดิมที่ผ่าน Moderate รองรับผลสำคัญ และไม่พบ M&E candidate ที่ให้ fit หรือ value เพิ่มที่เหมาะสม |

| M&E replacement / reuse        | ตัวเดิมไม่ผ่าน Moderate และใช้ M&E ที่เหมาะสมแทนการสร้างตัวใหม่                                          |
| Existing + M&E gap-fill        | คงตัวเดิมที่เหมาะสม และเพิ่ม M&E เพื่อครอบคลุมมิติสำคัญที่ยังขาด                                         |
| New last-resort                | ไม่พบตัวเดิมหรือ M&E ที่เหมาะสม จึงสร้างใหม่เฉพาะผลสำคัญ                                                 |
| Shared new indicator (M&E gap) | หลายกิจกรรมมี outcome ร่วมและไม่มี M&E ที่เหมาะสม จึงใช้ตัวชี้วัดใหม่ร่วมกัน                             |

# 11. การทวนสอบโดยผู้รีวิว

ผู้รีวิวทำหน้าที่ตรวจ judgement ของผล Moderate และ Preserve Existing โดยไม่จำเป็นต้องให้คะแนน C1-C6 ใหม่ทั้งหมด ผู้รีวิวอ่านบริบทสาขา แนวทาง มาตรการ กิจกรรม ตัวชี้วัด และเหตุผลที่บันทึกไว้ แล้วเลือกผลจากรายการมาตรฐาน

|**ตัวเลือกรีวิว**|**ความหมาย**|
|---|---|

|ควรตัดออกแทนการคง|เห็นว่าความสัมพันธ์ ขอบเขต หรือระดับผลไม่เหมาะสมเพียงพอ|
|ควรใช้ M&E ตัวอื่น|เห็นว่ามี M&E candidate ตัวอื่นที่เหมาะสมกว่า|
|ยังไม่แน่ใจ|ต้องการข้อมูลหรือการหารือเพิ่มเติมก่อนตัดสิน|

# 13. การควบคุมคุณภาพ

·         กิจกรรมทุกกิจกรรมต้องได้รับการประเมินครบ และตัวชี้วัดเดิมทุกตัวต้องมีผล Strict, Moderate และ Preserve Existing

·         M&E candidate ที่ใช้ต้องมาจากสาขาเดียวกัน และต้องตรวจความสอดคล้องกับ topic/guideline ที่เกี่ยวข้อง

·         M&E candidate ที่เทียบเท่าหรือเกือบเทียบเท่ากับตัวชี้วัดเดิมไม่ควรถูกนับซ้ำเป็นความสัมพันธ์ใหม่ แต่ควรเก็บเป็น harmonization reference

·         การเพิ่ม M&E แม้ตัวเดิมผ่าน Moderate ต้องมีเหตุผลด้าน substantive/operational fit หรือ harmonization value ที่อธิบายได้

·         ตัวชี้วัดใหม่นอก M&E ต้องมีหลักฐานว่าพิจารณาตัวเดิมและ M&E candidate ก่อนแล้ว และไม่พบทางเลือกที่เหมาะสมเพียงพอ

·         หากหลายกิจกรรมวัด outcome เดียวกัน ควรพิจารณา shared indicator ก่อนสร้างตัวใหม่หลายตัว

·         เหตุผลประกอบต้องอธิบายความสัมพันธ์ของกิจกรรมกับสิ่งที่ตัวชี้วัดวัด ไม่ใช้เพียงคำว่า “เกี่ยวข้อง” หรือ “ไม่เกี่ยวข้อง”

·         Data readiness ต้องประเมินแยกจาก suitability score เพราะตัวชี้วัดที่เหมาะสมอาจยังไม่มีระบบข้อมูลพร้อมใช้

# 15. ข้อจำกัดและแนวทางการทวนสอบ

·         น้ำหนักและ threshold เป็น methodological parameters เพื่อทำให้การตัดสินมีโครงสร้าง โปร่งใส และตรวจสอบย้อนกลับได้ ไม่ควรตีความเป็นค่าตัดเชิงประจักษ์ที่ใช้ได้กับทุกบริบทโดยอัตโนมัติ

·         ควรทวนสอบ best-fit crosswalk ระหว่าง Action Plan และ M&E Platform กับเจ้าของสาขา โดยเฉพาะกรณีที่โครงสร้างไม่ตรงแบบหนึ่งต่อหนึ่ง

·         ควรใช้ผู้เชี่ยวชาญสาขาตรวจกรณีที่ candidate มีความสัมพันธ์ทางอ้อม หรือมีหลาย M&E node ที่เป็นไปได้

·         ควรแยกการประเมินความพร้อมของข้อมูลออกจาก suitability score และจัดทำ data-source mapping สำหรับตัวชี้วัดที่ต้องนำไปใช้จริง

·         การรักษารหัสเดิมของตัวชี้วัด Existing และ M&E Platform ช่วยให้ตรวจสอบย้อนกลับและเชื่อมกับระบบข้อมูลได้ง่ายขึ้น
