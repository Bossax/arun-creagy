## 1. บทสรุปผู้บริหารและกรอบแนวคิดหลัก (Executive Summary & Core Thesis)

การปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศของประเทศไทยจำเป็นต้องอาศัยข้อมูลเชิงวิทยาศาสตร์ที่มีความน่าเชื่อถือ ละเอียด และสอดคล้องกับระดับพื้นที่ อย่างไรก็ตาม ข้อมูลจากแบบจำลองภูมิอากาศโลก (Global Climate Models: GCMs) มักมีความละเอียดเชิงพื้นที่หยาบ (ประมาณ 100x100 กิโลเมตรต่อตาราง grid) ซึ่งไม่เพียงพอสำหรับการวางแผนระดับจังหวัดหรือลุ่มน้ำ

รายงานฉบับนี้เป็นการสังเคราะห์องค์ความรู้เชิงวิทยาศาสตร์เพื่อสนับสนุนการสร้าง **ชุดแผ่นป้ายนิทรรศการ (Roll-up Series) 2 แผ่น** ของกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม (DCCE) โดยมุ่งเน้นการตอบคำถามสำคัญ 2 ประการ:

1. **Roll-up 01**: ข้อมูลฉายภาพภูมิอากาศคืออะไร แตกต่างจากการพยากรณ์อากาศอย่างไร และนำไปใช้สนับสนุนการตัดสินใจภายใต้ความไม่แน่นอนได้อย่างไร?
2. **Roll-up 02**: กระบวนการลดสเกล (Downscaling) แปลงข้อมูลระดับโลกสู่ระดับพื้นที่อย่างไร และชุดผลิตภัณฑ์ 4 ประเภท (GridData, WRF-Chem, RegCM5, Statistical Downscaling) มีจุดเด่นและการนำไปใช้งานอย่างไร?

## 2. ส่วนที่ 1: ข้อมูลฉายภาพภูมิอากาศและฉากทัศน์อนาคต (Climate Projection Data & Scenarios)

### 2.1 นิยามและความแตกต่างระหว่าง Projection กับ Forecast
ความเข้าใจผิดที่พบบ่อยคือการมองว่าข้อมูลฉายภาพภูมิอากาศเป็น "การพยากรณ์อากาศ" (Weather Forecast)

| มิติเปรียบเทียบ | การพยากรณ์อากาศ (Weather Forecast) | ข้อมูลฉายภาพภูมิอากาศ (Climate Projection) |
|---|---|---|
| **เป้าหมาย** | ระบุสภาพอากาศที่ระบุวัน-เวลาแน่นอน (Deterministic) | จำลองสถิติภูมิอากาศในระยะยาว (Probabilistic / Scenario-based) |
| **ระยะเวลา** | ล่วงหน้า 1–14 วัน | ล่วงหน้า 10–80 ปี (เช่น ค.ศ. 2030, 2050, 2100) |
| **ปัจจัยขับเคลื่อน** | สภาวะบรรยากาศ ณ ปัจจุบัน (Initial Atmospheric Conditions) | ฉากทัศน์การปล่อยก๊าซเรือนกระจกและนโยบายพัฒนา (SSPs / GHGs) |
| **การนำไปใช้** | การดำเนินชีวิตประจำวันและการเตือนภัยระยะสั้น | การวางแผนยุทธศาสตร์ นโยบายการปรับตัว และการลงทุนโครงสร้างพื้นฐาน |

### 2.2 ฉากทัศน์การพัฒนาทางเศรษฐกิจและสังคมที่ร่วมกัน (Shared Socioeconomic Pathways: SSPs)
ตามกรอบ CMIP6 (Coupled Model Intercomparison Project Phase 6) ของ IPCC ฉากทัศน์อนาคตถูกแบ่งตามเส้นทางการปล่อยก๊าซเรือนกระจกและการพัฒนาของมนุษย์:
- **SSP1-2.6 (Sustainability / Green Road)**: การพัฒนาที่ยั่งยืน การปล่อยก๊าซเรือนกระจกลดลงอย่างรวดเร็วเพื่อคุมอุณหภูมิไม่ให้เกิน 2°C
- **SSP2-4.5 (Middle of the Road)**: การพัฒนาแบบปานกลาง แนวโน้มการปล่อยก๊าซเป็นไปตามนโยบายปัจจุบัน
- **SSP5-8.5 (Fossil-fueled Development)**: การพัฒนาที่พึ่งพาพลังงานฟอสซิลอย่างหนัก การปล่อยก๊าซเพิ่มขึ้นสูงต่อเนื่อง

### 2.3 การนำข้อมูลไปสนับสนุนการตัดสินใจ 5 ด้านหลัก
1. **การจัดการทรัพยากรน้ำ**: การประเมินปริมาณน้ำท่า น้ำต้นทุนในเขื่อน และแนวโน้มความถี่ของภัยแล้ง/น้ำท่วม
2. **การเกษตรและความมั่นคงทางอาหาร**: การปรับปฏิทินการเพาะปลูก การประเมินผลกระทบจากคลื่นความร้อนต่อผลผลิต
3. **ผังเมืองและโครงสร้างพื้นฐาน**: การกำหนดเกณฑ์วิศวกรรมทนทานต่อระดับน้ำทะเลอ่าวไทยและการระบายน้ำเมือง
4. **การสาธารณสุขและภัยพิบัติ**: การเฝ้าระวังโรคติดต่อตามฤดูกาลและดัชนีความร้อน (Heat Index) ที่ส่งผลต่อสุขภาพ
5. **นโยบายและการลงทุน**: การประเมินความคุ้มค่าของการลงทุนมาตรการปรับตัว (Adaptation Investments)

### 2.4 กรอบ 5-Element Interpretation Checklist
ผู้ใช้ข้อมูลต้องพิจารณาองค์ประกอบทั้ง 5 ร่วมกันเสมอเพื่อป้องกันการตีความคลาดเคลื่อน:
$$\text{Climate Assessment} = f(\text{Model}, \text{Scenario}, \text{Time Horizon}, \text{Variable}, \text{Spatial Scale})$$

## 3. ส่วนที่ 2: ระเบียบวิธีวิจัยการลดสเกลเชิงพื้นที่ (Downscaling Methodologies)

### 3.1 ช่องว่างเชิงพื้นที่ (Spatial Scale Gap)
GCM มีความละเอียดเชิงพื้นที่ประมาณ 100 กม. ทำให้ตารางข้อมูล 1 ช่องครอบคลุมหลายจังหวัดพร้อมกัน ไม่สามารถสะท้อนยอดเขาสูง แนวชายฝั่ง หรือความแตกต่างระหว่างเมืองกับชนบทได้ จึงต้องอาศัยกระบวนการ Downscaling แปลงสู่ความละเอียด 3–25 กม.

```
+------------------------+           +------------------------+
| GCM Global Grid        |           | Downscaled RCM Grid    |
| Spatial: ~100 km       | ------->  | Spatial: ~3–5 km       |
| Broad general flow     |           | Complex topography     |
+------------------------+           +------------------------+
```

### 3.2 การเปรียบเทียบระเบียบวิธี Downscaling 2 รูปแบบ

| คุณลักษณะ | การลดสเกลเชิงพลศาสตร์ (Dynamical Downscaling) | การลดสเกลเชิงสถิติ (Statistical Downscaling) |
|---|---|---|
| **กลไกการทำงาน** | ซ้อนแบบจำลองภูมิอากาศภูมิภาค (RCM) คำนวณสมการฟิสิกส์บรรยากาศ | ใช้แบบจำลองสถิติ/ML (เช่น Random Forest, Bias Correction) จับคู่ข้อมูล |
| **ข้อดี** | รักษากฎฟิสิกส์ สะท้อนสภาพอากาศสุดขั้วและภูมิประเทศได้ดี | ประมวลผลรวดเร็วมาก ปรับแก้ความคลาดเคลื่อนเข้าหาสถานีจริงได้ดี |
| **ข้อจำกัด** | ใช้ทรัพยากรคอมพิวเตอร์และเวลาคำนวณสูงมาก | พึ่งพาความสัมพันธ์สถิติในอดีต อาจไม่ครอบคลุมฟิสิกส์ใหม่ในอนาคต |
| **ซอฟต์แวร์หลัก** | RegCM5, WRF-Chem | Machine Learning Regressors, ESD Frameworks |

## 4. ส่วนที่ 3: ชุดผลิตภัณฑ์ข้อมูลความละเอียดสูงของ DCCE (Data Product Family)

กรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม (DCCE) บริการชุดข้อมูลฉายภาพภูมิอากาศความละเอียดสูงสำหรับประเทศไทย แบ่งออกเป็น 4 ผลิตภัณฑ์สำคัญ:

```
                          +-----------------------------------+
                          | DCCE Climate Data Product Family  |
                          +-----------------------------------+
                                            |
        +------------------+----------------+------------------+------------------+
        |                  |                                   |                  |
+---------------+  +---------------+                   +---------------+  +---------------+
|   GridData    |  |   WRF-Chem    |                   |    RegCM5     |  |  Statistical  |
| Raster Grid   |  | Atmospheric   |                   | Regional Phys |  |  Downscaling  |
| NetCDF / CSV  |  | Chemistry/AQ  |                   | Extreme Event |  | Rapid Station |
+---------------+  +---------------+                   +---------------+  +---------------+
```

### 4.1 ตารางคุณลักษณะของชุดผลิตภัณฑ์ (Product Feature Matrix)

| ผลิตภัณฑ์ | ประเภท Downscaling | จุดเด่นเชิงวิชาการ | รูปแบบไฟล์ | กลุ่มผู้ใช้งานหลัก |
|---|---|---|---|---|
| **GridData** | Gridded Downscaled Output | ข้อมูลตารางพร้อมใช้งานเชิงพื้นที่ ครอบคลุมตัวแปรภูมิอากาศพื้นฐาน | NetCDF (`.nc`), CSV | นักวิเคราะห์ GIS, นักวิจัยผังเมือง |
| **WRF-Chem** | Dynamical (RCM + Chemistry) | บูรณาการฟิสิกส์บรรยากาศร่วมกับเคมีละอองลอย (Aerosols) และคุณภาพอากาศ | NetCDF | นักวิชาการสิ่งแวดล้อมและคุณภาพอากาศ |
| **RegCM5** | Dynamical (RCM Physics) | แบบจำลองภูมิภาคยุคใหม่ เน้นเหตุการณ์สภาพอากาศสุดขั้วและมรสุม | NetCDF | นักอุตุนิยมวิทยา, ผู้เชี่ยวชาญภัยพิบัติ |
| **Statistical Downscaling** | Empirical / Statistical | ประมวลผลรวดเร็ว ปรับแก้ค่าน้ำฝน/อุณหภูมิเข้าหาสถานีวัดจริง | CSV, Excel, NetCDF | นักวางแผนนโยบาย, ที่ปรึกษาโครงการ |

## 5. ส่วนที่ 4: แผนผังหลักฐานและการสื่อสารเชิงทัศน์ (Evidence Mapping & Visual Strategy)

### 5.1 การล็อกระบบสัญลักษณ์และจานสี (Design System Lock)
- **Palette**:
  - Egyptian Blue (`#0A369D`): สีหลักสำหรับองค์ประกอบโครงสร้างและหัวข้อสำคัญ
  - Sapphire Sky (`#4472CA`): สีรองสำหรับผังการเชื่อมโยงและกรอบข้อมูล
  - Glaucous (`#5E7CE2`): สีเน้นสำหรับดัชนีและตัวแปรภูมิอากาศ
  - Baby Blue Ice (`#92B4F4`): สีพื้นหลังส่วนข้อมูลเปรียบเทียบ
  - Pale Sky (`#CFDEE7`): สีพื้นหลังเน้นความสบายตาและอ่านง่าย
- **Illustration Style**: Flat Vector Construction, Bold Simplified Silhouettes, Clean Geometric Forms, Thick Outlines, Solid Fills พร้อม subtle shading.

### 5.2 ข้อห้ามและขอบเขตการนำเสนอเชิงทัศน์
1. **ห้ามแสดงผลเป็นตัวเลขการพยากรณ์รายวัน**: ต้องสื่อสารถึง "ช่วงความเป็นไปได้ตามฉากทัศน์"
2. **ห้ามเลียนแบบ UI หน้าจอดาวน์โหลดจริง**: ให้ใช้ไดอะแกรมอินโฟกราฟิกอธิบายขั้นตอนแทนภาพแคปหน้าจอที่ไม่แน่นอน
3. **ข้อความทั้งหมดต้องเป็น Editable Text Component**: เพื่อรองรับการปรับแก้ตัวอักษรในโปรแกรม Canva หรือแอปพลิเคชันออกแบบ
