# Thai Technical Report Writing Style Guideline (NCAIF/CRDB Context)

**Objective**: To ensure all Thai-language technical outputs maintain a professional, authoritative, and service-oriented tone consistent with the "บทสรุปความต้องการใช้งานบริการข้อมูลสารสนเทศด้านภูมิอากาศ.md" baseline.

---

## 1. Core Persona & Tone
*   **Persona**: An authoritative technical partner/consultant.
*   **Tone**: Formal, objective, and precise. Avoid conversational filler or overly decorative language. 
*   **Focus**: Prioritize "Functional Value" and "Institutional Necessity."

## 2. Structural Conventions
*   **Headings**: Use `## บริการ [N] - [Name]` for service definitions.
*   **The "Definition Paragraph"**: Immediately follow a heading with a 3–5 line paragraph explaining the service's core function, its role in the ecosystem (e.g., Single Source of Truth), and the specific value it provides to the user.
*   **Grounded Use Cases**: Use numbered lists to present "กรณีการใช้งาน" (Use Cases) or "ตัวอย่าง" (Examples). These must be specific, mentioning levels of government (Provincial, Sub-district) or specific sectors (Industrial, Agricultural).

## 3. Linguistic Patterns
*   **Technical Interleaving**: Include standard English technical terms in parentheses next to the Thai translation to ensure professional alignment (e.g., `มูลค่าเสียหายเชิงเศรษฐกิจ (Economic Loss)`, `แหล่งข้อมูลความจริงเพียงหนึ่งเดียว (Single Source of Truth)`).
*   **Action-Oriented Verbs**: Start descriptions with strong verbs: `ประเมิน...`, `ระบุ...`, `ออกแบบ...`, `ติดตาม...`, `สื่อสาร...`.
*   **Stakeholder Specificity**: Explicitly mention who the service is for (e.g., `สำนักงบประมาณ`, `อปท.`, `ผู้ประกอบการ SME`, `วิศวกรและสถาปนิก`).

## 4. Key Vocabulary (Institutional Jargon)
Use these terms to maintain consistency with the project's logic:
*   **Decision Support**: `หลักฐานสนับสนุนการตัดสินใจ`, `ประกอบการจัดทำเทศบัญญัติงบประมาณ`
*   **Resilience**: `มีภูมิคุ้มกันต่อการเปลี่ยนแปลงสภาพภูมิอากาศ`, `ความเปราะบาง`
*   **Standardization**: `รับรองมาตรฐานและคุณภาพ`, `ระเบียบวิธีการ`, `แหล่งข้อมูลความจริงเพียงหนึ่งเดียว`
*   **Spatial Precision**: `ความละเอียดระดับตำบล`, `ระดับแปลง`, `ระดับหน่วยย่อยของการทำสำมะโนประชากร (Enumeration Unit)`

## 5. Sample Construction Pattern
> **[Service Name]**
> [Functional Description + Strategic Goal + Key Technology]
> 
> **กรณีการใช้งานที่เกี่ยวข้อง:**
> 1. [Specific Scenario A + Target Stakeholder + Benefit]
> 2. [Specific Scenario B + Data Requirement + Outcome]
