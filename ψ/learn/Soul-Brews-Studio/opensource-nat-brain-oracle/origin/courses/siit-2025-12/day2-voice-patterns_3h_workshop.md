## 5 Patterns ที่จะได้เรียน

| Pattern | เรียนรู้อะไร |
|---------|-------------|
| **Delegate Reading** | แทนที่จะให้ AI ตัวหลักอ่านไฟล์ใหญ่ๆ ให้ AI ตัวเล็กอ่านแล้วสรุปมาให้ ประหยัดค่าใช้จ่ายและเร็วขึ้น |
| **Context-Finder FIRST** | ก่อนทำงานใดๆ ให้หาข้อมูลก่อนเสมอ อย่าเดาหรือทำเลย ค้นหาก่อนจะลดความผิดพลาด |
| **Human Confirmation** | AI ไม่ควร commit หรือ save อัตโนมัติ ต้องถามผู้ใช้ก่อนทุกครั้งที่จะทำสิ่งที่เปลี่ยนแปลงไม่ได้ |
| **Plugin Architecture** | แยก agent ออกเป็นส่วนๆ (module) เพื่อให้ดูแลรักษาง่าย และนำไปใช้ซ้ำในโปรเจกต์อื่นได้ |
| **Knowledge Distillation** | เปลี่ยนบันทึกการทำงาน (raw) → บทเรียนที่เรียนรู้ (patterns) → หลักการถาวร (soul) |
