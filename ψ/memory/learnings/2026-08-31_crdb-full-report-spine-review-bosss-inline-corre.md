# CRDB full-report spine review: Boss's inline corrections captured into LEXICON_T

CRDB full-report spine review: Boss's inline corrections captured into LEXICON_TH.json v4.5 and STYLE_PACK_TH.md. Lexical bans: ความล้มเหลว→อุปสรรค (too negative/personal in technical report); ชิ้นงาน→ผลผลิต (verified against project's own redirect-plan terminology); ห่วงโซ่ and คอขวด→อุปสรรค, banning both the words and the bottleneck-chain metaphor construction, with an explicit citation exception for the established artifact title "ห่วงโซ่คุณค่าข้อมูล / DCCE Data Value Chain.md". Structural principles added to STYLE_PACK_TH.md: (1) Thai prose keeps elaborating nouns rather than dropping them — a bare unexplained noun reads as vague, not concise; (2) ban metaphor outright in technical/institutional writing; (3) be conservative about reflexively translating English adjectives into a เชิง- prefix, and cut bare adjectives/quantifiers that add no information; (4) prefer helping/auxiliary verbs like ช่วย when an instrument enables rather than causes an outcome. Also notable: rationale for a non-mechanical promotion doesn't always need a fresh AskUserQuestion round — when the user has already stated explicit rationale verbatim (not inferred by the assistant), that satisfies writing-th's Stage 4c rationale gate directly.
