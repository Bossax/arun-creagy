# Skill designs must be unified under a single SKILL.md and labeled as strict mand

Skill designs must be unified under a single SKILL.md and labeled as strict mandatory directives rather than suggestions to prevent context fragmentation and drift. In multi-agent environments, separating core instructions into secondary reference files (like ruleset.md) causes other agent instances to treat the guidelines as optional recommendations instead of strict system boundaries.
