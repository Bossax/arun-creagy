# Thai institutional writing style capture (2026-08-26): Enforce anti-fragmentatio

Thai institutional writing style capture (2026-08-26): Enforce anti-fragmentation (unifying floating count/metadata phrases in intro paragraphs), list parallelism in bullet points (using symmetric relative clauses like ที่สามารถ... / ซึ่งผ่าน...), and enumeration cadence (using commas and formal conjunctions และ / รวมถึง instead of bare whitespace in tables and metric lists).
