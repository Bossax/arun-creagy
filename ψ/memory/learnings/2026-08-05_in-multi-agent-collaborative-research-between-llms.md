# In multi-agent collaborative research between LLMs (e.g., Claude Code + Antigrav

In multi-agent collaborative research between LLMs (e.g., Claude Code + Antigravity CLI), folder-based structured handoffs paired with a 3-tier subagent reasoning model architecture (Orchestrator: Medium, Query Runner: Low/Flash, Second-Opinion Reviewer: High/Pro) provide maximum grounding fidelity without token exhaustion. Furthermore, grounding early-stage blueprints against literature requires explicit 'phase, don't bundle' discipline and DATER dimension trimming to avoid the 'boiling-the-ocean' anti-pattern within tight delivery windows.
