# Session Retrospective Learning (2026-08-26):

Session Retrospective Learning (2026-08-26):
1. Whitespace is an ambiguous delimiter in Thai tables: In Thai prose without inter-word spaces, chaining multiple nouns/metrics in table cells using only whitespace creates run-on confusion. Use explicit commas (,) and formal conjunctions (และ, รวมถึง, พร้อมด้วย) for visual scanability.
2. Introductory fragments break cadence: Avoid opening briefing sections with detached count phrases (e.g., สไลด์หลัก 14 แผ่น...). Unify scoping metadata and purpose into a single complete sentence (เอกสารนี้ประกอบด้วย... ซึ่งจัดทำขึ้นเพื่อ...).
3. Slide bullet parallelism: Enforce uniform grammatical structures across list items (e.g., symmetric relative clauses ที่สามารถ... / ซึ่งผ่าน...).
4. Inspect git status before running git diff in In-Place mode to verify the exact tracked path in the active working tree.
