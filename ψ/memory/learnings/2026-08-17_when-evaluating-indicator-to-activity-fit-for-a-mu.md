# When evaluating indicator-to-activity fit for a multi-domain/multi-habitat activ

When evaluating indicator-to-activity fit for a multi-domain/multi-habitat activity, judge each candidate indicator as a member of a needed indicator SET, not as something that must singlehandedly cover the activity's full scope. Cutting a partial-coverage indicator is only correct if something better replaces it — if no broader alternative exists, cutting it just deletes information for no gain. Related trap: explicit mention of one sub-topic in a guideline/measure text is not proof of exclusive scope narrowing — it may just flag a sub-topic commonly omitted from generic framing (e.g. "mangrove" called out within "marine and coastal" because mangrove often gets dropped from generic marine/coastal lists, not because the activity excludes other coastal habitats). Also: don't write a specific-sounding fix ("use a different M&E indicator") without checking the real candidate pool for whether an alternative actually exists — in this session 3 of 5 such recommendations had no real alternative at all, and the honest finding was "no adequate option exists" (a coverage gap), not a swap.
