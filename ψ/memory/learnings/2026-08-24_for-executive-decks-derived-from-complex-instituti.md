# For executive decks derived from complex institutional analysis, a component-by-

For executive decks derived from complex institutional analysis, a component-by-component slide mapping is not a narrative. The deck must first state one decision thesis, then sequence evidence → institutional cause → dependency mechanism → roadmap adjustment → decision request. Tables and lists should support that causal spine, not replace it. Validate the narrative in prose before implementing visual slides; HTML validity and slide count cannot detect incoherence.
