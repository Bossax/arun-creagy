# In a federated multi-agent network (MAW), orchestration capabilities must be sym

In a federated multi-agent network (MAW), orchestration capabilities must be symmetric across all peers rather than centralized in one node, structured around a 3-step cognitive escalation (Ask yourself -> Ask a friend -> Tell friends to do their parts). Inter-agent tickets must use dynamic requester inboxes and archive to local outboxes, never polluting human-curated atomic knowledge vaults. Multi-agent convergence should default to headless file-joins to avoid context and token degradation, treating visual tmux canvases as an on-demand presentation layer.
