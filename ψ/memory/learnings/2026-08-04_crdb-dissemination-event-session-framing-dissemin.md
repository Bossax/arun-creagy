# CRDB Dissemination Event Session Framing: Dissemination events hosted under spec

CRDB Dissemination Event Session Framing: Dissemination events hosted under specific consulting contracts (like CRDB) must remain strictly grounded in that project's deliverables, scope, and technical models (CDM/LDM) rather than mixing in broader multi-year agency budget defense narratives.
