# When a stakeholder question resists a confident direct answer on a long-running

When a stakeholder question resists a confident direct answer on a long-running project, search the project's own prior artifacts (oracle_search, then /trace or targeted Grep) before synthesizing a fresh framework. A plausible-sounding new synthesis is strictly worse than restating an artifact the project already produced and partially socialized with the client — it keeps the citation trail honest and avoids inconsistent recommendations across deliverables. When escalating to a skill like /trace, treat its prescribed heavy mode (e.g. parallel subagents) as one option, not mandatory — a cheaper targeted search over a known local directory can answer the same question, but say so explicitly rather than silently deviating.
