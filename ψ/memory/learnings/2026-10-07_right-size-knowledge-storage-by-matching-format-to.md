# Right-size knowledge storage by matching format to entity scale: reserve relatio

Right-size knowledge storage by matching format to entity scale: reserve relational tables (SQLite) for uniform mass catalogs (>1000 items) to prevent vector pollution, modular Markdown (<100 items) for conceptual models and editorial gates, and paragraph-level vector embeddings (bge-m3) for rhetorical exemplars and semantic style matching. In MAW, separate parallel fan-out (maw hey team) from conductor orchestration.
