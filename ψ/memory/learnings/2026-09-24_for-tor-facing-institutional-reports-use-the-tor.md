# For TOR-facing institutional reports, use the TOR-numbered deliverable folder as

For TOR-facing institutional reports, use the TOR-numbered deliverable folder as the primary evidence spine. Separate consultation evidence from implementation evidence as feedback source -> documented revision; never infer that a recommendation was implemented merely because it was raised. Use trace and archive material only to resolve gaps or contested causal links. Keep one owner for integrated chronological prose; delegate only bounded evidence audits and independent final review.
