# Lesson Learned — rrr skill follow-through

The `/rrr` skill must be executed as a memory-writing workflow, not summarized as a response. When the user asks for `/rrr`, the expected output is a retrospective artifact, a lesson-learned artifact, and an updated metrics row. If timestamps cannot be mined, the timeline should explicitly say `timestamps unavailable` rather than guessing.

## Generalizable rule
When a skill is designed to preserve memory, the correct default is to create the memory artifact immediately and only explain the process if the skill itself asks for it.
