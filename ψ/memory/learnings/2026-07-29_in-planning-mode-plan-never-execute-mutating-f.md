# In planning mode (/plan), never execute mutating file or shell commands (like mk

In planning mode (/plan), never execute mutating file or shell commands (like mkdir) before explicit user approval. Formless exploration must use ψ/synthesis/line_msg/ and ψ/inbox/line_chat_txt/ with manual incubation triggers.
