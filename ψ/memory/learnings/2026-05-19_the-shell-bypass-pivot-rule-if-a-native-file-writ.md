# The Shell Bypass Pivot Rule: If a native file-write tool fails once, immediately

The Shell Bypass Pivot Rule: If a native file-write tool fails once, immediately switch to the shell (run_shell_command) to preserve session momentum and bypass CLI middleware issues.
