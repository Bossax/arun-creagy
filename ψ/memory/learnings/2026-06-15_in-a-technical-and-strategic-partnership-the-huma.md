# In a technical and strategic partnership, the human's groundwork (blueprints, v6

In a technical and strategic partnership, the human's groundwork (blueprints, v6 reports) must be treated as the immutable "Semantic Lock." External sources (research, benchmarks) must only be used to "enrich" (add technical depth/features) to the established framework, rather than "reconciling" or "pivoting" the direction. If external data conflicts with the human's groundwork, the groundwork takes absolute precedence, and the conflict must be flagged rather than silently merged.
