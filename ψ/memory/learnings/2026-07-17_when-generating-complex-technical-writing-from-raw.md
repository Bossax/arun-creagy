# When generating complex technical writing from raw data, utilize subagent orches

When generating complex technical writing from raw data, utilize subagent orchestration where each subagent reads specific raw JSON extractions and drafts a single section. Do not attempt to blitz large documents in a single shot from memory. Always verify and adhere strictly to directory structure mandates (e.g., 03-brain-structure.md) before creating new folders.
