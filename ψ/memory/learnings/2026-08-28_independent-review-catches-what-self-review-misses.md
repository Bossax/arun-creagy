# Independent review catches what self-review misses, even when the drafting agent

Independent review catches what self-review misses, even when the drafting agent is being careful. When resolving inline human corrections on three AI-drafted exec-summary sections and running them through a writing-quality harness (writing-th v5), the drafting agent made every fix carefully, cross-checked against evidence sidecars, and still had all three sections come back FAIL on the first independent review — on real major findings (a misattributed ownership claim, a missing required caveat, an unsourced claim, a fix that reproduced exactly the excluded detail it was meant to avoid). One finding needed two follow-up rounds: the first fix removed over-detailed content but left an old table row re-promoting the same excluded content under new packaging — a second independent check was needed to catch the fix was only half-done. Pattern: self-verification by the same agent that made the edit is structurally weak even when careful, because the agent's own mental model of "what I changed" doesn't include "what I forgot to also change." How to apply: when a workflow calls for an independent editorial/review gate, budget for at least 2 fix-reverify cycles per unit as the normal case, not a fallback. Don't treat a fix as done until a genuinely independent check (fresh context, no shared rationale, instructed to re-derive verdicts from source documents rather than trust the drafting agent's summary) confirms it — and re-verify with fresh eyes again after every fix, since a partial fix can look complete from inside the fixing agent's own frame.
