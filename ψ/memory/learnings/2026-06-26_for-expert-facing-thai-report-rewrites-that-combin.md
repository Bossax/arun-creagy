# For expert-facing Thai report rewrites that combine institutional workflow, inte

For expert-facing Thai report rewrites that combine institutional workflow, international methodology, and target data architecture, do not draft prose until the supporting artifact chain is complete. Reliable sequence: raw evidence capture, methodology distillation, comparative analysis, target technical design, source-availability review, gap analysis, execution plan, outline approval, then full prose rewrite. This prevents inflated claims, compensation-loss conflation, and architecture prose that sounds plausible but is not evidence-safe.
