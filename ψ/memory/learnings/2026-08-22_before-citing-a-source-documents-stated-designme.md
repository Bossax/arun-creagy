# Before citing a source document's stated design/mechanism as evidence something

Before citing a source document's stated design/mechanism as evidence something works or exists functionally, verify separately whether it actually operates — a document describing a process ("compares results to targets, adjusts policy") is evidence of intent/specification, not evidence of operation. Check for (a) separate evidence of actual operation, and (b) whether the design contains the institutional/authority layer needed to function, not just the measurement/technical layer. A related conflation: answering "is X a formal governance stage" using an activity/spending taxonomy instead of a stage-based cycle framework — different axis, same root cause of reaching for the nearest available classification without checking it answers the actual question.
