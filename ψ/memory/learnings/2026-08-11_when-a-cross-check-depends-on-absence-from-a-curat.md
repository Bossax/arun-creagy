# When a cross-check depends on absence-from-a-curated-extract as evidence of non-

When a cross-check depends on absence-from-a-curated-extract as evidence of non-existence, verify the extract's completeness before treating a miss as a real finding — a subset file missing something is a weaker signal than the primary source missing it. Separately, in a T-E-D-A seal chain, Evidence (what was discovered) and Assets (what was authored/produced) must never be the same file — citing a deliverable as evidence for itself is circular.
