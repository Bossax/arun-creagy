# When a user names a source document as the sole reference for a presentation, tr

When a user names a source document as the sole reference for a presentation, treat it as the full content specification: discard prior derivative structure rather than selectively translating or patching it. For PDF delivery, use the presentation tool's proven exporter and preserve its required DOM contract (for frontend-slides, `.slide` elements at a fixed 1920×1080 stage). Verify that the PDF artifact exists before declaring success.
