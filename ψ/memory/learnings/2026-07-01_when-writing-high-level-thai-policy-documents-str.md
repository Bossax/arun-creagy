# When writing high-level Thai policy documents, strictly banish parenthetical Eng

When writing high-level Thai policy documents, strictly banish parenthetical English jargon (e.g., '(Data Strategy)', '(Dashboard)') to maintain an authoritative, non-translated tone, except for universally recognized acronyms like API or TOR. When discussing data governance, explicitly anchor roles (Data Owner, Custodian, Steward) to the DGA Data Governance Framework to ensure institutional legitimacy.
