# Harness Engineering controls (Feedforward/Feedback) should not replace human-cen

Harness Engineering controls (Feedforward/Feedback) should not replace human-centric strategic writing skills, but rather be integrated into their execution phase (Stage 4/5). Rhetoric requires human alignment; execution requires deterministic LLM validation.
