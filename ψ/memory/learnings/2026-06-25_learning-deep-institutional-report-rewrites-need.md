# Learning: Deep institutional report rewrites need evidence packets before prose.

Learning: Deep institutional report rewrites need evidence packets before prose.

Pattern:
1. split the weak section into evidence domains,
2. extract each domain into a focused note,
3. build a source-to-claim matrix for each section,
4. only then rewrite the final prose.

Why it matters:
Generic prose often comes from skipping the layer between source reading and sentence writing. When named frameworks, institutional workflow, and design logic must all appear precisely, the missing layer is usually not better wording but better claim control.
