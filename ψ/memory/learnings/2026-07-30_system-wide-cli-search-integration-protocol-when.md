# System-wide CLI Search Integration Protocol: When installing system-wide search 

System-wide CLI Search Integration Protocol: When installing system-wide search tools (Perplexity pplx and Brave Search bx), compile/deploy standalone binaries to user profile directories (~/.pplx-cli, ~/.brave-search-cli), set permanent Windows User environment variables (PERPLEXITY_API_KEY, BRAVE_SEARCH_API_KEY), and register global skills in ~/.gemini/skills/<tool>/SKILL.md with explicit YAML frontmatter triggers and default execution protocols.
