# For evidence-led visual design, treat final-language layout copy as a Stage 3 pr

For evidence-led visual design, treat final-language layout copy as a Stage 3 production companion to the generation/layout handoff. Keep each language in a separate editable text-only file (for example, layout_text_th.md) created alongside the handoff. The handoff points to the file; it does not absorb the copy. This keeps prompts concise, preserves controlled typography and citations, and makes copy revisions independent of image-generation instructions.
