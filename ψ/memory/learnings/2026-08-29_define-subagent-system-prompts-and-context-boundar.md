# Define subagent system prompts and context boundaries canonically in shared refe

Define subagent system prompts and context boundaries canonically in shared references (e.g. references/subagent-prompts.md) at the workspace level rather than locking them into runtime-specific files. This allows multi-runtime systems (Claude Code, Google Antigravity, Codex) to share the same deterministic gate logic while cleanly mapping to native invocation primitives (invoke_subagent vs Agent).
