# When a writing plan excludes a framing device (e.g., IPCC risk chain) from one d

When a writing plan excludes a framing device (e.g., IPCC risk chain) from one deliverable variant (executive summary) that a sibling variant (full report) uses explicitly, don't default to drafting a compressed version of the same device. Ask what replaces it as the reader-facing explanation instead — the plan author may have a specific alternate framing (e.g., the Conceptual Data Model's data domains, which already embed the excluded ontology) that only surfaces if asked, not inferred from the exclusion list alone. Caught this at the /writing-th content-contract approval gate, before any prose was written, which made the correction cheap.
