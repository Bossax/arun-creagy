# When compressing a large validated body of work (e.g. N validated findings, M re

When compressing a large validated body of work (e.g. N validated findings, M requirements) into a fixed-size deliverable like a slide deck, explicitly count what's actually presented and diff it against any "N of M" / "all X" quantifier claim made elsewhere in the same document (e.g. speaker notes citing "7 failure modes") before calling the work done. This is a mechanical pre-flight check, not a vibe check — naming this as a lesson once did not prevent reproducing the exact same gap (4-of-7 failure modes turned into slides while notes claimed all 7) in the very next session on the same document.
