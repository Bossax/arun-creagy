# When a human reviewer inserts margin notes (e.g., '%% วิกฤติอะไร %%') in a draft

When a human reviewer inserts margin notes (e.g., '%% วิกฤติอะไร %%') in a draft asking for clarification, the AI must resolve these queries by returning to the NotebookLM Phase 2/3 extractions (`raw-copy.md`) to find grounded answers, rather than guessing. The final draft should integrate these answers directly.
