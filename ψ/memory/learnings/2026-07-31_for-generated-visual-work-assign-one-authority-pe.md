# For generated visual work, assign one authority per decision: the rendered HTML 

For generated visual work, assign one authority per decision: the rendered HTML layout controls composition; a style-only reference controls illustration language; final-language layout text controls copy; and a self-contained review note controls revisions. Do not attach a full reference image to the full-rollup generation prompt when it can dominate composition. Stage 5 must delegate asset identification and sequential image-prompt creation to ChatGPT, rather than pre-inventing the asset list in the workflow.
