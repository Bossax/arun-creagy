# Task-driven Harnessing: System prompt bloat degrades LLM reasoning. Do not load 

Task-driven Harnessing: System prompt bloat degrades LLM reasoning. Do not load specific rulesets (e.g. writing style guides) globally. Keep system prompts lean (containing only the directory structure and non-negotiable safety rules) and localize constraints inside specific task skills. Combine this with deterministic scripts (Python/Typescript) running as mandatory terminal gates to prevent agent self-auditing hallucination, goal-completion bias, and destructive compression.
