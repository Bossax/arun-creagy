# Atomicity is conceptual, not source-based. When querying large PDFs in NotebookL

Atomicity is conceptual, not source-based. When querying large PDFs in NotebookLM, do not ask compound queries. Instead, break down targets into single-focus questions and run multiple micro-queries against the same source ID, performing all comparative synthesis locally in the repository files after saving the raw responses.
