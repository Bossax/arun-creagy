# When new evidence changes the unit of analysis, do not patch it into an existing

When new evidence changes the unit of analysis, do not patch it into an existing research taxonomy merely because the topics touch. Create a separate, directly named research domain; preserve each source as a source-faithful atomic register with stable IDs; express cross-source logic through typed relationships; and convert unsupported claims, hidden assumptions, and implementation dependencies into research-ready questions with evidence requirements and completion criteria. Keep source assertions, supplied evidence, analyst inference, and unresolved validation visibly separate.
