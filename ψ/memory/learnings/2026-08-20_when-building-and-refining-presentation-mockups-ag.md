# When building and refining presentation mockups against an Information Architect

When building and refining presentation mockups against an Information Architecture (IA) and sitemap specification:
1. Strict Structural Fidelity: Never substitute a flat, tag-filterable grid with an asymmetric split layout unless explicitly instructed, and always preserve the verbatim sequence of nodes and tools from the sitemap.
2. Visual Frame Geometry & Padding: Full-bleed diagrams and banners (e.g. PROVIDE pathways, M&E platform banners) require dedicated viewport height and proper containment (object-contain) to eliminate label clipping or cutoff on fixed-ratio presentation frames (10:8).
3. Selective Preview Mapping: Allocate image preview thumbnails strictly to cards that possess concrete visual assets, providing clean structured metadata badges for data catalogs and text-first registries.
