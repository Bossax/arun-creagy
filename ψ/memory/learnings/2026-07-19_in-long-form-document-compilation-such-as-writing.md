# In long-form document compilation (such as writing structured scientific review 

In long-form document compilation (such as writing structured scientific review articles), initial generation must avoid high-level summaries and directly reference the raw extracted JSON data sources to maintain 1-to-1 fidelity with historical campaigns, equations, and specifications. Utilizing a multi-agent orchestration approach—spawning separate subagents dedicated to individual chapters—is a powerful strategy to bypass context window size limitations, prevent semantic drift, and compile highly precise, detailed technical foundations in parallel before consolidation.
