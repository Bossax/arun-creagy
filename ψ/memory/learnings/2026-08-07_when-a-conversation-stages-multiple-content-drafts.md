# When a conversation stages multiple content drafts over several turns before any

When a conversation stages multiple content drafts over several turns before any of them get committed to disk, editing based only on the most recent exchange risks silently dropping earlier-agreed changes that haven't been written yet. Before executing a write/edit that follows multiple rounds of drafting, re-read the target file and diff it against the FULL set of changes promised across the conversation so far, not just the change discussed in the current turn.
