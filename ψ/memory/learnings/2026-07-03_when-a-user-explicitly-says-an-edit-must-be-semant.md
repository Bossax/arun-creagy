# When a user explicitly says an edit must be semantic only and must not compress 

When a user explicitly says an edit must be semantic only and must not compress content, treat that as a hard fidelity boundary, not a style preference. Rewording may improve Thai cadence, but it must not remove examples, caveats, institutional references, or analytical distinctions. In Thai technical report writing, detail often carries the argument itself; trimming it can change the evidentiary weight of the section even if the surface meaning still looks intact.

## Patterns
- Use preservation-first task labels instead of compression-oriented labels.
- Put a fidelity check at the end of any prose revision that touches policy logic or report structure.
- When delegating subtasks, state explicitly that scope, examples, and qualifiers are non-removable.
- Treat “clearer Thai” as a local wording improvement, not a license to shorten.

## Caution
- A cleaner sentence is not automatically a safer sentence.
- If the source text is already carrying layered institutional meaning, the editing goal is clarification without collapse.
