# When executing visual design and slide text synthesis workflows under strict con

When executing visual design and slide text synthesis workflows under strict constraints, always prioritize direct file access (view_file, replace_file_content) over custom scripting wrappers or command-line pipelines for simple document reading and text replacement. Writing temporary utility scripts or shell pipelines for text-editing tasks introduces token overhead, risk of syntax parsing bugs, and acts as a cognitive buffer that can cause the agent to miss direct user comments in markdown execution plans. Furthermore, slide presentation graphics should leverage abstract geometric vector illustrations and layout-aligned system constellations over generic clip-art or simple shapes to convey technical capabilities (such as national security, data sharing networks, and modular systems) in a professional minimal corporate visual theme.
