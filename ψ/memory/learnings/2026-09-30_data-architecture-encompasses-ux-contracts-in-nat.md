# Data Architecture Encompasses UX Contracts: In national digital public platforms

Data Architecture Encompasses UX Contracts: In national digital public platforms, data architecture is inseparable from information architecture and user experience. Developer-Ready Design (DRD) specifications and screen interaction state trees define the downstream data contracts, query shapes, and latency thresholds that the data warehouse must serve. Omitting UX from an enterprise data architecture curation misses half the system boundary. When staging domain knowledge into specialized Oracles, preserve client architectural assets (CDM, schemas, UX specs, NFRs) while strictly filtering out ad-hoc code scripts and theoretical academic literature.
