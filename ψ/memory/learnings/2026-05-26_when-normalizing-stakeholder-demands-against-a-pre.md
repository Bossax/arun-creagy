# When normalizing stakeholder demands against a predefined framework, prioritize 

When normalizing stakeholder demands against a predefined framework, prioritize matching the **functional intent** over the **semantic wording** or **delivery mechanism**. A request for an "API for engineering parameters" maps to an existing "transport infrastructure planning" use case. It is a "Hardening" of an existing use case (Utility shift), not a "Novel" use case. Always locate and read the canonical definition of a taxonomy before mapping data to it.
