# When rendering HTML slide presentations with narrow non-Latin fonts (such as TH

When rendering HTML slide presentations with narrow non-Latin fonts (such as TH Sarabun) to PDF or high-resolution viewports, setting font-size too low (below 23px) or using unbold font weights makes text appear excessively light and small. Increasing base font-weight to 600 for body and 800 for titles preserves crisp legibility and dark contrast without container overflow.
