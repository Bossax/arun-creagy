# When drafting a large, multi-section report with strict negative constraints (e.

When drafting a large, multi-section report with strict negative constraints (e.g., no colons, no AI transitions) and specific narrative flows, rely on sequential micro-scoped subagents passing context forward, rather than batching or using a single agent. This guarantees precise 1-to-1 adherence without structural hallucination.
