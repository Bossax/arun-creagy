# Abstract-Geometric Vector Prompting & Hardware Safe Zones for Physical Infograph

Abstract-Geometric Vector Prompting & Hardware Safe Zones for Physical Infographics: Avoid procedural UI terms (which produce blank templates) and photorealistic descriptions (which produce visual clutter). Use explicit abstract-geometric vocabulary (flat color-blocked shapes, concentric rings, minimalist symbols) and enforce absolute vertical height zones to protect hardware safe areas.
