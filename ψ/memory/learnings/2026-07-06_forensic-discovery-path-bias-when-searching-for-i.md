# Forensic Discovery Path Bias: When searching for institutional evidence or docum

Forensic Discovery Path Bias: When searching for institutional evidence or documentation, agents must avoid the bias of searching only raw staging directories (e.g., `inbox_source/`) and overlooking downstream synthesis directories (e.g., `output/03_DataInventory_DQ/` and `output/final_report/5.2/`). Exhaustive directory mapping must precede query execution.
