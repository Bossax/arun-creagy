# Thai Institutional Writing & Style Rules from Chapter 3 Human Teach-In:

Thai Institutional Writing & Style Rules from Chapter 3 Human Teach-In:
1. Direct Forward Syntax: Ban inverted negative conditionals ('จะยังไม่...จนกว่า...'). State the direct, positive, active duty ('โครงสร้างข้อมูล X จะต้องถูกนำไปพัฒนาเป็นส่วนหนึ่งของแพลตฟอร์ม...').
2. Operational Reality over Semantic Confusion: Distinguish data processing proxy misuse (relief budgets misused as proxy for damage) from vocabulary classification problems.
3. Domain Subject Anchoring: Prohibit aggressive noun-dropping in titles/H1/H2; keep full domain scope ('สำหรับการประเมินความสูญเสียและความเสียหายจากสาธารณภัย').
4. Purge AI Puffery & Melodrama: Strict ban on 'เชิงประจักษ์' (redundant with 'ชี้ให้เห็นว่า'), 'อย่างสิ้นเชิง' (theatrical melodrama), 'แกน' (awkward for framework components -> 'องค์ประกอบ'), 'งานประจำวัน' (collocation error in disaster management).
5. Self-Contained Recommendations: Eliminate repetitive trailing case study callouts from recommendation lists.
6. Executive Inset Standards: Use blockquote callouts for concise technical data definitions (> เขตข้อมูล (Data Field) คือ...).
