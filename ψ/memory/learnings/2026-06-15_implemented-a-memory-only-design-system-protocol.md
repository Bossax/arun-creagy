# Implemented a 'Memory-Only' design system protocol where DESIGN.md templates are

Implemented a 'Memory-Only' design system protocol where DESIGN.md templates are stored in global memory (ψ/memory/design/) and indexed in a REGISTRY.json. This allows the agent to semantically match project 'vibes' (e.g., futuristic, authoritative) and load design tokens into the session context only when needed, preventing persistent context window bloat in non-UI sessions.
