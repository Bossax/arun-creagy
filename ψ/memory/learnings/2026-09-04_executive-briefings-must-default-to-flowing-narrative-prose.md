# Learning — Executive Briefings Must Default to Flowing Narrative Prose & Contract Pruning

## Pattern
1. **Default to Continuous Narrative Prose Over Bulleted Outlines in Formal Reporting**:
   When a user or decision-maker asks for a "brief" of report chapters or technical sections (such as 1.1–1.4 in an institutional deliverable), the default deliverable modality should be publication-ready, paragraph-based narrative prose rather than bulleted lists or comparison tables. Bulleted summaries force the user to do the secondary work of expanding them into sentences. Authoring flowing paragraphs directly allows immediate copy-pasting into executive drafts.

2. **Prune Administrative Contract Noise to Elevate Policy Altitude**:
   When summarizing project scope (e.g., TOR 5.1–5.7) for executive audiences, avoid reciting administrative contract clause numbers, sub-clause references (e.g., TOR 5.2.1, 5.3.6), and meeting attendance quotas (e.g., "ไม่น้อยกว่า 15 คน"). These granular administrative details reduce high-altitude policy briefs to bureaucratic compliance checklists. Instead, abstract the scope into clear, functional work streams (e.g., 4 main work groups) and articulate the strategic value delivered by each stream.

3. **Pre-emptive Lexicon Alignment Eliminates Gate Friction**:
   In institutional writing pipelines (`writing-th`), known project bans—such as prohibiting bare acronyms like `NCAIF` in prose, swapping `หมวดหลัก` for `หัวข้อหลัก`, avoiding metaphor words like `ห่วงโซ่` and `ชิ้นงาน`, and using `ทรัพย์สิน` instead of `สินทรัพย์`—must be actively guarded against during initial draft authoring rather than relying on a post-hoc mechanical gate run (`lint_thai_writing.py`) to catch them.

## Why it matters
- Saves unnecessary iteration cycles between the user and the agent.
- Produces text that immediately matches the formal register expected by ministry executives and steering committees.
- Guarantees 100% first-pass clearance on automated mechanical quality gates.
