# For locally delivered HTML slide decks, declaring a Thai font in CSS is not veri

For locally delivered HTML slide decks, declaring a Thai font in CSS is not verification. Confirm the installed font files and the browser FontFace statuses, then bundle the regular and bold faces with the final package. Treat cards as a semantic component—use them for comparable metrics, discrete choices, or process stages; render causal argument and narrative directly on the slide canvas.
