# When designing multi-stage institutional writing skills (like writing-th), Stage

When designing multi-stage institutional writing skills (like writing-th), Stage 0 must be a hard, non-bypassable Plan Mode gate verifying the Triad Checklist (Outline, Trace-Grounded Evidence Base, Session Rules). Broad evidence discovery belongs in Stage 0 (Macro-Grounding via trace logs and file locking), while Stage 1 is restricted to Micro-Synthesis (binding bounded source files to Toulmin grounds and trace logs to Toulmin warrants). In multi-agent workspaces shared across Antigravity, Claude Code, and Codex, skills must provide explicit execution recipes for each runtime rather than assuming uniform UI modals or subagent APIs.
