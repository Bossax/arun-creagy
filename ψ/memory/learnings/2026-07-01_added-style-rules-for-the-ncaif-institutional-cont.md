# Added style rules for the NCAIF-Institutional context (v4.1) based on in-place e

Added style rules for the NCAIF-Institutional context (v4.1) based on in-place edits in Section 5.3.9:
1. Direct Mandates Over Philosophical Preaching: Avoid perspective shifts and moralizing advice; use direct, positive operational mandates (ต้องจัดตั้งแนวทาง..., จะต้องบริหาร...).
2. Eliminate English Contrast Scaffolding: Remove patterns like 'ไม่ได้... แต่...' or 'ไม่ควรถูกมองเป็น... แต่ควรถูกมองเป็น...' (not X, but Y).
3. Structured Breakdowns for Complex Lists: Format multi-item recommendations or pillars as numbered lists with line breaks instead of inline text.
4. Lexicon updates: Standardized 'ปรับปรุง' (for update), 'แดชบอร์ดแสดงผลข้อมูล', 'โครงสร้างทางเทคโนโลยีสารสนเทศ', 'ขอบเขตพื้นที่ที่หน่วยงานรับทุนจำเป็นต้องจัดการจริง', and 'ข้อเสนอเชิงยุทธศาสตร์ที่สำคัญ'.
