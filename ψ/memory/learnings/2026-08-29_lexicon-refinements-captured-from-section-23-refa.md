# Lexicon refinements captured from Section 2.3 refactor:

Lexicon refinements captured from Section 2.3 refactor:
1. 'กำหนดหลักร่วม' -> 'กำหนดหลักการ' (ban calque 'หลักร่วม', standardize on 'หลักการ')
2. 'เลือกหลักฐานได้เหมาะกับ' -> 'เลือกใช้ข้อมูลได้เหมาะกับ' (replace courtroom 'หลักฐาน' with domain-natural 'ข้อมูล' in platform usage)
3. 'ผู้รับคำเตือน' -> 'ผู้รับการแจ้งเตือน' (ban disciplinary 'คำเตือน', use DRM standard 'ผู้รับการแจ้งเตือน')
4. 'แจ้งค่าหรือระดับของภัย' -> 'รายงานค่าหรือระดับความรุนแรงของภัย' (elevate informal 'แจ้งค่า' to institutional 'รายงานค่าหรือระดับความรุนแรง')
5. 'งานวิเคราะห์' (in use case synthesis) -> 'ขั้นตอนการวิเคราะห์ข้อมูล' (use structured workflow terminology)
