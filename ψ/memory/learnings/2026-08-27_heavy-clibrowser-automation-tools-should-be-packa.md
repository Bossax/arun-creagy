# Heavy CLI/browser automation tools should be packaged as global skills pointing

Heavy CLI/browser automation tools should be packaged as global skills pointing to system-wide binary caches (~/AppData/Local/ms-playwright) rather than duplicating binaries inside workspace directories. Export engines should auto-detect fallback DOM selectors (.slide -> .s -> section).
