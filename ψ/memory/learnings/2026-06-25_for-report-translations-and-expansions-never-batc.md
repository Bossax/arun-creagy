# For report translations and expansions, never batch multiple sections into a sin

For report translations and expansions, never batch multiple sections into a single subagent and never withhold the source text. Enforce 1-to-1 micro-scoping where each subagent receives exactly one source section to translate and expand. Conflating 'depth' with 'academic complexity' leads to robotic jargon; explicitly ban literal translations and enforce natural institutional terminology.
