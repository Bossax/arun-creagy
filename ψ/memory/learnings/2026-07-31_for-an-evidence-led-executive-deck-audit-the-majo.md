# For an evidence-led executive deck, audit the major project-output folders befor

For an evidence-led executive deck, audit the major project-output folders before finalizing the narrative and map each high-value artifact to a slide. Treat ledger inspection as read-only discovery; reserve ledger-specific workflows such as /seal for modification. This prevents missing authoritative assets—such as sitemap and asset-inventory outputs—and avoids inventing a false access blocker.
