# Human Gate Bypass != Architecture Bypass: Permission from a user to skip a human

Human Gate Bypass != Architecture Bypass: Permission from a user to skip a human sign-off prompt (e.g., Stage 2 Blueprint gate in writing-th) is strictly an instruction to proceed automatically to the next subagent stage, NEVER a license to collapse an isolated multi-agent pipeline into an in-line parent context.

Deterministic CLI scripts (linters, cryptographic hash verifiers) verify syntax, token counts, and file integrity; they do not substitute for the unprimed, non-self-grading cognitive evaluation of an independent reviewer subagent. An agent that drafts prose must NEVER author its own Stage 5 review receipt.
