# Avoid over-engineering metadata conventions with complex generated index files (

Avoid over-engineering metadata conventions with complex generated index files (e.g. TAGS.md) or indirection mandates. Prefer single-source-of-truth configuration files (like root AGENTS.md) and leverage native editor search for tag discovery to eliminate friction and file bloat.
