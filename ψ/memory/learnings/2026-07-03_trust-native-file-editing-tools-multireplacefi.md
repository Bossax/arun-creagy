# Trust native file-editing tools (`multi_replace_file_content` / `replace_file_co

Trust native file-editing tools (`multi_replace_file_content` / `replace_file_content`) over writing custom Node.js/Bash scripts for string replacements, unless dealing with massive regex operations. Ad-hoc scripts for string replacement introduce unnecessary complexity, versioning conflicts, and debugging loops. Always attempt native tool operations first.
