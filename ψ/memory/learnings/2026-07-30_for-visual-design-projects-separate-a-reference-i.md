# For visual-design projects, separate a reference image into composition, illustr

For visual-design projects, separate a reference image into composition, illustration style, and information hierarchy before building the visual system. In evidence-led rollups, lock the reader questions and product scope before researching or laying out claims; otherwise platform affordances and source-image details can distort the narrative. Use the Stage 1 evidence gate to prevent premature HTML layout or image generation.
