# For evidence-bound institutional report revisions, keep three layers separate: (

For evidence-bound institutional report revisions, keep three layers separate: (1) record stakeholder feedback as speaker/group -> requested artifact or rule -> intended user or decision; (2) describe the consultant's incorporation as a later, explicitly attributed design action; and (3) identify the observable output version without backdating later evidence. When standardizing adjacent chronological subsections, use parallel paragraph jobs and tables but preserve asymmetric source roles—for example, one meeting deck may be the input to a revision while a later deck is the endpoint. Distinguish domain-level reclassification from entity-level continuity: a concept can leave the top-level domain view while remaining represented in the ERD. Use one-paragraph commits as human review checkpoints, staging only the target document and leaving unrelated working-tree changes untouched. The user's latest named subsection determines the next edit even when a broader standardization plan exists.
