# A preview-before-write gate surfaces reuse opportunities no single agent in a de

A preview-before-write gate surfaces reuse opportunities no single agent in a debate-then-synthesize pipeline can know about. Neither of two debate subagents nor a third synthesis agent knew an existing A-BTR dissection database could ground cheaper work than the field-level STM authoring both proposed — that reuse only surfaced when the human reviewed a concrete, specific WP-by-WP preview (named files, named scope) rather than an abstract options list. Abstract summaries don't trigger tacit "we already have X for that" corrections; concrete previews do. Treat "show the plan before writing" as a discovery mechanism, not just an approval gate — the specificity of the preview matters as much as the pause itself.
