# เมื่อผู้ใช้ได้อนุมัติขอบเขตของงานเขียนที่ชัดเจนแล้ว ให้เปลี่ยนจากการหารือไปสู่กา

เมื่อผู้ใช้ได้อนุมัติขอบเขตของงานเขียนที่ชัดเจนแล้ว ให้เปลี่ยนจากการหารือไปสู่การลงมือเขียนทันที ห้ามสร้างชั้นการวางแผนภายในซ้ำอีกก่อนเรียกเครื่องมือ เพราะการเตรียม patch ขนาดใหญ่โดยยังไม่เริ่มดำเนินการทำให้ผู้ใช้เห็นเพียงความเงียบและอาจทำให้ turn ถูกขัดจังหวะก่อนเกิดผลลัพธ์ วิธีปฏิบัติที่ถูกต้องคือยึดโครงสร้างที่ได้รับอนุมัติ เรียกเครื่องมือเขียนโดยตรง แล้วตรวจสอบไฟล์บนดิสก์ใน turn เดียวกัน หากงานมีขนาดใหญ่จนเสี่ยงต่อความล่าช้า ให้ลดความซับซ้อนของ artifact ให้ตรงกับคำขอ แทนการวางแผนว่าจะเขียนแผนอย่างไรเพิ่มเติม
