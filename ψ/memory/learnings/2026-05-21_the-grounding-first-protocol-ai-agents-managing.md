# The 'Grounding First' Protocol: AI agents managing project ledgers must perform 

The 'Grounding First' Protocol: AI agents managing project ledgers must perform a physical file audit (ls/read) and follow a sequential registration (Trigger -> Evidence -> Change -> Asset) to prevent naming drift and ensure auditable traceability.
