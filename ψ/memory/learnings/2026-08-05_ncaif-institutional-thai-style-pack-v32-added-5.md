# NCAIF-Institutional Thai style pack, v3.2: added 5 rules against literal-transla

NCAIF-Institutional Thai style pack, v3.2: added 5 rules against literal-translation artifacts surfaced in the CRDB timeline-th synthesis output. (1) No abstract positional nouns for decisions — "จุดยืน"/"จุดตัดเวลา" should become direct statements ("กำหนด...", "เส้นตาย"). (2) No metaphor-translation for institutional roles — "ประตูหลัก" (front door) should become "โครงสร้างหลัก". (3) No quoted English strategy codenames in Thai prose (e.g. "Blueprint-as-a-Shield") — describe the mechanism in plain Thai instead. (4) Named actor over generic role noun — "ผู้สนับสนุนโครงการ" becomes "กรม สส." when the actor is already known, same typology as DCCE -> กรมฯ. (5) "ปิด" is not a general completion verb — "ปิดผังเว็บไซต์"/"ปิดพจนานุกรม" read as literal-translated "close out"; use "สรุป" or a concrete verb, and reserve "ปิด"/"ผนึก" for an actual ledger Sealed status only.
