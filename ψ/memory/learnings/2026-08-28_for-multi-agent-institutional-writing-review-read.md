# For multi-agent institutional writing review, read the task-specific execution p

For multi-agent institutional writing review, read the task-specific execution plan before deriving workflow choices from a broad writing plan. Separate content defects, stylistic preferences, human comments, and typing slips; promote a new style rule only after repeated independent human evidence. A passing receipt must separately test causal mechanism and plan-boundary compliance, and final review must be independent of the drafting agent and its same-family reviewer. Resolve any contract-plan conflict before drafting so compliant text cannot violate the governing report scope.
