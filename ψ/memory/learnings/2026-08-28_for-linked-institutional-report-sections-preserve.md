# For linked institutional-report sections, preserve the evidence chronology befor

For linked institutional-report sections, preserve the evidence chronology before compressing it into prose: distinguish originating evidence (such as interviews), validation/refinement evidence (such as workshops), analytic synthesis (use cases to service concepts), and later decision layers (priority, detailed specification, readiness). Treat counts at each layer as different objects, and lock the corresponding primary sources in the writing contract and evidence sidecar. Mechanical style gates can catch recurring form faults, but independent semantic review remains necessary to test causal validity and source ancestry.
