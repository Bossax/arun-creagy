Captured workflow design for institutional writing:

- Separate evidence handling from prose generation.
- Use a staged pipeline: task framing → evidence inventory → gap decomposition → paragraph payload design → outline approval → skeleton draft → anti-shallow audit → style compression → reader-use audit → human edit and learn-back.
- Require every substantive paragraph to carry a claim, a concrete example, a consequence, and an institutional or technical mechanism.
- Treat style as subordinate to analytical payload.
- Use bullets or tables when comparing multiple services, gaps, or artifacts would otherwise blur distinctions.
- Add explicit gates that block abstract gap statements, recommendation paragraphs without named deliverables, and style smoothing that erases evidence.

This learning records the key design principle that readable institutional prose must not be allowed to become polished emptiness.
