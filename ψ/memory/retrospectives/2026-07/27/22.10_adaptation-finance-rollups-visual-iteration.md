## What the evidence showed

- Draft 0 had the desired editorial density, full-height visual rhythm, and strong hierarchy, but its copied/reference-like object set and generated copy could not be retained.
- Draft 3 embedded invented English text and unsupported process details, demonstrating that image generation must not be the source of final copy.
- Draft 4 correctly removed generated text but was too generic and used visual semantics that did not match the approved Thai content.
- Draft 5 and Roll-up 2 Draft 2 restored visual energy, but their empty areas were not internally structured enough to receive the approved Thai copy without drift or cramped typesetting.

## Decisions carried forward

- Use Draft 0 only as a composition benchmark: visual rhythm, distributed crops, diagonal framing, and editorial contrast.
- Use original imagery; never reproduce the supplied climate-finance image's composition or object arrangement.
- Treat `layout_text_en.md` and `layout_text_th.md` as the sole text authority.
- Keep generated imagery text-free.
- For Roll-up 1, generate explicit internal scaffolding: 3 preparation slots, 5 funding-match slots, 3 route cards, 5 lifecycle steps, action, and source note.
- For Roll-up 2, generate shared preparation scaffolding, equal GCF/AF panels, shared readiness checks, roles, and source note.

[→ AGENT DECISION] I made the wrong choice by responding to visual-semantic mismatches with copy-oriented notes instead of explicit visible transformations; this allowed image iterations to preserve the same incorrect scaffold.

## Lesson

For text-free infographic generation, separate three contracts: visual scaffolding, final editable copy, and source-verified semantics. A revision note must specify observable changes to icons, slots, flows, and hierarchy; it cannot rely on the future text to correct a visually incorrect image.
