## 2. Actions & Decisions

*   **Demographic Multiplier Integration**: Instead of loading pre-multiplied datasets, raw households are now disaggregated and multiplied on-the-fly inside the pipeline against dynamic DOPA registries. This preserves data lineage and enables provincial fallback tracking in [household_to_people_conversion_audit.csv](file:///C:/Users/sitth/OracleWorkspace/Arun_Creagy/ψ/incubate/DCCE/CRI/data_system/artifacts/analysis/household_to_people_conversion_audit.csv).
*   **CRI Completeness Strictness**: Enforced complete-group constraints. Hazards lacking relief statistics (Landslide, Wildfire, Cold Spell) are omitted from the composite indicator and have their own CRI Score metrics disabled in the interface, protecting the validity of index averages.
*   **Clean Name Resolution**: Rather than retrieving name strings from raw DDPM inputs, names are fetched from the DOPA spine master, eliminating NaN outputs.
*   **Zero-Impact UI Guards**: Replaced empty top-10 lists with unambiguous warnings informing the user that all tambons recorded zero impacts for the chosen hazard.
*   **[→ AGENT DECISION] Indentation Precision**: I made the wrong choice by introducing an extra leading space when updating the markdown block inside `pages/methodology.py`. This caused an `IndentationError` that broke app imports. Even for text and layout updates, I must run quick syntax compiler validation (`py_compile`) immediately after any code changes before declaring work complete.
