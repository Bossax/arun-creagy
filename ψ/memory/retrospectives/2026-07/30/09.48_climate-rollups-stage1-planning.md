# Retrospective: Climate rollups — Stage 0 to Stage 1 planning

**Date**: 2026-07-30 09:48 +07:00
**Oracle**: Codex | **Human**: Boss
**Project**: Climate data downscaling roll-ups

## What happened

This session returned to a new two-rollup climate-data design. We inspected five supplied climate information designs and `reference.jpg`, clarified that the reference illustration treatment—not merely its layout—should guide the visual system, and established a five-color blue palette.

The content direction changed from a platform access/request workflow to a product-and-concepts explanation:

- Rollup 1 explains climate projection data, importance, scenarios, and uses.
- Rollup 2 explains statistical and dynamical downscaling, why multiple models and scenarios are needed, and the four products: GridData, WRF-Chem, RegCM5, and Statistical Downscaling.

The project brief was updated, and a Stage 1 research plan was created with the required evidence hierarchy, research tools, Insight Cards, claim mapping, and acceptance criteria. A forward handoff was also created for the next session.

## What worked

- Reference inspection separated content sources from visual-style references.
- The visual style became specific enough to reuse: flat vector construction, bold simplified forms, geometric shapes, strong outlines, solid fills, subtle tonal shading, and clear visual metaphors.
- The workflow correctly stopped before layout and image generation because the revised claims require deeper evidence research.
- The Stage 1 plan explicitly assigns Brave Search MCP, native web search, Perplexity MCP, official-source verification, and direct platform inspection different roles.
- User-facing scope was corrected from “how to request data” to “what the data and products are.”

## What did not work

- The initial content framing overemphasized the platform request path and had to be corrected by Boss.
- Several exchanges interpreted the desired reference style too narrowly before the distinction between “cartoon” and “illustrated infographic vector iconography” was resolved.
- The first research pass started before the Stage 1 plan was written, which created unnecessary back-and-forth; the plan is now recorded for the next session.
- Perplexity authentication was configured but not re-tested in the current process after the persistent user-environment update.

## [→ AGENT DECISION]

I incorrectly treated the platform’s user request path as a central rollup topic after the initial Stage 0 framing, instead of revalidating the reader’s intended learning goal before carrying that structure forward. The correction is to make climate projection concepts and the four data products the content authority, with platform access kept out of scope unless Boss explicitly restores it.

## Reusable lesson

For visual-design projects, a reference image can carry three separate instructions: composition, illustration style, and information hierarchy. Resolve which layer the user wants before describing the visual system. For evidence-led rollups, freeze the reader questions and product scope before researching claims; otherwise platform affordances and source-image details can distort the narrative.
