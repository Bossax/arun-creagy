## 1. What Was Installed & How They Were Built

### 1. Perplexity CLI (`pplx-cli`)
* **Repository**: [nileshr/pplx-cli](https://github.com/nileshr/pplx-cli)
* **Location**: `C:\Users\sitth\.pplx-cli`
* **Build Mechanism**:
  * Cloned repository using `git clone`.
  * Installed dependencies (`drizzle-orm`, `@types/bun`, `typescript`, etc.) using **Bun v1.3.9**.
  * Compiled standalone executable `pplx.exe` using `bun build ./index.ts --compile --outfile pplx`.
* **Environment Variable**: `PERPLEXITY_API_KEY` set permanently in Windows User environment variables (`pplx-uNA4v...`) and stored in `C:\Users\sitth\.pplx-cli\.env`.

### 2. Brave Search CLI (`brave-search-cli` / `bx`)
* **Repository**: [brave/brave-search-cli](https://github.com/brave/brave-search-cli)
* **Location**: `C:\Users\sitth\.brave-search-cli`
* **Build Mechanism**:
  * Discovered that `brave-search-cli` is written in Rust (`Cargo.toml`).
  * Downloaded pre-compiled v1.5.0 Windows x64 release binary `bx-1.5.0-windows-amd64.exe` using `gh release download`.
  * Renamed to `C:\Users\sitth\.brave-search-cli\bx.exe`.
* **Environment Variables**: `BRAVE_SEARCH_API_KEY` and `BRAVE_API_KEY` set permanently in Windows User environment variables (`BSAPeLSQT...`) and stored via `bx config set-key`.
