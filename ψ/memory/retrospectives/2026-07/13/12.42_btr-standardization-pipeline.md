## 3. Lessons Learned

* **Decoupling Data from Compilers**: Freezing structured data tables (like 140+ quantitative mappings) inside python source code makes iteration rigid and blocks other agents from expanding the dataset. Using flat JSON files as the "handshake layer" maintains script portability.
* **Verification via Comma-Stripping**: Normalizing numeric values for text matching requires stripping commas (e.g. converting `64,000` to `64000` or handling float representations like `2025.0` to `2025`) before doing string lookups in narrative reports.
