## 3. Retrospective Analysis & Lessons Learned

### Friction & Pitfalls
*   **Path Scoping Bias**: Defaulting to standard research staging folders (like `inbox_source/`) caused the first wave of the trace to omit structured project outputs stored inside numbered directories (like `03_DataInventory_DQ/`) and draft report sections (like `final_report/5.2/`).
*   **Active Log Path Mismatch**: Seeking CLI chat jsonl logs inside the old `.gemini/tmp/arun-creagy/chats` directory caused path-lookup failure on Windows since current CLI files are stored in `C:\Users\sitth\.gemini\antigravity-cli\brain\`.

### Correction & Strategy
*   **Exhaustive Structural Mapping**: Prior to executing keyword queries on large repos, perform a broad directory traversal to identify all possible data holds (especially numbered outputs and draft report structures).
*   **Direct Active Transcript Reading**: Retrieve session logs directly from the active `transcript.jsonl` log file to guarantee 100% time-fidelity and accuracy.
