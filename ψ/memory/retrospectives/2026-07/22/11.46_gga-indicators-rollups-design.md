## 4. Lesson Learned Pattern
* **Pattern**: Abstract-Geometric Vector Prompting & Hardware Safe Zones for Physical Infographics
* **Concept**: `[design-system, prompt-engineering, visual-infographics, layout-grid]`
* **Learn**: To generate effective background graphics for infographics, avoid procedural UI terms (which produce blank templates) and photorealistic descriptions (which produce visual clutter). Use explicit abstract-geometric vocabulary (`flat color-blocked shapes`, `concentric rings`, `minimalist symbols`) and enforce absolute vertical height zones to protect hardware safe areas.
