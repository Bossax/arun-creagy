## 💡 Key Learnings

- **DOPA Civil Registration Mutual Exclusivity**: In raw DOPA census data (`pop67.csv`), multiple rows exist for a single 6-digit subdistrict when residents are divided between District Offices (`อำเภอ`) and Municipal Offices (`ท้องถิ่นเทศบาล...`). Because DOPA enforces strict 13-digit National ID uniqueness in household books (`ทร.14`), these rows are mutually exclusive partitions. Never run `drop_duplicates()`; always sum them via `groupby(['year_be', 'subdistrict_code']).agg({'population_total': 'sum', 'household_total': 'sum'})`.
- **Direct Asset Pipelines**: Staging build artifacts in intermediate folders is redundant if the web application's local `data/` folder serves as the canonical runtime target. Outputting directly to `output/cri_impact_app_v3/data/` simplifies lineage and eliminates copy drift.
