## Lessons and Friction

### Technical Learnings
* **Disaster Temporal Scaling:** Localized incidents (like Phra Nakhon Si Ayutthaya's Bang Ban floods) must be modeled as children of a parent storm/monsoon event (`DISASTER_EVENT` linked to `EVENT_LOCATION` via foreign keys). This resolves the scaling conflict, allowing national analysts to calculate aggregate storm impact while preserving local downtime characteristics.
* **Emergency Budgets vs. Economic Loss:** Government advance payments (เงินทดรองราชการ) represent fiscal caps rather than actual economic damage. Databases should isolate raw relief logs from macroeconomic GPP-based loss models to protect indicator fidelity.

### Friction & Workarounds
* **PowerShell String Escaping:** Passing multi-line Python scripts inside PowerShell double quotes often leads to syntax errors due to brace and quote collisions. The safest workaround is to write python code as a scratch script and invoke it cleanly.
* **Subagent Invoking Constraints:** Dynamic subagent registration is locked by the container platform. Predefined types (`research` and `self`) must be used instead.
