## Blockers & Discoveries
- **Global config**: The `agy` CLI's `/mcp` command reads its servers list from the global config path `~/.gemini/config/mcp_config.json`. When this file is empty, the command returns "no mcp server config".
- **LanceDB vs. Embedder Connection**: LanceDB is serverless and successfully initiates local connections instantly, but executing vector queries or inserting documents requires the active embedding provider (Ollama) to be reachable.
- **Docker Host Routing**: For a docker container on Windows, the host's localhost port is unreachable via `http://localhost:11434`. It must be explicitly routed using `http://host.docker.internal:11434`.
