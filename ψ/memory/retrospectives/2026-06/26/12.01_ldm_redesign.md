## Honest Feedback

- **Environment Robustness:** When the default conda base environment threw DLL errors on `pyexpat`, using `uv` proved to be the ultimate escape hatch. I should keep `uv` in mind as the default tool manager on Windows.
- **API and UI Drift:** Direct internal HTTP API calls are much faster, but since they are undocumented, they carry drift risk if Google alters endpoint URLs. However, browser selectors drift just as frequently, making the API version the superior choice due to its speed.

- **API-based MCPs over Playwright:** For time-sensitive tasks, choose direct API integrations over browser automation to avoid 60s host client timeouts.
- **Isolated Tool Provisioning:** When host Python environments have DLL errors, use `uv tool install` to provision isolated execution environments.
- **Manual Cookie Management:** Using manual cookie extraction is a reliable fallback when automated CDP logins fail or trigger bot protection.
- **Tool Context Management:** Enforce a strict Query-Only policy for NotebookLM. All other features (podcasts, mindmaps, slide decks, video generation, quizzes) are strictly prohibited and banned from use in this workspace to prevent context window bloat and maintain predictable tool behavior.
