## Lessons Learned

- A service baseline is not operational until it has a dossier structure: thesis, use-case cluster, agency targets, data/method requirements, governance, and adoption test.
- Use cases should be treated as decision situations that justify a reusable service, not as one-off requests.
- The conceptual model should be sealed separately from the applied example so the abstraction layer is clear.
- Workspace cleanup should preserve the active canonical layer and archive older drafts immediately after the canonical path is accepted.
- When a repo uses a different root marker than the skill template expects, the root-detection logic must be adapted to the local project conventions.
