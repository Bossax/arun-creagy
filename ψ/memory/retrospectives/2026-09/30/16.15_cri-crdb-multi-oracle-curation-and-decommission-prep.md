## 4. Lessons Learned

1. **Architecture Encompasses UX Contracts**: In national digital public platforms, data architecture is inseparable from information architecture and user experience. Developer-Ready Design (DRD) specs and screen interaction models define the downstream data contracts and query shapes that the data warehouse must serve. Omitting UX from an enterprise data architecture curation misses half the system boundary.
2. **Beware of Deep Vendor Clones in Breadth Scans**: Never run unconstrained recursive directory traversals (`Get-ChildItem -Recurse` or `find .`) over `ψ/learn/` without explicitly excluding vendor repositories or node/git subtrees. Large mirrored repositories like `Soul-Brews-Studio` contain tens of thousands of nested files that easily overwhelm shell execution buffers.
3. **The Staging-to-Decommissioning Two-Step**: Staging knowledge into specialized Oracles first (`ψ/active/incoming_*/`) while leaving parent workspace files untouched creates a zero-risk testing window for the user. Once the target Oracles verify their internalized models, purging the parent directories reclaims substantial disk space (~1.2 GB) safely.
