Friction 1: I let an inherited figure stand. The handoff, the plan and `counts.md` all repeated "266" and I passed it on. When several documents agree, that raises the chance they copied one mistake, so I should treat agreement as a reason to recompute, not to relax.

Friction 2: I answered the readiness question with the wrong tool. Boss said "we discussed this before" and I searched two unrelated conversation logs before finding the right transcript. His memory index already has a feedback item saying to use `/trace` for exactly this kind of search, and I did ad-hoc greps instead. The search cost several rounds.

Friction 3: The lint failure cost the whole session. Every draft edit produced a "venv is missing" message that I treated as background noise and worked around by running lint manually with a different interpreter. Boss called it "stupid, persistent", and he was right that a warning I ignore and route around is a broken control, not a nuisance. I should have diagnosed it at the first sighting, not the twentieth.

## Lessons Learned

1. Recompute totals from the data, never from a summary. Documents that agree may share one error.
2. When a figure in prose disagrees with a data file, find which decision produced the prose figure before choosing a side.
3. A shared skill's design docs (`README`, sync script) define what is intentional. Read them before proposing a structural fix.
4. A hook that fails silently on every run is a defect to diagnose immediately, and a diagnostic that prints the environment beats reasoning about it.
5. Use the dedicated writing agent for Thai prose, then diff its output against yours; the differences are the evidence.
