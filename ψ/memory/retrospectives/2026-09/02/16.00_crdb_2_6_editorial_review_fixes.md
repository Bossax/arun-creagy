## Lessons Learned
1. **The Bounded Amendment Path**: When the human's manual edits abstract away details mandated by the Argument Map, do not force the details back in. Instead, amend the Argument Map and Contract in-place so the framework matches the human's newly established abstraction level.
2. **Canonical Artifact Precedence**: Always reference institutionalized Phase 2 outputs (like `Domains-v3.csv` or `Pillar_05_CDM_EARCatalog_Deliverable.md`) for structural domains, rather than relying on earlier phase memory or unverified drafts.
3. **Lexicon over Contract**: If a specific `writing-contract.json` mandates a term that conflicts with the global `LEXICON_TH.json`, the global Lexicon (which reflects long-term human preferences) should take precedence, and the contract must be updated.
