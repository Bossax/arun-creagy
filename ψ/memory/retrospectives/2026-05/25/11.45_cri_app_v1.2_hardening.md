## Honest Feedback
1.  **Corruption Friction**: The stray characters introduced into `app.py` during the v1.1.0 update were a major setback. It seems that `replace` or `write_file` might have overlapped in a way that left garbage at the end of the file, necessitating an extra hotfix turn.
2.  **Environment Friction**: The `PyInstaller` build failed multiple times due to environment issues (corrupted miniconda DLLs) and file locks (running .exe). Navigating Windows filesystem permissions for `.exe` files is always tedious.
3.  **Data Quality Friction**: The Shapefile's data quality for Bangkok was unexpectedly poor, with province names missing entirely. I spent several turns diagnosing why Bangkok wouldn't plot before realizing the underlying name field was just `"<NA>"`. This forced a significant pivot in the logic mid-session.

## Lessons Learned
*   **Administrative Code Superiority**: Always prefer standardized administrative code prefixes (e.g., 2-digit province codes) for spatial filtering over name-based joins, which are prone to corruption and translation inconsistencies.
*   **Robust Joins**: Using a `left` join from the map geometry to the impact data ensures that the entire boundary is always rendered, avoiding "holes" in the map for subdistricts with zero or missing impact records.
