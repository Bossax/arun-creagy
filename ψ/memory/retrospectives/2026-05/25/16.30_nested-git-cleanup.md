## Honest Feedback
1. **Shell Friction**: PowerShell's `&&` restriction still causes minor pauses in momentum, requiring a shift to `;` or full `powershell.exe -NoProfile -Command` wraps.
2. **Gitlink Complexity**: Gitlinks (mode 160000) are powerful but often confusing when they aren't explicit submodules. They hide "dirty" states that bubble up as vague errors.
3. **Context Volume**: Adding 400+ files to the tracking index is a jump in repo size, but for a reference vault (`ψ/learn`), visibility and backup are more important than keeping the git index tiny.

## Lessons Learned
- **Flatten Reference Repos**: When cloning external repositories into a knowledge vault (`ψ/learn`), it is often better to remove the `.git` metadata immediately. This prevents "gitlink" behavior and allows the main repository to manage the files as static reference data.
- **Line Ending Sensitivity**: Nested repositories are particularly sensitive to `core.autocrlf` settings if they weren't initialized with the same policy as the host.
