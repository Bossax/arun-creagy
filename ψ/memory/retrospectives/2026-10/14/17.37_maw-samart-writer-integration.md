## 5. Lessons Learned

1. **Non-Interactive Shells in MAW**: `maw ls` and `maw wake` prompt for interactive snapshot restoration if snapshots exist in `~/.maw/snapshots/`. Scripted callers must redirect `< /dev/null` to prevent hung background processes.
2. **Command Scoping in MAW**: MAW's `commands` map in `maw.config.json` allows full command line flags (e.g. `codex -m <model> -c <key>=<val>`), eliminating the need to alter global tool configs.
3. **Cross-OS Codex Authentication**: When calling Codex inside WSL, authentication is read from `~/.codex/auth.json`. Syncing from Windows `%USERPROFILE%\.codex\auth.json` enables immediate authentication without manual web login flows.
