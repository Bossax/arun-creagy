## 3. AI Diary & Agent Decisions

### [→ AGENT DECISION]
In my initial formulation of `plan_maw_interop_skills.md`, I made two flawed architectural assumptions:
1. I treated Arun as the sole orchestrator and planned to house `/conduct`, `/fleet-doctor`, and `/team-room` only locally in `Arun_Creagy`, failing to embrace the symmetric peer-to-peer nature of the Oracle network where *any* Oracle can conduct, delegate, and synthesize.
2. I mandated that responding Oracles write cached briefs into `ψ/memory/knowledge/`, violating the core principle that `ψ/memory/knowledge/` is reserved exclusively for human-curated atomic knowledge and overlooking the fact that some Oracles do not even have this directory.

When Boss intervened on lines 47, 80, and 100, I acknowledged these mistakes, unified all skills under the `maw-` namespace in `oracle-shared-skills` for global distribution, implemented the 3-step cognitive escalation workflow (Ask yourself $\rightarrow$ Ask a friend $\rightarrow$ Tell friends to do their parts), made requester inbox destinations dynamic, and redirected responder archival safely to `ψ/outbox/`.

## 4. Lessons Learned

1. **Symmetric Peer Architecture in Multi-Agent Networks**: In an ecosystem of specialized sovereign agents, orchestration capabilities must not be siloed to a single master node. Every peer must possess identical primitives for self-grounding, 1-on-1 consultation, and multi-peer convergence so leadership can rotate dynamically based on where the user's prompt lands.
2. **Preservation of Curated Memory Stores**: Automated inter-agent messaging pipelines must never dump raw or intermediate briefs into curated knowledge vaults (`ψ/memory/knowledge/`). Operational mailboxes (`ψ/inbox/`, `ψ/outbox/`) provide full session auditability without polluting human-curated knowledge graphs.
3. **Headless Convergence vs. Visual Co-location**: Multi-oracle problem decomposition does not require the overhead of a resident tmux session or shared worktree. Pure headless file-join over `maw hey` avoids tmux pane zombies and context window pollution, while team canvases should remain an on-demand presentation layer for human visual monitoring.
4. **PowerShell-to-WSL String Interpolation Traps**: In PowerShell Core, string `-replace` with scriptblocks containing capture group indexing can fail with `Cannot index into a null array`. Explicit regex matching with the automatic `$Matches` variable is significantly more robust for cross-platform path translation.
