## Lessons Learned

1. **Clear Taxonomy over Incremental Clutter**: Root utilities that provision or manage repositories are `tools/`. Skill-specific operational scripts belong strictly inside `skills/<name>/scripts/`. Mixing them at root creates confusion about where shared logic lives.
2. **Native Runtimes Win Over Virtual Environments**: Packaging Python `.venv` inside git submodules or project copies generates thousands of files, breaks across operating systems, and causes interpreter mismatch friction. Leveraging Node.js native ICU `Intl.Segmenter` gave us zero-dependency, instantaneous, portable Thai word tokenization across all agent hosts.
3. **Multi-Client Support Must Be First-Class**: Supporting Claude Code (`.claude/agents/*.md`), Antigravity (`.agents/agents/*.md`), and OpenAI Codex CLI (`.codex/agents/*.toml`) requires declarative automated provisioning in `tools/sync-skills.ps1`, not manual instructions.
4. **Anticipate Submodule Dirty States in Consumers**: When propagating across a fleet, consumer submodules may have accumulated editor-induced formatting changes or untracked directories (like `.obsidian/`). The propagation process must verify clean status or restore trackable shared files before attempting checkouts.
5. **Strict Disk Verification Before Declaration**: Always execute the linter and drift scripts and inspect exit codes before claiming zero drift or test pass.
