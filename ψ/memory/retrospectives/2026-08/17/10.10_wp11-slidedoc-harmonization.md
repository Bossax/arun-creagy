## 2. Hard Lessons & Root Causes
- **The Design Drift Phenomenon**: During initial markdown-to-HTML compilation, subagents independently adjusted CSS variables (shrinking titles to 32px, changing padding, dropping font stacks), leading to visual regression from the Creagy Corporate standard.
- **Asset Relative Path Fragility**: Relying on relative paths across varying folder depths caused broken images. Placing an explicit `assets/` subfolder adjacent to the HTML decks provides stable visual rendering.

## 3. [→ AGENT DECISION]
- **Wrong Choice**: When compiling Deck 2 initially, I permitted the HTML compiler subagent to write a custom adapted stylesheet instead of strictly mandating a 100% verbatim copy of the canonical `WP9_Slidedoc/index.html` `<style>` block and asset folder. This caused visible formatting degradation that required user intervention to detect and fix.
- **Corrective Action**: Enforced strict stylesheet locking across all three decks, ensuring identical variable tokens, font weights (800/600), typography scale (62/42/38/27), and local asset folder structure.
