## AI Diary

The main design correction was to distinguish an LLM-neutral workflow from neutral
access to host evidence. Both supported hosts load `.agents/skills`, but each keeps
session data in a different shape and location. The shared adapter therefore selects
only an explicit host and returns an honest absence result instead of scanning every
provider directory.

[→ AGENT DECISION] I initially proposed generated host-specific mirrors before
verifying whether Antigravity and Codex already load `.agents/skills`; that would
have preserved unnecessary duplication and drift risk.

## Lesson

Portability should be implemented as a stable capability contract with narrow host
adapters, not by embedding provider assumptions in workflow instructions. An
unavailable capability is valid evidence and must be reported rather than replaced
with guessed history.

## Follow-up

- When a host session is intended to supply history, set `ORACLE_SKILL_HOST` to
  `antigravity` or `codex` before invoking the shared adapter.
- Review the staged skill changes independently from the unrelated worktree state
  before committing.
