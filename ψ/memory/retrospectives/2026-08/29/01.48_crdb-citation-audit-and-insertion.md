## What Could Improve

- Closing summaries after multi-agent work need to inventory ALL findings evenly, not lead
  with whichever chapter the user originally flagged. A "quick wins" framing is fine as a
  section, but it can't replace a complete inventory.
- Should have explicitly told the chapter-1 subagent it could NOT use WebFetch/web search —
  the plan said "search project files," but general-purpose subagents have full tool access
  by default, and one used it anyway. Scope needs to be enforced with an explicit tool
  restriction, not just described in prose.
- Should have anticipated that "no date" citations are a real gap category the project's own
  citation-hygiene rules would reject, and either flagged that risk to Boss before inserting
  them, or defaulted to gap-logging undated sources from the start rather than inserting them
  and having to walk them back.

## Honest Feedback

Three friction points, concretely: (1) I under-communicated my own audit's findings —
having the data isn't the same as surfacing it, and a synthesis message that leads with
"priority actions" instead of "here's everything found" reads as incomplete even when the
underlying work isn't. (2) I let a subagent exceed its scoped research method (project
files only) without catching it before reporting back — I flagged it after the fact
instead of constraining the tool access up front, which is a weaker control. (3) I inserted
undated citations without first checking them against the project's own established
citation-hygiene standard, which explicitly treats "no real source" as a rejection
condition — an undated citation is a half-measure that should have been caught before
Boss had to say so. None of these were about wrong facts; all three were about judgment on
what "done" looks like and how to present it honestly.

## Lessons Learned

1. When reporting multi-agent findings, inventory every result with equal weight in the
   closing summary — don't let a "priority" framing bury solid findings the user will
   independently notice are missing.
2. Scope subagent tool access explicitly (not just in prose) when the task requires staying
   within one data source (e.g. "project files only, no WebFetch") — general-purpose agents
   default to full tool access and will use it if not constrained.
3. An undated ("n.d.") citation should be treated as equivalent to no citation under this
   project's citation-hygiene standard — don't insert it speculatively; log it as a gap from
   the start.
