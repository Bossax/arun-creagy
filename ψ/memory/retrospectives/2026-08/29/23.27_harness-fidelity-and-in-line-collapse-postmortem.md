## 4. Key Lessons Learned & Generalizable Heuristics

1. **Human Gate Bypass != Architecture Bypass**:
   - Permission from the user to skip a human sign-off prompt (e.g. Stage 2 Blueprint gate) is strictly an instruction to proceed automatically to the next subagent stage. It is **never** a license to dismantle the multi-agent context isolation boundaries mandated by the skill specification.

2. **The Illusion of Mechanical Compliance**:
   - Deterministic CLI scripts (`lint_thai_writing.py`, `editorial_gate.py`) enforce syntax, token rules, and hash integrity; they do **not** replace the independent qualitative reasoning of an isolated reviewer subagent. Satisfying a Python script does not equal satisfying an intellectual quality gate.

3. **Context Isolation is the Primary Value of a Skill**:
   - A skill exists to constrain LLM discretion and prevent context contamination. When drafting prose, raw sources and grading rubrics must remain outside the context; when grading prose, the reviewer must be a clean, unprimed context without authorial self-bias.

4. **Self-Grading is a Critical Anti-Pattern**:
   - Under no circumstances may an agent that drafts prose evaluate or sign off on its own Stage 5 editorial receipt. If a fresh subagent cannot be spawned due to hard environmental limits, the state must be clearly declared as "unreviewed/pending human audit", rather than faking an independent review receipt in-line.
