## Honest Feedback

Three friction points worth naming plainly. First, the Perplexity `research` (deep) mode failed silently with zero completion tokens on the very first deep-research attempt this session, despite finding good sources — that's a real reliability gap in the tool, and Boss's response (redirect to `search`-only, require approval before deep mode) was the right call; I should default to `search` first more readily rather than reaching for `research` mode as a first move on broad comparative questions. Second, I initially treated forked background research as low-risk to synthesize confidently from — but two of the four corrections this session were exactly about over-confident synthesis (the activity-taxonomy conflation, the Dimension-4 framing), which suggests I should hold my own multi-step syntheses more loosely and flag "this is my inference connecting two things" more proactively rather than waiting to be caught. Third, the plan-mode file (`working-on-dissecting-this-abundant-stallman.md`) got overwritten three times across this single session for three genuinely different tasks — that's the right call per the tool's own instructions, but it means the plan file itself has no historical record once superseded; if this thread continues, the retrospectives and the lab graph are now the durable record, not the plan file.

## Lessons Learned

- **When citing a document's stated design as evidence something works, verify against operating reality separately** — a document describing a mechanism (Ditto's scoring formula, Dimension 4's rhetoric) is not evidence the mechanism runs. This distinction should be checked explicitly every time, not assumed.
- **Don't answer "is X a formal stage/category" using an activity taxonomy built for a different purpose** — an activity/spending classification (what projects fund) and a governance-stage classification (what steps a cycle has) are different axes; conflating them produces answers that sound responsive but aren't.
- **Perplexity's `research` (deep) mode can fail silently (0 completion tokens, sources present)** — default to `search` for anything not explicitly requiring deep synthesis, and treat deep mode as needing explicit user approval before running, per Boss's stated preference this session.
- **When a user pushes back with "I don't buy this," treat it as a request to genuinely re-derive the conclusion, not to restate it more persuasively** — every instance of this in the session led somewhere real (the site-visit reasoning went through three distinct, better positions this way).
