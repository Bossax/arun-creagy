## 4. Lessons Learned
- **Gate Enforcement**: The `editorial_gate.py verify` script is strict about all fields being appropriately populated. Empty strings for reviewer identities will cause a failure even in a degraded/self-review mode.
- **Artifact Isolation**: Temporary drafts and their associated contracts/reviews must reside strictly in the workspace's target isolation directory (`ψ/incubate/drafts/...`) to ensure that the python scripts can path to them properly. Mixing them up with UI artifacts causes tool failures.
