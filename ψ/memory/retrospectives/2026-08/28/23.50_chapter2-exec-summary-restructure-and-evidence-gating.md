## Lessons Learned

1. **A section move invalidates semantic assumptions, not only paths.** When a draft workspace is renumbered, re-check the writing plan, contract, exclusions, and neighboring-section boundaries before reusing any inherited artifact.
2. **Freeze canonical names before final drafting.** Define full inventory names, exact service labels, and ontology terms in the contract terminology map. Use explicit first mentions and controlled short forms thereafter.
3. **Keep ontology and service architecture separate.** A service can support monitoring and evaluation without making monitoring and evaluation a demonstrated CDM domain.
4. **Assign sources distinct jobs.** For Section 2.4, the data catalog supports direct dataset recounting, the dissemination deck supports product-type shares, and draft 5.3.4 supports product geography, delivery channels, and qualitative findings.
5. **Make denominators and overlapping classifications explicit.** Access percentages must state the 257-record denominator, while overlapping product-type percentages must be explained as non-additive.
6. **Treat independent review as semantic verification.** Mechanical linting cannot catch recommendation drift, missing contract structures, ontology conflation, or competing canonical terms.
7. **Do not convert ambiguity into executive prose.** If a slide claim lacks a clear definition or denominator, retain it in the evidence note until it can be reconciled.
