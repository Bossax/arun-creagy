## Lessons Learned

1. **Advance approval accelerates a gated workflow without erasing its audit trail.** Record the approval in the content contract, then continue through isolation, mechanical checks, semantic review, and the human merge bridge.
2. **Executive synthesis must distinguish three kinds of completion.** A design blueprint can be complete while source content remains partial and no operational software exists. State each layer separately and attach the relevant evidence.
3. **Internal locators belong in a sidecar.** Evidence paths, document positions, requirement codes, and drafting rationale support traceability but must not leak into audience-facing prose.
4. **A review receipt certifies immutable content, not a filename.** Any correction changes the draft hash and requires a fresh semantic review, even when the edit appears minor.
5. **Independent review remains useful after a mechanical pass.** Encoded rules caught none of the three copy defects; human semantic reading caught them without confusing them with major editorial failures.
6. **Locate before patching.** Reviewer line numbers and quoted fragments are pointers, not guaranteed current patch context. Search the live file and edit the smallest exact span.
7. **Reload MCP workers by verified identity.** Inspect process name and full command line, terminate only matching workers, leave host daemons and unrelated MCP servers untouched, and verify the backing container remains healthy.
