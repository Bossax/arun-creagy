## Lessons Learned

1. **Ephemeral Execution Environments**: When a user provides a raw shell command that only modifies environment state (like activating a Python `venv` or setting environment variables), the agent must clearly communicate that such state changes do not persist across isolated tool calls. Chaining `(activate) ; (execute)` is mandatory for background tool runners.
2. **Pre-approvals in Multi-Gate Workflows**: Human pre-approval for complex, multi-stage workflows (like `writing-th` v5) is highly effective. It allows the agent to move directly from contract generation to drafting and editorial review without pausing, provided the final merge remains safely guarded.
