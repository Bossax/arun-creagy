## 5. Key Architectural Insights & Patterns

1. **3-Tier Subagent Reasoning Model Selection**:
   * **Main Agent (Orchestrator)**: Medium reasoning.
   * **Bulk Query Runner**: Low reasoning (`flash` / `flash_lite`) for fast, zero-error verbatim JSON captures.
   * **Second-Opinion Auditor**: High reasoning (`pro`) for synthesis analysis, DAMA/TOGAF/BABOK web cross-referencing, and feedback generation.
2. **Automated Background Schedule Polling**:
   * Replaced blocking sleep loops with `schedule` timers checking every 120s for file creation (`iteration-N/02_synthesis.md`), achieving smooth asynchronous multi-agent coordination.
3. **"Phase, Don't Bundle" Rule**:
   * Academic literature (DAMA-DMBOK, IEEE 29148) explicitly mandates keeping data governance, CDM, business glossary, and master data as distinct disciplines rather than combining them into a single monolithic document.
