## Honest Feedback

Three friction points worth naming. First, the citation-audit files (`ch1-4-references.md`) have no explicit "last verified against draft version X" marker — I had to infer staleness indirectly via file mtimes and git log, which worked but is fragile; a simple frontmatter timestamp keyed to the draft's own last-revision commit would make this a one-glance check instead of forensic reconstruction. Second, the `evidence-traceability.md` / `ch{N}-references.md` split (internal traceability vs. audience-facing citation audit) is a real and useful distinction, but nothing enforces that a claim added to one gets mirrored in the other — I did it manually this session and it would be easy for a future session to update one and forget the other. Third, discovering that `section-1.4-draft.md` predates the v6.0 pipeline entirely (no argument map, ever) only surfaced when I literally tried to write to it — there's no index or manifest of "which drafts are pre-v6.0 and frozen" that a session could check up front, so this kind of gate-hit is likely to recur across other pre-v6.0 sections (1.1's `02_th_draft.md`, 1.2, 1.3, 2.x, 3.x may have the same gap) until someone runs recovery on all of them or builds that manifest.

## Lessons Learned

- **Before compiling any citation/reference deliverable from working-audit files, cross-check audit timestamps against draft-modification timestamps** — an audit is a snapshot, and drafts that go through later revision (especially the revision-mode redraft pipeline) can silently invalidate it without any visible marker in the audit file itself.
- **When a claim originates in an internal, unsealed working document, treat that as a strong signal to look for the real external concept it's approximating, not as a citation source itself** — internal docs are useful for identifying *what* needs grounding, not *what* grounds it.
- **Check for a draft's `argument-map.json` sibling before proposing exactly where an edit will land** — pre-v6.0 drafts are silently frozen by the harness gate, and this is discoverable with a single Glob before spending a user turn on placement questions.
