## Lessons Learned

- **Stage 0 must be a hard gate, not a loose suggestion**: Without a strict 3-part checklist (Outline, Evidence Base, Session Rules), agents drift into guessing scopes or reaching for the wrong source taxonomy.
- **Trace logs are the bridge to Toulmin warrants**: An outline alone provides only semantic intent; trace logs provide the technical ancestry and problem triggers [T] required to build defensible institutional warrants [W].
- **Shared .agents/ skills must explicitly account for all resident runtimes**: In a workspace shared by Antigravity, Claude Code, and Codex, skills must explicitly document the execution recipe for each host rather than assuming all runtimes support identical UI modals or subagent APIs.
