# Style-Pack: NCAIF-Institutional
**Samples Learnt**: 6 (Naturalization & Empirical Precision) | **Last Updated**: 2026-06-10

## 1. Ranked Style Rules
1. **Naturalization over Translation** - NEVER translate English metaphors literally. 
    - Use **"ประเด็นการดำเนินงาน"** (Action Points) instead of "พื้นที่การดำเนินงาน" (Areas of Action).
    - Use **"รากฐาน"** instead of "ฐานราก" (which sounds like foundation engineering).
2. **Empirical Precision (20/80 Rule)** - Avoid vague quantifiers like "ข้อมูลส่วนใหญ่" (Most data). Use specific statistics: **"ร้อยละ 20 เท่านั้นที่มีความพร้อม..."** vs **"ส่วนที่เหลือร้อยละ 80 ยังติดอุปสรรค..."** to build credibility.
3. **Purpose-First Phrasing** - Start Institutional Necessity sections with proactive intent: **"เพื่อแก้ไขอุปสรรคเชิงโครงสร้าง..."**, **"เพื่อขจัดข้อจำกัด..."**, or **"เพื่อคุ้มครองผู้บริหารและหน่วยงาน..."**.
4. **Descriptive Thai Headers** - Replace English jargon in parentheses with descriptive Thai phrases. Instead of "Translational Gap," use **"การขาดการประมวลผลข้อมูลวิทยาศาสตร์สู่สารสนเทศสนับสนุนการตัดสินใจ"**.
5. **Contextual Concreteness** - Link data gaps to specific real-world engineering/policy impacts (e.g., "การออกแบบอัตราการระบายน้ำของท่อระบายน้ำ", "การออกแบบท่าเรือให้พร้อมกับระดับน้ำทะเล").
6. **In-line Justification** - Integrate "Regulatory Justification" (ความชอบธรรมตามกฎข้อบังคับ) directly into the narrative.

## 2. Lexicon & Diction (Dos/Don'ts)
| Banned/Common | Preferred | Reason |
| :--- | :--- | :--- |
| "พื้นที่การดำเนินงาน" | "ประเด็นการดำเนินงาน" | Avoids robotic translation of "Areas". |
| "ฐานราก" | "รากฐาน" | Sounds more natural in a policy context. |
| "ชิ้นข้อมูลฐานราก" | "ข้อมูลพื้นฐาน" | Metaphor removal. |
| "พละกำลัง" (Effort) | [Rephrase to actual impact] | "พละกำลัง" sounds like physical strength; use "ทรัพยากรบุคคล" or "ภาระงาน". |
| "คอขวด" (Bottleneck) | "อุปสรรคเชิงโครงสร้าง / ข้อจำกัด" | Focus on the nature of the obstacle. |
| "Institutional Shield" | "การคุ้มครองผู้บริหาร" | Focus on administrative safety. |

## 3. Structural DNA
- **Bottom-Up Evidence**: Start with the raw data audit (260 datasets) to justify the service-level gaps.
- **Problem-Oriented Headers**: Headers should state the *challenge* (e.g., "การตัดสินความคุ้มค่าท่ามกลางความไม่แน่นอน") rather than the *process*.
- **Natural Transition**: Use connectors that link technical gaps to policy outcomes without sounding like a translated list.

## 4. Anti-AI Shield (Counter-examples)
- **CRITICAL DON'T**: Use English parentheticals like "(Bottom-Up Analysis)" or "(Temporal Gap)" in final headers.
- **CRITICAL DON'T**: Use "...ในระดับฐานราก" (sounds like civil engineering).
- **DON'T**: Use vague "ตอบโจทย์ผู้ใช้งาน". Use **"สนับสนุนความต้องการใช้งานของผู้มีส่วนเกี่ยวข้อง"**.

## 5. Master Implementation Prompt
> **Writing Mode**: NCAIF-Institutional (v2.3 - Natural & Empirical)
> **Instructions**: Write in a formal Thai institutional voice. Avoid literal translations of English metaphors (e.g., use "ประเด็น" not "พื้นที่" for areas). Prefer "รากฐาน" over "ฐานราก". Use specific empirical statistics (e.g., 20/80 split) and concrete engineering examples. Lead with "เพื่อแก้ไข..." or "เพื่อคุ้มครอง...". Remove all English jargon parentheticals. Focus on executive protection, audit risk, and the transition from raw data to decision intelligence.
