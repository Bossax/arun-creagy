## 2. Tone and Style Shift Analysis

1. **Elimination of Fragmented Floating Phrases (Anti-Jumpiness)**:
   - *AI Draft Tendency*: Often prepends descriptive metadata or standalone noun phrases before the main subject (e.g., \สไลด์หลัก 14 แผ่น... เอกสารนี้...\), causing a disjointed reading flow.
   - *Refined Institutional Standard*: Integrates scoping and introductory metadata into one complete, flowing sentence (\เอกสารนี้ประกอบด้วย... ซึ่งจัดทำขึ้นเพื่อ...\).

2. **Punctuation and Conjunction Discipline in Enumerations**:
   - *AI Draft Tendency*: In table cells or dense summaries, separates multiple nouns/metrics purely by spaces, forcing the reader to guess boundary breaks.
   - *Refined Institutional Standard*: Applies clear punctuation (\,\) and connectors (\และ\, \รวมถึง\, \พร้อมด้วย\) to delineate separate deliverables and attributes smoothly.

3. **Parallel Structure in Multi-Item Bullet Lists**:
   - *AI Draft Tendency*: Mixes full action sentences (Subject + Verb) with bare noun phrases in the same bullet block.
   - *Refined Institutional Standard*: Enforces structural symmetry across all bullet points (e.g., all items start as qualified outcomes with \ที่สามารถ...\ or \ซึ่งผ่าน...\).

4. **Action-Verb Consistency in Implementation Schedules & Task Tables**:
   - *AI Draft Tendency*: Randomly alternates between verbal commands (\ออกแบบทางกายภาพ\) and static nouns (\การแยกสภาพแวดล้อม\, \สัญญาข้อมูล\).
   - *Refined Institutional Standard*: Ensures every clause in a task breakdown begins with an active operational verb (\จัดทำ...\, \กำหนด...\, \ออกแบบ...\).

## 3. Candidate Style Rules

- **Candidate Rule 1 (Introductory Sentence Cohesion)**: Document and section overviews must not start with floating noun fragments; combine volume/scope metadata into a complete main clause with clear relational connectors (\ประกอบด้วย... ซึ่งจัดทำขึ้นเพื่อ...\).
- **Candidate Rule 2 (Enumeration Cadence & Punctuation)**: In dense table cells or metric summaries, do not chain noun phrases using only whitespace. Use commas (\,\) and formal conjunctions (\และ\, \รวมถึง\, \พร้อมด้วย\) to guide reading cadence.
- **Candidate Rule 3 (Bullet-List Parallelism)**: Ensure all items within a bulleted list share identical grammatical structure (e.g., all active verbs or all outcome phrases with relative clauses).
- **Candidate Rule 4 (Task Table Verb-Object Uniformity)**: Every modification or deliverable bullet in an operational plan must consistently lead with an action verb (\จัดทำ\, \กำหนด\, \ออกแบบ\, \เพิ่ม\).
