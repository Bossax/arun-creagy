**1. ที่มาและความสำคัญ**

          โครงการพัฒนาแห่งสหประชาชาติ (UNDP) ดำเนินงานในกว่า 170 ประเทศและเขตพื้นที่ทั่วโลก มุ่งสนับสนุนการขจัดความยากจน ลดความเหลื่อมล้ำ และเสริมสร้างความเข้มแข็งให้แก่ประชาชน  
และโลก เพื่อให้ประเทศต่าง ๆ สามารถก้าวไปข้างหน้าได้อย่างยั่งยืน โครงการพัฒนาแห่งสหประชาชาติ (UNDP) ในฐานะหน่วยงานด้านการพัฒนาของสหประชาชาติ มีบทบาทสำคัญในการสนับสนุนประเทศต่าง ๆ  
ให้บรรลุเป้าหมายการพัฒนาที่ยั่งยืน (SDGs) ผ่านเครือข่ายนโยบายระดับโลกและชุมชนนักปฏิบัติ  
ซึ่งช่วยถ่ายทอดองค์ความรู้ด้านนโยบายการพัฒนาให้แก่แต่ละประเทศ พร้อมทั้งเผยแพร่ประสบการณ์ของประเทศเหล่านั้นไปยังเวทีโลก

ประเทศไทยได้ดำเนินการอย่างแข็งขันในการรับมือกับความท้าทายด้านการเปลี่ยนแปลง  
สภาพภูมิอากาศ โดยมีความมุ่งมั่นในการเสริมสร้างความสามารถในการปรับตัวของประเทศ  
ตามที่กำหนดไว้ในแผนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศแห่งชาติ (National Adaptation Plan : NAP) และเป้าหมายที่ประเทศกำหนด (Nationally Determined Contribution : NDC)  
ในฐานะภาคีของกรอบอนุสัญญาสหประชาชาติว่าด้วยการเปลี่ยนแปลงสภาพภูมิอากาศ (United Nations Framework Convention on Climate Change : UNFCCC) และความตกลงปารีส (Paris Agreement) ประเทศไทยมีพันธกรณีในการจัดทำรายงานความก้าวหน้าด้านการดำเนินงานด้าน  
สภาพภูมิอากาศอย่างสม่ำเสมอ ซึ่งรวมถึงการรายงานด้านการปรับตัว ผ่านรายงานแห่งชาติ (National Communication : NCs) และรายงานความโปร่งใสรายสองปี (Biennial Transparency Reports : BTRs) ภายใต้กรอบความโปร่งใสที่ยกระดับขึ้น (Enhanced Transparency Framework : ETF) ข้อกำหนด  
ในการรายงานระดับนานาชาติเหล่านี้ จำเป็นต้องอาศัยข้อมูลที่ครอบคลุมและเป็นปัจจุบันเกี่ยวกับผลกระทบด้านสภาพภูมิอากาศ ความเปราะบาง มาตรการปรับตัว รวมถึงประสิทธิผลของการดำเนินงาน โดยยึดตามวิธีการ ขั้นตอน และแนวทาง (Modalities, Procedures and Guidelines: MPGs)

กองทุนสิ่งแวดล้อมโลก (GEF) ได้ให้การสนับสนุนแก่โครงการพัฒนาแห่งสหประชาชาติ (UNDP) แห่งประเทศไทย ผ่านโครงการ “รายงานความโปร่งใสรายสองปีฉบับแรกของประเทศไทย (1BTR)และรายงานแห่งชาติฉบับที่ 5 และรายงานความโปร่งใสรายสองปีฉบับที่ 2 (5NC/BTR2)” เพื่อสนับสนุนกรมการเปลี่ยนแปลงสภาพภูมิอากาศและสิ่งแวดล้อม (DCCE) ในการจัดทำและยื่นรายงานความโปร่งใสรายสองปีฉบับที่ 1 (1BTR) และรายงานแห่งชาติฉบับที่ 5 และรายงานความโปร่งใสรายสองปีฉบับที่ 2 (5NC/BTR2) ต่อกรอบอนุสัญญาสหประชาชาติว่าด้วยการเปลี่ยนแปลงสภาพภูมิอากาศ (UNFCCC) นอกจากนี้ โครงการดังกล่าวยังสนับสนุนให้ประเทศไทยสามารถจัดทำรายงานความก้าวหน้า  
ด้านการสื่อสารด้านการปรับตัว (Adaptation Communication) ซึ่งประเทศไทยได้เคยจัดทำไว้ในรายงานแห่งชาติฉบับที่ 4 (4NC) ตามข้อบทที่ 7 ของความตกลงปารีส และการตัดสินใจที่ 9/CMA.1

          เพื่อให้ประเทศไทยสามารถยกระดับระบบการติดตามและประเมินผลด้านการเปลี่ยนแปลงสภาพภูมิอากาศในระดับประเทศได้อย่างมีประสิทธิภาพ โครงการฯ จึงได้พัฒนา (ร่าง) เอกสารกรอบข้อมูลฐาน (Baseline Framework Document) และแบบฟอร์มข้อมูลอ้างอิง (Data Reference Sheet) เพื่อใช้เป็นเครื่องมือกำหนดมาตรฐานข้อมูล ตัวชี้วัด วิธีเก็บรวบรวมข้อมูล และช่องทางรายงานที่สอดคล้องกันระหว่างหน่วยงานต่าง ๆ ในประเทศ การประชุมครั้งนี้จึงมีความสำคัญในการเผยแพร่ข้อมูล เสริมสร้างความเข้าใจร่วมกัน รวมถึงการรับฟังข้อคิดเห็นจากหน่วยงานที่เกี่ยวข้อง เพื่อนำไปสู่การพัฒนาเอกสารทั้งสองฉบับให้สมบูรณ์ เหมาะสม และรองรับระบบรายงานตามกรอบความโปร่งใสที่ยกระดับขึ้น (ETF) ได้อย่างยั่งยืน

การประชุมครั้งนี้จึงจัดขึ้นเพื่อนำเสนอกรอบแนวคิดและผลการจัดทำเอกสารทั้งสองฉบับ รวมถึงสาธิตการใช้แบบฟอร์ม Excel สำหรับการทบทวนรายการข้อมูลสนับสนุน โดยเปิดโอกาสให้หน่วยงานที่เกี่ยวข้องร่วมตรวจสอบความถูกต้อง ความเหมาะสม ความพร้อมของข้อมูล แหล่งที่มาของข้อมูล หน่วยงานเจ้าของข้อมูล ตลอดจนให้ข้อคิดเห็นและเสนอข้อมูลเพิ่มเติม เพื่อนำไปปรับปรุงเอกสารให้มีความครบถ้วน สอดคล้องกับบริบทการดำเนินงานของหน่วยงาน และสามารถใช้ประโยชน์ในการติดตามประเมินผลและการจัดทำรายงานด้านการปรับตัวของประเทศได้อย่างเป็นระบบและต่อเนื่อง

**2. วัตถุประสงค์ของการประชุม**

 2.1 เพื่อนำเสนอหลักการ แนวคิด และโครงสร้างของ (ร่าง) เอกสารกรอบข้อมูลฐาน (Baseline Framework Document) และ (ร่าง) เอกสารอ้างอิงข้อมูลฐาน (Baseline Data Reference Sheet) สำหรับสนับสนุนระบบติดตามและประเมินผลด้านการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศของประเทศไทย

2.2 เพื่อสร้างความเข้าใจเกี่ยวกับความเชื่อมโยงระหว่างข้อมูลสนับสนุนจากระบบติดตามและประเมินผล ตัวชี้วัดผลลัพธ์ของแผนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศแห่งชาติ ตัวชี้วัดของแผนปฏิบัติการด้านการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศรายสาขา และเป้าหมายการปรับตัวระดับโลก

2.3 เพื่อรับฟังความคิดเห็น ข้อเสนอแนะ และข้อสังเกตจากหน่วยงานที่เกี่ยวข้องต่อความถูกต้องและความเหมาะสมของรายการข้อมูลสนับสนุน ได้แก่ แหล่งข้อมูล หน่วยงานเจ้าของข้อมูล หน่วยวัด ความถี่ในการจัดเก็บ และความพร้อมของข้อมูล

2.4 เพื่อเปิดโอกาสให้หน่วยงานที่เกี่ยวข้องร่วมทบทวนและให้ข้อคิดเห็นต่อ (ร่าง) เอกสารอ้างอิงข้อมูลฐาน ผ่านแบบฟอร์ม Excel รวมทั้งเสนอข้อมูลหรือเอกสารอ้างอิงเพิ่มเติม เพื่อประกอบการปรับปรุงเอกสารให้มีความครบถ้วนและสามารถนำไปใช้ประโยชน์ได้อย่างเหมาะสม

**3. กลุ่มเป้าหมาย**

          3.1 กลุ่มเป้าหมายหลัก : หน่วยงานรับผิดชอบหลัก และหน่วยงานที่เกี่ยวข้องในรายสาขา  
ตามแผนการปรับตัวต่อการเปลี่ยนแปลงสภาพภูมิอากาศแห่งชาติ (NAP)       

3.2 กลุ่มเป้าหมายรอง : หน่วยงานต่าง ๆ ที่ดำเนินงานโครงการ/กิจกรรมร่วมกับกรมการเปลี่ยนแปลง

สภาพภูมิอากาศและสิ่งแวดล้อม
