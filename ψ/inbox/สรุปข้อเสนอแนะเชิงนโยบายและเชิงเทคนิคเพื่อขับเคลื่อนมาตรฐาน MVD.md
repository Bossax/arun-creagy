

## 1. ภาพรวมและหลักคิดของข้อเสนอ

การวิเคราะห์ในหัวข้อ 4.4 และ 4.5 ชี้ว่า การนำมาตรฐาน MVD ไปปฏิบัติใช้จริงไม่สามารถแก้ไขได้ด้วยการปรับปรุงแบบฟอร์มภาคสนามเพียงอย่างเดียว ข้อจำกัดสำคัญเป็นข้อจำกัดเชิงสถาบัน ได้แก่ ความกระจัดกระจายของสายธารเงินทดรองราชการ ความไม่สอดคล้องของกรอบเวลา การแยกส่วนของฐานข้อมูลข้ามกระทรวง และข้อจำกัดด้านกำลังคนระดับพื้นที่ คณะที่ปรึกษาจึงเสนอยุทธศาสตร์แบบบันไดก้าวหน้า (Progressive Tiered Roadmap) ที่เชื่อมโยงระเบียบวิธีประเมิน ข้อมูลทุติยภูมิ และกฎระเบียบด้านการคลังเข้าด้วยกัน โดยสอดคล้องกับบทบาทและอำนาจหน้าที่ของ กรม สส. ซึ่งไม่มีกลไกสำรวจภาคสนามและไม่มีอำนาจสั่งการให้หน่วยงานอื่นเปลี่ยนวิธีรายงาน

## 2. ข้อเสนอแนะเชิงนโยบาย

**2.1 วางตำแหน่ง กรม สส. เป็นผู้บูรณาการข้อมูลทุติยภูมิส่วนกลาง**  
การสร้างระบบประเมินที่ใช้ข้อมูลทุติยภูมิจาก กรม ปภ. กรมส่งเสริมการเกษตร GISTDA และกระทรวงการคลัง เป็นแนวทางเดียวที่เป็นไปได้จริงในทางปฏิบัติ และช่วยให้ กรม สส. เริ่มสร้างระบบข้อมูลได้ในระยะเวลาอันใกล้ โดยไม่ต้องรอให้หน่วยงานอื่นปรับวิธีรายงาน

**2.2 จัดตั้งกลไกแลกเปลี่ยนข้อมูลข้ามกระทรวง**  
เนื่องจาก กรม ปภ. ไม่มีอำนาจกำหนดมาตรฐานการบันทึกข้อมูลข้ามกระทรวง ควรกำหนดกลไกความร่วมมือในรูปแบบบันทึกข้อตกลงแลกเปลี่ยนข้อมูล (MOU/Data Sharing) และการเชื่อมต่อผ่าน API โดยออกแบบให้เกิดคุณค่าร่วมระหว่างหน่วยงาน และให้การคำนวณมูลค่าความสูญเสียดำเนินการที่ส่วนกลาง

**2.3 ร่วมมือกับ กรม ปภ. และกรมบัญชีกลางด้านสายธารการเงินการคลัง**

- ใช้สถิติการใช้จ่ายเงินทดรองราชการเป็นตัวแทนขั้นต้น (Fiscal Proxy) ของผลกระทบทางการคลังและความสูญเสียขั้นต่ำที่ภาครัฐต้องแบกรับในระดับจังหวัด เพื่อให้มีตัวเลขเชิงประจักษ์สำหรับรายงานได้ทันทีในระยะแรก
- ในระยะถัดไป พัฒนากลไกตรวจสอบเงินช่วยเหลือให้ละเอียดขึ้นจนเชื่อมโยงถึงระดับรายเหตุการณ์ โดยเชื่อมโยงบัญชีการคลัง New GFMIS Thai เข้ากับทะเบียนที่เชื่อมประกาศเขตการให้ความช่วยเหลือแต่ละฉบับเข้ากับรายการเบิกจ่ายเงินทดรองราชการที่เกี่ยวข้อง
- ชี้แจงขอบเขตของตัวเลขงบประมาณให้ชัดเจนว่ารวมการเบิกจ่ายจากทุกกระทรวงในจังหวัดหรือไม่ เนื่องจากระเบียบเปิดให้ทั้งผู้ว่าราชการจังหวัดและกระทรวงเจ้าของภารกิจมีวงเงินทดรองราชการของตนเอง

**2.4 กำหนดขอบเขตการใช้ข้อมูลดาวเทียมอย่างรัดกุม**  
ในขั้นนี้ข้อมูลดาวเทียมใช้เป็นเครื่องมือตรวจทานคุณภาพ (QA) และคัดกรองความผิดปกติเชิงพื้นที่เท่านั้น ภาครัฐไม่ควรนำไปประกอบการพิจารณาจ่ายเงินเยียวยาผู้ประสบภัยจริง เพราะยังขาดข้อมูลปฐมภูมิเพื่อยืนยันความเสียหาย (ground truth) และเพื่อรักษาความเป็นธรรมและความชอบธรรมตามระเบียบราชการ

**2.5 ไม่เพิ่มภาระงานแก่เจ้าหน้าที่ระดับพื้นที่**  
เจ้าหน้าที่ ปภ. จังหวัดและท้องถิ่นมีภารกิจหลักในการช่วยชีวิตและบริหารศูนย์พักพิง จึงไม่ควรกำหนดให้บันทึกข้อมูลครบทั้ง 62 เขตข้อมูล หรือประเมินมูลค่าทางเศรษฐกิจ ควรคงบทบาทของพื้นที่เป็นผู้ตรวจนับข้อมูลกายภาพ

**2.6 ขับเคลื่อนแบบก้าวหน้า 3 ระยะ ตามความพร้อมของข้อมูลและสถาบัน**  
เริ่มจากสิ่งที่ กรม สส. ทำได้ทันทีภายใต้อำนาจหน้าที่ปัจจุบัน แล้วยกระดับไปสู่ความละเอียดระดับรายเหตุการณ์และการประเมินเชิงลึกเมื่อกลไกความร่วมมือเข้มแข็งขึ้น โดยมีเงื่อนไขก่อนขยายงานในแต่ละระยะ (รายละเอียดในหัวข้อ 4)

## 3. ข้อเสนอแนะเชิงเทคนิค

**3.1 จัดสถาปัตยกรรมข้อมูล MVD เป็น 3 Tiers (38/17/7)**  
แบ่งเขตข้อมูลทั้ง 62 เขตตามความสามารถของผู้บันทึกและแหล่งข้อมูล เพื่อให้ข้อมูลระดับพื้นฐานจัดเก็บได้จริง ส่วนข้อมูลที่ต้องอาศัยความเชี่ยวชาญเฉพาะประมวลผลที่ส่วนกลาง

**3.2 พัฒนาทะเบียนรหัสเชื่อมโยงใน Tier 1**  
จัดทำทะเบียนที่ผูกรหัสธุรกรรมหรือรหัสการเบิกจ่ายเข้ากับรหัสประกาศเขตการให้ความช่วยเหลือ และรหัสเหตุการณ์ภัยพิบัติทางกายภาพ เพื่อให้ตรวจสอบย้อนกลับได้ว่าแต่ละประกาศหรือแต่ละเหตุการณ์ได้รับอนุมัติ เบิกจ่าย และส่งใช้เงินทดรองราชการเท่าใด

**3.3 แยกวันสิ้นสุดการเผชิญเหตุออกจากวันสิ้นสุดผลกระทบ**  
ออกแบบโครงสร้างข้อมูลให้แยกสองกรอบเวลานี้ออกจากกัน เพื่อแก้ปัญหาวันสิ้นสุดของภัยเฉียบพลันเป็นค่าว่าง และรองรับการคำนวณระยะเวลาความสูญเสียทางเศรษฐกิจที่ต่อเนื่อง โดยใช้แบบจำลองและข้อมูลดาวเทียมสนับสนุน

**3.4 ระเบียบวิธีประเมินภาคเกษตรกรรม**

1. คัดกรองพื้นที่ประสบภัยด้วยภูมิสารสนเทศ โดยนำข้อมูลจาก GISTDA ซ้อนทับกับทะเบียนเกษตรกรและพิกัดแปลงของกรมส่งเสริมการเกษตร และข้อมูลการใช้ที่ดินของกรมพัฒนาที่ดิน
2. ประมาณมูลค่าผลผลิตที่สูญเสียจากพื้นที่ที่ได้รับผลกระทบ ร่วมกับผลผลิตเฉลี่ยต่อไร่ (Baseline Yield) และราคา ณ ไร่นา (Farm-gate Price) จาก สศก. โดยคำนึงถึงระยะการเติบโตของพืชและระดับความเสียหาย
3. ประมวลผลที่ส่วนกลางด้วยแบบจำลองเดียวกันทั่วประเทศ

**3.5 ระเบียบวิธีประเมินสิ่งปลูกสร้างและโครงสร้างพื้นฐาน**

1. ต่อยอดจากกรอบ GRADE ของธนาคารโลก โดยซ้อนทับขอบเขตและความรุนแรงของภัยกับฐานข้อมูลที่ตั้งอาคารและโครงข่ายคมนาคมของหน่วยงานเจ้าของทรัพย์สิน
2. กำหนดบัญชีราคากลางมาตรฐานต่อหน่วย (เช่น บาทต่อหลัง หรือบาทต่อกิโลเมตร) จำแนกตามประเภทสิ่งปลูกสร้างและระดับความเสียหาย โดยอ้างอิงราคากลางของกรมบัญชีกลางหรือหน่วยงานช่าง
3. แยกการบันทึกมูลค่าความเสียหายทางกายภาพที่คำนวณได้ ออกจากการบันทึกงบประมาณหรือความต้องการฟื้นฟูตามหลัก Build Back Better เพื่อป้องกันความสับสนระหว่างความเสียหายจริงกับแผนการลงทุนในอนาคต

**3.6 ใช้ข้อมูลดาวเทียมและแบบจำลองเป็นเครื่องมือสนับสนุน**  
อาศัยบทเรียนจาก Farmers and Pixels, RIICE และ GRADE เพื่อให้ได้ตัวเลขความสูญเสียและความเสียหายขั้นต้นจากข้อมูลทุติยภูมิที่มีอยู่แล้ว โดยไม่ต้องเริ่มต้นจากการเก็บข้อมูลปฐมภูมิภาคสนามเพียงอย่างเดียว

## 4. แผนที่นำทางแบบบันไดก้าวหน้า 3 ระยะ

คณะที่ปรึกษากำหนดแผนดำเนินงานเป็น 3 ระยะ ตามลำดับความพร้อมของข้อมูลและสถาบัน โดยขอบเขตข้อมูลขยายตัวตามสถาปัตยกรรม 3 Tiers จาก 38 เป็น 55 และครบ 62 เขตข้อมูลตามลำดับ

**ระยะที่ 1: วางรากฐานและระบบต้นแบบ**

- _เป้าหมายหลัก:_ ประสานหน่วยงานแกนกลาง 4 หน่วยงาน พัฒนามาตรฐานพจนานุกรมข้อมูล จัดทำระบบต้นแบบรับข้อมูลแกนหลัก และจัดทำรายงาน Fiscal Proxy จากสถิติเงินทดรองราชการ
- _ขอบเขตข้อมูล:_ Tier 1 (38 เขตข้อมูล) ซึ่งเป็นข้อมูลตั้งต้นที่พร้อมใช้ทันทีจากรายงานเหตุด่วนของ ปภ. ทะเบียนประกาศจังหวัด และสถิติเงินทดรองราชการระดับจังหวัด
- _ผลผลิตสำคัญและเงื่อนไขก่อนขยายงาน:_ นิยามข้อมูลและหน้าที่ชัดเจน ระบบต้นแบบรับข้อมูลแกนหลัก รายงานวิเคราะห์ Fiscal Proxy ย้อนหลัง (พ.ศ. 2546–ปัจจุบัน) และมาตรฐานรหัสประกาศเขตการให้ความช่วยเหลือสำหรับใช้เชื่อมโยงข้อมูล

**ระยะที่ 2: ขยายความร่วมมือรายสาขา**

- _เป้าหมายหลัก:_ บูรณาการฐานข้อมูลรายสาขา เชื่อมโยงบัญชีการคลัง New GFMIS Thai และขยายการตรวจสอบย้อนกลับเงินทดรองราชการระดับรายเหตุการณ์ ผ่านทะเบียนที่เชื่อมประกาศเขตการให้ความช่วยเหลือเข้ากับรายการเบิกจ่ายเงินช่วยเหลือ
- _ขอบเขตข้อมูล:_ Tier 1 และ Tier 2 (รวม 55 เขตข้อมูล) เติมเต็มข้อมูลผลผลิต ราคา และการเงิน โดย New GFMIS Thai ผูกกับรหัสประกาศและรหัสเหตุการณ์
- _ผลผลิตสำคัญและเงื่อนไขก่อนขยายงาน:_ บันทึกข้อตกลงแลกเปลี่ยนข้อมูล (MOU/Data Sharing) ระบบคำนวณมูลค่าอัตโนมัติที่ส่วนกลาง และบัญชีเงินช่วยเหลือที่ตรวจสอบย้อนกลับได้รายเหตุการณ์

**ระยะที่ 3: ยกระดับสู่การประเมินเชิงลึก**

- _เป้าหมายหลัก:_ พัฒนาข้อกำหนดร่วมกับระบบงานราชการ และเปิดใช้การประเมินความต้องการฟื้นฟูระดับชาติ
- _ขอบเขตข้อมูล:_ ครบทั้ง 62 เขตข้อมูล (รวม Tier 3 อีก 7 เขตข้อมูล) รองรับการประเมิน PDNA และ Build Back Better
- _ผลผลิตสำคัญและเงื่อนไขก่อนขยายงาน:_ กลไกประเมิน PDNA ในภัยขนาดใหญ่ การเชื่อมต่อระบบงานผ่าน API และทีมงานดูแลรักษาระบบระยะยาว

## 5. บทสรุป

ข้อเสนอทั้งเชิงนโยบายและเชิงเทคนิคมีความเชื่อมโยงกันอย่างเป็นระบบ การเชื่อมโยงข้อมูลการคลังต้องอาศัยทะเบียนรหัสเชื่อมโยง การประเมินมูลค่าต้องอาศัยฐานข้อมูลกลางที่ไม่พึ่งพาเจ้าหน้าที่ในพื้นที่มากเกินไป และการบูรณาการข้ามกระทรวงต้องอาศัยกลไกการสร้างคุณค่าร่วมระหว่างหน่วยงาน การดำเนินงานแบบบันไดก้าวหน้าตั้งแต่ข้อมูลทุติยภูมิและการประมวลผลที่ส่วนกลางในระยะที่ 1 ไปจนถึงการประเมินเชิงลึกระดับชาติในระยะที่ 3 จะช่วยให้ กรม สส. เดินหน้าระบบติดตามความสูญเสียและความเสียหายจากการเปลี่ยนแปลงสภาพภูมิอากาศได้จริงภายใต้อำนาจหน้าที่ที่มีอยู่
